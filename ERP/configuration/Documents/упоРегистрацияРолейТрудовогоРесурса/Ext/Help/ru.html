Документ Назначение трудового ресурса на роль

Назначение

Документ "Назначение трудового ресурса на роль" предназначен для установления соответствия между трудовым ресурсом (элемент справочника Трудовые ресурсы) и ролями (элементы справочника Роли трудовых ресурсов). С помощью документа "Назначение трудового ресурса на роль" производится введение данных о том, какие из ролей выполняет тот или иной трудовой ресурс. В дальнейшем, использование механизма присвоения ролей трудовому ресурсу будет полезно:

  • При планировании проектов (возможность назначать на те или иные проекты определенные роли);
  • Для быстрого удобного подбора трудовых ресурсов в соответствии с назначенными ранее ролями.

    • Документ "Назначение трудового ресурса на роль" позволяет:

  • Регистрировать и хранить в системе сведения о ролях трудовых ресурсов;
  • Назначать одному трудовому ресурсу несколько ролей.

    • Форма объекта

    При создании документа "Назначение трудового ресурса на роль" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию - текущая дата;
  • Трудовой ресурс — выбирается из справочника Трудовые ресурсы.

    • Табличная часть документа "Назначение трудового ресурса на роль" заполняется назначаемыми трудовому ресурсу ролями. Заполнение происходит следующим образом:

  • С помощью универсального механизма заполнения табличной части — кнопки Подбор;
  • Вручную — по кнопке Добавить на панели инструментов или с помощью клавиши Insert.

    • Следует отметить, что одному и тому же трудовому ресурсу можно назначить любое количество ролей.
