Документ Регистрация должности сотрудника

Назначение

Документ "Регистрация должности сотрудника" предназначен для регистрации должности сотрудника, то есть места сотрудника в организационной структуре предприятия. Документ "Регистрация должности сотрудника" позволяет:

  • Регистрировать и хранить в системе информацию о том, какое место в организационной структуре предприятия занимает тот или иной сотрудник.

    • Важно! Сведения, введенные в систему с помощью документов "Регистрация должности сотрудника", носят исключительно справочный характер и никак не влияют на объекты управления системы (проекты, задачи и т.п.)

    Форма объекта

    При создании документа "Регистрация должности сотрудника" необходимо заполнить следующие обязательные реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию — текущая дата;
  • Сотрудник — из справочника Сотрудники выбирается сотрудник, должность которого регистрируется данным документом;
  • Организация — из справочника Организации выбирается организация, которой принадлежит данная должность;
  • Подразделение организации — из справочника Подразделения выбирается подразделение, которому принадлежит данная должность;
  • Должность — из справочника Должности выбирается должность, регистрируемая за сотрудником данным документом.
