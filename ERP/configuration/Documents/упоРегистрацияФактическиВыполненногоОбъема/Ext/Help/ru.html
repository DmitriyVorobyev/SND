Документ Регистрация фактического выполненного объема

Назначение

Документ "Регистрация фактического выполненного объема" предназначен для регистрации фактически выполненных объемов в процессе выполнения проекта.

Форма объекта

Примечание. Рекомендуется создавать этот документ в режиме ввода на основании, основанием служит документ Проектная задача.

При формировании документа вручную необходимо заполнить следующие обязательные реквизиты шапки документа:

  • Номер документа — уникальный номер документа, формируется автоматически.
  • Дата — дата документа, по умолчанию подставляется текущая дата.
  • Проект – проект, по проектным задачам которого производится фиксация фактически освоенных объемов, элемент справочника Проекты.

    • Дополнительно можно включить следующие опции:

  • Записывать процент готовности по доходным объемам — если опция включена, при проведении документа процент готовности проектной задачи будет рассчитан по план-фактным данным номенклатуры с признаком "Основной результат" из табличной части "Субпродукты" документа Проектная задача. В новых документах опция включена по умолчанию (с возможностью отключить вручную), если в проекте включена опция "Рассчитывать процент готовности при регистрации фактически выполненных объемов". Расчет процента готовности производится для проектной задачи в статусе "Выполняется" проекта в статусе "Выполняется".

    • Примечание. Расчет процента готовности для проектных задач нижнего уровня декомпозиции (моделей пакетов работ) производится по данным документа (по объемам), а для этапов - по процентам готовности подчиненных проектных задач.

    Закладка "Доходные объемы"

    На данную закладку заносятся данные о фактически выполненных доходных объемах.

    Заполнение табличной части "Доходные объемы":

  • Кнопка Добавить — добавляет новую строку в табличную часть;

    • Для вида объемов Номенклатура:

  • Кнопка Заполнить → По текущему плану БДР — автоматически заполняет табличную часть по данным плана доходных объемов всех задач проекта;
  • Кнопка Заполнить → Остатками объемов — автоматически заполняет табличную часть остатками плановых доходных объемов на дату документа.

    • Для вида объемов Проектная продукция:

  • Кнопка Заполнить → Оборотами проектной продукции за период — автоматически заполняет табличную часть оборотами плановых доходных объемов проектной продукции за период, указанный в поле Период регистрации по:.

    • Примечание. При создании документа "Регистрация фактически выполненного объема" на основании проектной задачи данные заполняются автоматически, независимо от статуса проектной продукции.

    Для ручного ввода доступны следующие поля табличной части:

  • N – номер строки;
  • Проектная задача – проектная задача, для которой регистрируется факт выполненных доходных объемов;
  • Контрагент – контрагент–заказчик, элемент справочника Контрагенты;
  • Договор – договор с контрагентом–заказчиком, элемент справочника Договоры контрагентов;
  • Валюта – валюта договора с контрагентом–заказчиком, элемент справочника Валюты;
  • Номенклатура – номенклатура, по которой вводится факт выполнения (доступно, если учет объемов в проекте ведется по натуральным показателям), элемент справочника Номенклатура;
  • Проектная продукция – проектная продукция, по которой вводится факт выполнения (доступно, если учет объемов в проекте ведется по натуральным показателям), элемент справочника Проектная продукция;
  • Единица измерения – единица измерения номенклатуры (доступно, если учет объемов в проекте ведется по натуральным показателям), элемент справочника Упаковки;
  • Количество – количество выполненных объемов (доступно, если учет объемов в проекте ведется по натуральным показателям);
  • Стоимость – стоимость единицы номенклатуры (доступно, если учет объемов ведется по натуральным показателям);
  • Сумма – сумма выполненных объемов в денежном выражении;
  • Дата – дата, на которую будут отнесены фактически выполненные объемы;
  • Статья – статья доходов, на которую будут отнесены фактически выполненные объемы, элемент справочника Статьи доходов по проектам.

    • Заполнение табличной части "Распределение доходных объемов":

  • Кнопка Добавить – добавляет новую строку в табличную часть;
  • Кнопка Заполнить → Заполнить по умолчанию – в табличную часть добавляется одна строка, в которой автоматически заполняются реквизиты значениями из табличной части "Распределение объемов" документа Проектная задача;
  • Кнопка Заполнить → Выделить НДС – выделяет сумму НДС из выполненной суммы объемов, распределенной по подразделениям, при этом считается что выполненная сумма объемов указана с НДС. Для каждой из строк табличной части "Распределение доходных объемов" вычисляется сумма НДС по ставке, указанной в договоре, либо в константе "Ставка НДС по умолчанию" в Параметрах подсистемы PM. Вычисленные суммы НДС вычитаются из строк распределения доходных объемов и собираются в отдельной строке с признаком "НДС" в аналитике "СС/СП".

    • Важно! Поиск ставки НДС для расчетов производится в следующей последовательности (используется первое найденное значение):

  • Договор, указанный в строке доходных объемов;
  • Реквизит "Настройка распределения БДР по умолчанию" на закладке "Опции проектной модели" в карточке проекта;
  • Константа "Ставка НДС по умолчанию" в Параметрах подсистемы PM.

    • Табличная часть "Распределение доходных объемов" позволяет распределить строчки из табличной части "Доходные объемы" по следующим аналитикам:

  • Подразделение – подразделение–исполнитель, элемент справочника Подразделения;
  • Специальность – роль–исполнитель, элемент справочника Роли трудовых ресурсов;
  • СС/СП – признак "Собственные силы" / "Субподряд", элемент справочника Собственные силы/субподряд;
  • Исполнитель – элемент справочника Контрагенты / Трудовые ресурсы:
  • контрагент-подрядчик, если установлен признак "Субподряд";
  • относящийся к собственным силам контрагент или трудовой ресурс, если установлен признак "Собственные силы" и в карточке проекта на закладке "Опции проектной модели" включена опция "Использовать аналитику "Контрагент" / "Трудовой ресурс" для собственных сил";
  • Заказ/Договор – договор с контрагентом–подрядчиком, элемент справочника Договоры контрагентов;
  • Количество – количество выполненных объемов (доступно, если учет объемов в проекте ведется по натуральным показателям);
  • Сумма – сумма выполненных объемов в денежном выражении.
