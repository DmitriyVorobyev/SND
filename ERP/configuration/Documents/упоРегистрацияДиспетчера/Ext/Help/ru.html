Документ Регистрация диспетчера

Назначение

Пользователей системы может быть несколько. Сотрудников на предприятии гораздо больше, и не все из них являются пользователями. Документ "Регистрация диспетчера" предназначен для установления связи между диспетчером (пользователем) и сотрудником. С помощью документа "Регистрация диспетчера" в системе производится регистрация информации о том, кто из пользователей системы является диспетчером для того или иного сотрудника.

Диспетчер сотрудника — пользователь, который работает с системой от имени сотрудника, обладает внутри системы всеми полномочиями этого сотрудника, получает информацию, адресованную системой сотруднику, и т.д.

Документ "Регистрация диспетчера" позволяет:

  • Регистрировать и хранить в системе сведения о том, какие сотрудники работают под тем или иным пользователем;
  • Регистрировать и хранить в системе сведения о том, какие пользователи представляют в системе того или иного сотрудника.

    • Важно! Один и тот же сотрудник может работать от нескольких пользователей и несколько сотрудников могут представлять в системе одного пользователя.

    Форма объекта

    При создании документа "Регистрация диспетчера" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию - текущая дата;
  • Диспетчер (пользователь) — выбирается из справочника Пользователи.

    • Табличная часть документа "Регистрация диспетчера" заполняется назначаемыми на управление пользователю сотрудниками.

    Заполнение происходит следующим образом:

  • С помощью универсального механизма заполнения табличной части — кнопки Подбор;
  • Вручную — по кнопке Добавить на панели инструментов или с помощью клавиши Insert.

    • После проведения документа в справочнике Пользователи на закладке "Диспетчер" отображается список сотрудников, от имени которых может работать пользователь, и заполняется сотрудник по умолчанию.
