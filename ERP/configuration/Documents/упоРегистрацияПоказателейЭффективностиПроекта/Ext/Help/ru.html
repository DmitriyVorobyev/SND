Документ Регистрация значений показателей эффективности проекта

Назначение

Документ "Регистрация значений показателей эффективности проекта" предназначен для регистрации в системе текущих значений показателей эффективности инвестиций для выбранного проекта.

Важно! При помощи документа "Регистрация значений показателей эффективности проекта" можно ввести в систему значения только тех показателей, для которых установлен режим заполнения Автоматически в документе расчет эффективности.

Форма объекта

При создании документа "Регистрация значений показателей эффективности проекта" необходимо заполнить следующие реквизиты:

  • Номер — уникальный номер документа (формируется автоматически);
  • Дата — дата документа (по умолчанию подставляется текущая дата);
  • Проект — проект, для которого необходимо выполнить регистрацию показателей;
  • Период расчета — в расчете показателей эффективности используются плановые данные БДДС по проекту за указанный период;
  • Кнопка Заполнить период по сроку проекта — автоматически заполняет период расчета по плановым датам начала и завершения проекта (начало самой ранней и завершение самой поздней задач).

    • Значения показателей записываются в табличную часть документа, которая содержит следующие реквизиты:

  • Индикатор — элемент справочника Показатели проектов;
  • Значение индикатора — текущее значение показателя.

    • Для заполнения табличной части используются следующие кнопки:

  • Кнопка Добавить / Подобрать — вызвать универсальную форму подбора табличных частей документов;
  • Кнопка Заполнить — вызвать функцию автоматического заполнения табличной части (туда будут помещены все возможные показатели проекта с режимом заполнения Автоматически в документе расчет эффективности);
  • Кнопка Пересчитать — выполнить расчет значений показателей за указанный период.

    • Значения показателей эффективности инвестиций для проекта рассчитываются на основании плановых данных БДДС с учетом ставки дисконтирования.

    Важно! В качестве ставки дисконтирования используется значение элемента справочника Показатели проектов, указанного в Параметрах подсистемы PM как показатель ставки дисконтирования (группа настроек "Заявки на проекты"), зарегистрированное для проекта документом Регистрация значений показателей проектов.

    Показатели эффективности проекта:

  • Чистая приведенная стоимость NPV — разница между всеми поступлениями и выплатами, приведенными к текущему моменту времени.
    • NPV = n CFt — I
    ∑
    ──────
    (1 + r)t
    t=1
  • n — длительность жизненного цикла проекта;
  • t — период жизненного цикла проекта;
  • CFt — денежный поток в период t;
  • r — ставка дисконтирования;
  • I — начальный инвестируемый капитал.
  • Внутренняя ставка доходности IRR — процентная ставка, при которой чистая приведенная стоимость (NPV) равна 0.
    • I = n CFt
    ∑
    ──────
    (1 + IRR)t
    t=1
  • Срок окупаемости PBP — период времени, необходимый для того, чтобы доходы, генерируемые инвестициями, покрыли затраты на инвестиции.
    • PBP = n, если n CFt > I
    ∑
    t=1
  • Индекс прибыльности PI — отношение приведенной величины поступлений к приведенной величине платежей.
    • n CFt
    ∑
    ──────
    (1 + IRR)t
    PI = t=1
    ────────────
    I
  • Чистый денежный поток NCF — разность между суммами поступлений и выплат денежных средств.
    • NCF = CF+ - CF-
  • CF+ — положительный денежный поток;
  • CF- — отрицательный денежный поток.

    • Дополнительно

    Значения показателей проекта, которые были введены в систему при помощи документа, можно проанализировать при помощи отчета Анализ проектов по показателям или при помощи обработки Панель руководителя.
