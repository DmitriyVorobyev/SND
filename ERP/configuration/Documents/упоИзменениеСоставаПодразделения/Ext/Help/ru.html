Документ Изменение состава подразделения

Назначение

Документ "Изменение состава подразделения" предназначен для управления составом подразделения и ввода в систему информации о том, что те или иные роли, ранее закрепленные за одним подразделением, были переданы из этого подразделения в другое. Документ "Изменение состава подразделения" позволяет:

  • Фиксировать и хранить в системе информацию о том, какие роли в какое подразделение были перемещены.

    • Форма объекта

    При создании документа "Изменение состава подразделения" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию — текущая дата;
  • Старое подразделение — подразделение выбирается из справочника Подразделения;
  • Новое подразделение — подразделение выбирается из справочника Подразделения. Данный реквизит не требуется заполнять, если нужно только сместить роли.

    • Табличная часть документа заполняется списком ролей трудовых ресурсов следующим образом:

  • Автоматически — с помощью кнопки Заполнить;
  • Вручную — по кнопке Добавить на панели инструментов или с помощью клавиши Insert.

    • Важно! Заполнение табличной части документа вручную не рекомендуется: если в документ будут внесены роли, не принадлежащие данному подразделению, документ не проведется и будет выведено сообщение об ошибке.
