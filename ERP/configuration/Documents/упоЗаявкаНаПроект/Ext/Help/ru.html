Документ Заявка на проект

Назначение

Документ "Заявка на проект" предназначен для заведения в систему информации о планируемых проектах, которые, возможно, будут выполняться в будущем. К документу привязывается (или создается на основании документа) соответствующий элемент справочника Проекты. В дальнейшем информация из документа "Заявка на проект" и проекта (а именно, значения показателей проекта) используется для оценки возможности включения данного проекта в бизнес план на будущий период при формировании бизнес плана с помощью документа Формирование бизнес плана.

Форма объекта

При создании документа "Заявка на проект" заполняются следующие реквизиты:

  • Дата — дата документа (по умолчанию подставляется текущая дата).
  • Номер документа — уникальный номер документа (формируется автоматически).
  • Проект — проект, элемент справочника Проекты, для которого регистрируется заявка. Если проект еще не введен в систему, вместо данного реквизита заполняется реквизит "Наименование проекта". Если проект уже существует в системе, он указывается в данном реквизите, после чего реквизит "Наименование проекта" становится недоступен.
  • Наименование проекта — проект, элемент справочника Проекты, для которого регистрируется заявка. Реквизит заполняется, если проект еще не введен в систему. После проведения документа "Заявка на проект", в системе будет создан проект с указанным наименованием, который будет автоматически указан в реквизите "Проект" данного документа.

    • Примечание. Если проект вводится в систему посредством документа "Заявка на проект", значения реквизитов "Подразделение", "Портфель проектов", "Программа проектов", "Тип проекта", "Направление инвестиций", "Цель проекта", "Обоснование проекта", "Выгоды" и "Результаты проекта" будут заполнены значениями соответствующих реквизитов этого документа. Если документ "Заявка на проект" связывается с уже существующим в системе проектом, значения реквизитов этого проекта не будут изменены.

  • Подразделение — элемент справочника Подразделения. Данный реквизит указывает, каким из подразделений предприятия будет выполняться проект. Реквизит не является обязательным для заполнения.
  • Портфель проектов — элемент справочника Портфели проектов. Этот реквизит показывает, какому портфелю проектов принадлежит проект. Реквизит не является обязательным для заполнения.
  • Программа проектов — элемент справочника Программы проектов. Этот реквизит показывает, какой программе проектов принадлежит проект. Реквизит не является обязательным для заполнения.
  • Статус — статус заявки на проект (Инициировано, На рассмотрении, Отклонено, Принято, В резерве, Инвестируется).

    • Закладка "Характеристики проекта"

    На данной закладке заполняются характеристики проекта:

  • Тип проекта — элемент справочника Типы проектов. Этот реквизит показывает, к какому типу проекта принадлежит проект. Реквизит не является обязательным для заполнения.
  • Цель проекта — текстовое описание цели проекта.
  • Обоснование проекта — текстовое описание обоснования проекта.
  • Выгоды — текстовое описание ожидаемых выгод от реализации проекта.
  • Результаты проекта — текстовое описание ожидаемых результатов проекта.
  • Направление инвестиций — элемент справочника Направления инвестиций. Этот реквизит показывает, к какому направлению инвестиций относится проект. Реквизит не является обязательным для заполнения.
  • Объем финансирования — общая сумма инвестиций проекта.

    • Закладка "Связанные заявки"

    Данная закладка содержит список связанных с данной заявкой документов "Заявка на проект". Новый элемент списка добавляется при помощи кнопки Добавить.

    Закладка "Протоколы"

    Табличная часть "Протоколы" содержит информацию о фазах проекта, связанных с фазами проектных решениях (заданиях с видом "Проектное решение") и значения показателей инвестирования, зарегистрированных для связанных с фазами вех.
