Документ Согласование трудозатрат

Назначение

Документ "Согласование трудозатрат" предназначен для ввода в систему данных о согласованных затратах рабочего времени исполнителей по проектным задачам.

Важно! Для работы данного документа необходимо в Параметрах подсистемы PM в группе "Согласование трудозатрат" установить значения констант "Норма стоимости несогласованных трудозатрат" и "Период согласования трудозатрат".

Форма объекта

При создании документа "Согласование трудозатрат" необходимо заполнить следующие реквизиты:

  • Месяц / Неделя – период, за который заполняется документ (зависит от константы "Период согласования трудозатрат"). Реквизит является обязательным для заполнения.

    • Также установить требуемые отборы для заполнения табличной части документа:

  • Проект – данный отбор устанавливается, если необходимо заполнить трудозатраты исполнителей по определенному проекту, в случае, если проект не будет выбран, то заполнение документа произойдет по всем проектам. Значение выбирается из справочника Проекты.
  • Руководитель проекта – данный отбор устанавливается, если необходимо заполнить трудозатраты исполнителей по проектам, руководителем которых является выбранный сотрудник. Заполняется автоматически по данным проекта, если в документе установлен отбор по проекту. Значение выбирается из справочника Сотрудники, по умолчанию заполняется текущим сотрудником.
  • Подразделение – данный отбор устанавливается, если необходимо заполнить трудозатраты исполнителей по определенному подразделению, в случае, если подразделение не будет выбрано, то заполнение произойдет по всем подразделениям. Значение выбирается из справочника Подразделения.
  • Руководитель подразделения – данный отбор устанавливается, если необходимо заполнить трудозатраты по проектам исполнителей из подразделений, руководителем которых является выбранный сотрудник. Заполняется автоматически по данным подразделения, если в документе установлен отбор по проекту. Значение выбирается из справочника Сотрудники, по умолчанию заполняется текущим сотрудником.

    • Заполнение табличной части "Проектные задачи"

    Пользователь не может вручную добавлять строки в табличную часть документа, заполнение табличной части производится только автоматически (кнопка командной панели Заполнить). Для заполнения документа в систему должны быть введены данные о затратах рабочего времени либо документом Распределение рабочего времени за неделю либо документом Табель учета рабочего времени. Автоматическое заполнение производится по следующим правилам:

  • дата внесенных трудозатрат находится в периоде, указанном в документе;
  • данные заполняются с отбором по проекту, подразделению, руководителю проекта или подразделения, если последние указаны в шапке документа.

    • Группировку табличной части можно настроить по кнопке Настройки:

  • Выводить иерархию задач – данные табличной части будут выводиться с группировкой по проектным задачам, этапам и проектам.
  • Выводить подразделение – данные табличной части будут выводиться с группировкой по подразделениям.

    • Табличная часть "Проектные задачи" содержит реквизиты:

  • Актируемый этап – заполняется автоматически проектными задачами, по которым были введены данные по фактическим трудозатратам исполнителем.
  • Стоимость итог – заполняется автоматически итоговой согласованной стоимостью по уровню группировки.
  • Часы указанные – заполняется автоматически фактически введенными трудозатратами по проектной задаче.
  • Часы согласованные – указывается количество часов исполнителя, которые согласовывает руководитель проекта или руководитель подразделения. По умолчанию заполняется фактически введенными трудозатратами по проектной задаче.
  • Норма стоимости – заполняется автоматически значением нормы стоимости, которая указана в проектной задаче для данного исполнителя. При необходимости можно изменить.
  • Ставка – заполняется автоматически значением ставки нормы стоимости трудового ресурса.
  • Стоимость – стоимость согласованных часов. Рассчитывается автоматически относительно согласованных часов и значения ставки.
  • Часы по затратной – указывается количество несогласованных часов, которые необходимо рассчитать по размеру затратной ставки.
  • Норма стоимости (по затратной) – заполняется автоматически значением нормы стоимости, которая указана в значении константы "Норма стоимости несогласованных трудозатрат" в Параметрах подсистемы PM. При необходимости можно изменить.
  • Ставка (по затратной) – заполняется автоматически значением ставки нормы стоимости (по затратной).
  • Стоимость (по затратной) – стоимость часов по затратной ставке. Рассчитывается автоматически относительно часов по затратной и значения ставки.
  • Часы отклонены – количество отклоненных часов. Рассчитывается автоматически как разница между указанными часами и часами согласованными и часами по затратной ставке.

    • Кнопка Отправить на согласование создает задание с видом "Согласование" для согласования документа. В качестве согласующего лица указывается руковитель подразделения (если заполнены соответствующие реквизиты). При создании задания, у документа устанавлиается статус "На согласовании". По результатам согласования статус изменяется на "Согласовано", либо "Не согласовано".

    По ссылке "Даты запрета изменения данных" можно перейти в настройку дат запрета изменения данных, чтобы после ввода согласования установить дату запрета изменения данных по разделу "Трудозатраты".

    Дополнительно

    Данные, введенные в систему при помощи документов "Согласование трудозатрат", можно свести воедино и проанализировать при помощи отчета Согласованные трудозатраты.
