Документ Регистрация стоимости ресурсов

Назначение

Документ "Регистрация стоимости ресурса" предназначен для регистрации в системе информации о стоимости:

  • Номенклатуры;
  • Трудовых ресурсов;
  • Ролей трудовых ресурсов.

    • Форма объекта

    При создании документа "Регистрация стоимости ресурсов" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически.
  • Дата — по умолчанию - текущая дата.
  • Тип ресурса - выбирается тип данных (Номенклатура, Трудовой ресурс или Роль трудового ресурса);

    • В зависимости от выбранного типа ресурса в табличную часть подбираются соответствующие ресурсы. Заполнение происходит следующим образом:

  • Вручную — по кнопке Добавить на панели инструментов или с помощью клавиши Insert.
  • С помощью универсального механизма заполнения табличной части — кнопки Подобрать;

    • Помимо этого в табличной части необходимо заполнить информацию:

  • Норма стоимости — выбирается из справочника Нормы стоимости;
  • Единица времени — выбирается из справочника Едининцы измерения времени;
  • Стоимость — заполняется вручную.

    • Кнопка Заполнить позволяет заполнить "Норму стоимости", "Единицу времени" и "Стоимость" для подобранных ресурсов (устанавливается одинаковое значение для всех строк). Если для каких-то строк значения уже были заполнены, будет предложено заменить их на выбранные значения.
