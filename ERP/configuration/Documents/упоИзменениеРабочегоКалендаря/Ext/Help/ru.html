Документ Изменение рабочего календаря

Назначение

Документ "Изменение рабочего календаря" предназначен для внесения изменений в уже зарегистрированный рабочий календарь. Документ "Изменение рабочего календаря" представляет собой дополнительный список исключений, аналогичный списку исключений документа Регистрация рабочего календаря.

Форма объекта

При создании документа "Изменение рабочего календаря" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию - текущая дата;
  • Рабочий календарь – заполняется автоматически из документа-основания;
  • Календарный год – заполняется автоматически из документа-основания;
  • Документ-основание – документ Регистрация рабочего календаря, для которого необходимо внести изменения.

    • Табличная часть "Изменения в календаре" заполняется списком дней года, по которым надо внести изменения в количестве рабочих часов. Новая строка добавляется кнопкой Добавить.

    Табличная часть содержит следующие колонки:

  • N — номер строки;
  • День года — день, по которому вносится изменение количества рабочих часов;
  • Количество часов — новое количество рабочих часов за указанный день. Если количество часов равно 0, день считается нерабочим.

    • Важно! При проведении / перепроведении / отмене проведения / удалении документа "Изменение рабочего календаря", из регистра сведений Рабочие календари удаляется информация обо всех рассчитанных ранее смещениях (быстрых переходах к следующим или предыдущим датам) по календарю, указанному в документе. После этого рекомендуется выполнить оптимизацию расчета сроков для расчета новых смещений кнопкой Нужно оптимизировать расчет сроков в карточке соответствующего элемента справочника Рабочие календари. Оптимизация расчета сроков также может быть выполнена автоматически при помощи регламентного задания "Оптимизация рабочих календарей" (см. Регламентные и фоновые задания).
