Документ Соответствие стратегическим целям

Назначение

Документ "Соответствие стратегическим целям" предназначен для оценки влияния планируемых проектов на достижение стратегических целей.

Стратегические цели – не имеющие физической оценки результаты, которых стремится достичь компания в перспективе.

Форма объекта

На форме документа расположены поля и кнопки для управления настройками и формированием документа:

  • Дата – дата создания документа.
  • Номер – номер документа, формируется автоматически.
  • Программа проектов – программа проектов, элемент справочника Программы проектов, по которой будет производиться подбор проектов в табличную часть (реквизит "Программа проектов" в паспорте проекта).
  • Портфель проектов – портфель проектов, элемент справочника Портфели проектов, по которому будет производиться подбор проектов в табличную часть (реквизит "Портфель проектов" в паспорте проекта).
  • Подразделение – подразделение, элемент справочника Подразделения, по которому будет производиться подбор проектов в табличную часть (реквизит "Бизнес-единица" в паспорте проекта).
  • Цели – набор стратегических целей, элементов справочника Стратегические цели, для которых будет производиться оценка влияния планируемых проектов.
  • По весам – если опция отключена для оценки влияния будет использоваться градация Нет / Незначительное / Среднее / Сильное / Критичное, если опция включена, влияние будет оцениваться при помощи весовых коэффициентов, на основании которых будет устанавливаться один из вышеуказанных статусов.

    • Табличная часть документа заполняется следующими способами:

  • Вручную, при помощи кнопки Добавить.
  • Автоматически, с учетом настроенного отбора, при помощи кнопки Заполнить.
  • Рассчитанный балл по проектам автоматически заполнится в реквизит "Приоритет" справочника Проекты при помощи кнопки Записать баллы в приоритеты проектов.

    • В табличной части расположены колонки:

  • Проект – элемент справочника Проекты, для которого производится оценка соответствия целям.
  • [Стратегическая цель] – стратегическая цель из набора, заданного в реквизите "Цели" текущего документа.
  • [Вес] – весовой коэффициент цели, колонка отображается только при включенной опции "По весам".
  • Балл – общая итоговая оценка соответствия проекта всем указанным в документе стратегическим целям.

    • Важно! При автоматическом заполнении, в табличную часть попадают только те проекты, для которых созданы документы Заявка на проект.

    По данным табличной части автоматически строится диаграмма соответствия стратегическим целям, которая выводится в нижнюю часть документа.
