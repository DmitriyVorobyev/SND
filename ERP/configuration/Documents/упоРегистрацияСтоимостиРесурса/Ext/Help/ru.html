Документ Регистрация стоимости ресурса

Назначение

Документ "Регистрация стоимости ресурса" предназначен для регистрации в системе информации о стоимости:

  • Номенклатуры;
  • Трудовых ресурсов;
  • Ролей трудовых ресурсов.

    • Форма объекта

    При создании документа "Регистрация стоимости ресурса" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически.
  • Дата — по умолчанию - текущая дата.
  • Ресурс предприятия:
  • вначале выбирается тип данных (Номенклатура, Роли трудовых ресурсов или Трудовые ресурсы);
  • затем производится подбор конкретного ресурса из справочника.
  • Норма стоимости — выбирается из справочника Нормы стоимости.

    • Если при создании документа в поле "Ресурс предприятия" выбрать "Номенклатура", то становятся доступны следующие необходимые для заполнения реквизиты:

  • Единица измерения — выбирается из справочника Упаковки и единицы измерения;
  • Стоимость — заполняется вручную.

    • Если при создании документа в поле "Ресурс предприятия" выбрать "Роли трудовых ресурсов" или "Трудовой ресурс", то становятся доступны следующие необходимые для заполнения реквизиты:

  • Единица времени — выбирается из справочника Единицы измерения времени;
  • Стоимость — заполняется вручную.

    • Важно! Номенклатура нормируется по единицам измерения, а трудовые ресурсы и роли трудовых ресурсов — по времени их использования.
