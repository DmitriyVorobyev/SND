Документ Назначение трудовых ресурсов на проект

Назначение

Документ "Назначение трудовых ресурсов на проект" предназначен для ввода в систему предварительной информации о составе трудовых ресурсов, которые предполагается использовать для выполнения работ в рамках проекта.

Трудовые ресурсы, назначенные на проект при помощи документа, отображаются в карточке проекта на закладке "Участники" (табличная часть "Команда проекта"). 

Детализация окончательной информации о распределении трудовых ресурсов на задачи проекта производится при помощи документа Назначение трудовых ресурсов на проектную задачу.

Форма объекта

При создании документа "Назначение трудовых ресурсов на проект" необходимо заполнить следующие реквизиты:

  • Номер документа — уникальный номер документа (формируется автоматически);
  • Дата — дата документа (по умолчанию подставляется текущая дата);
  • Проект — элемент справочника Проекты, указывает на тот проект, для которого производится назначение или освобождение трудовых ресурсов.

    • Табличные части документа "Назначение трудовых ресурсов на проект" разнесены по двум закладкам.

    Закладка "Назначаемые ресурсы"

    На этой закладке расположена табличная часть, в которой перечисляются трудовые ресурсы, назначаемые на выполнение работ в рамках проекта. Табличная часть содержит следующие реквизиты:

  • Трудовой ресурс — элемент справочника Трудовые ресурсы, указывает на тот трудовой ресурс, который привлекается к выполнению работ;
  • Подразделение – элемент справочника Подразделения, указывает принадлежность трудового ресурса какому-либо подразделению.

    • Табличную часть можно заполнить следующими способами:

  • Кнопка Добавить — добавляет новую строку в табличную часть;
  • Кнопка Подобрать — открывает универсальную форму подбора табличной части.

    • Закладка "Освобождаемые ресурсы"

    На этой закладке расположена табличная часть, в которой перечисляются трудовые ресурсы, освобождаемые от выполнения работ в рамках проекта. Табличная часть содержит следующие реквизиты:

  • Трудовой ресурс — элемент справочника Трудовые ресурсы, указывает на тот трудовой ресурс, который освобождается от выполнения работ.

    • Важно! Освободить от выполнения работ можно только тот трудовой ресурс, который ранее был назначен на выполнение работ в рамках именно этого проекта.

    Табличную часть можно заполнить следующими способами:

  • Кнопка Добавить — добавляет новую строку в табличную часть;
  • Кнопка Подобрать — открывает универсальную форму подбора табличной части;
  • Кнопка Заполнить — заполняет табличную часть всеми трудовыми ресурсами, назначенными на проект ранее.

    • Примечание. Для заполнения табличной части рекомендуется использовать кнопку Заполнить.
