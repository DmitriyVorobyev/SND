Документ Синхронизация фактических движений денежных средств

Назначение

Документ "Синхронизация фактических движений денежных средств" предназначен для регистрации в системе данных о фактических поступлениях и выплатах по нескольким проектным задачам и проектам одновременно.

Документ может использоваться:

  • Для регистрации фактических ДДС вручную.
  • При интеграции с "1С:Бухгалтерия предприятия 3.0", для отражения в системе PM оборотов, перенесенных при помощи специальной обработки "Синхронизация с 1С:РМ" (входит в виде расширения в поставку и в поставку обновления продукта "1С:PM Управление проектами КОРП").

    • Важно! Интеграция с "1С:Бухгалтерия предприятия 3.0" работает только в "1С:PM Управление проектами КОРП". В "1С:ERP+PM Управление проектной организацией 2" интеграции нет.

    Важно! При переносе данных обработка создает по одному документу "Синхронизация фактических движений денежных средств" на каждый день имеющихся оборотов за выбранный период.

    Важно! При повторном переносе данных за тот же период программа удалит ранее загруженные данные и внесенные изменения из табличной части документа и загрузит текущие обороты.

    Форма объекта

    Реквизиты документа:

  • Номер документа – уникальный номер документа (формируется автоматически);
  • Дата – дата документа (по умолчанию подставляется текущая дата);
  • Комментарий – текстовый комментарий, при переносе данных из "1С:Бухгалтерия предприятия" заполняется автоматически: "Загружено автоматически из базы "адрес_базы" в "дата_загрузки"".

    • Табличная часть "Фактические движения денежных средств"

    При интеграции с "1С:Бухгалтерия предприятия" табличная часть "Фактические движения денежных средств" заполняется автоматически. Данные, при необходимости, можно дозаполнить вручную.

    При ручном заполнении документа или необходимости добавления новых строк в документ, можно воспользоваться кнопками:

  • Добавить – добавляет новую пустую строку в документ;
  • Подобрать
  • По статьям ДДС;
  • По контрагентам;
  • Параметры подбора – направление движения ДС (Поступление денежных средств / Выплата денежных средств).

    • Табличная часть "Фактические движения денежных средств" содержит следующие колонки:

  • N – номер строки;
  • Проект – проект, по проектным задачам которого производится фиксация фактических движений денежных средств. Заполняется автоматически при указании проектной задачи;
  • Проектная задача – проектная задача, на которую распределяются переносимые обороты. Заполняется:
  • Автоматически, при переносе данных из "1С:Бухгалтерия предприятия" если был заполнен реквизит "Проектная задача по умолчанию для ДДС" в соответствующих элементах справочников Контрагенты, Договоры контрагентов, Статьи движения денежных средств или настройке распределения оборотов по кор. счету на проектную задачу в обработке "Синхронизация с 1С:РМ" в базе "1С:Бухгалтерия предприятия";
  • Вручную, при ручном заполнении документа или если не было произведено автоматическое заполнение.
  • Контрагент – элемент справочника Контрагенты, при переносе данных из "1С:Бухгалтерия предприятия" заполняется значение, указанное в платежном документе;
  • Договор – элемент справочника Договоры контрагентов, при переносе данных из "1С:Бухгалтерия предприятия" заполняется значение, указанное в платежном документе;
  • Статья ДДС – элемент справочника Статьи движения денежных средств, при переносе данных из "1С:Бухгалтерия предприятия" заполняется значение, указанное в платежном документе;
  • Направление – направление движения денежных средств;
  • Дата движения – дата, на которую отнесены фактические ДДС, при переносе данных из "1С:Бухгалтерия предприятия" заполняется значение, указанное в платежном документе;
  • Валюта – валюта платежа;
  • Сумма – сумма платежа в управленческой валюте;
  • Валютная сумма – сумма платежа в валюте;
  • Номер п/д – номер платежного документа, при переносе данных из "1С:Бухгалтерия предприятия" заполняется автоматически;
  • Дата п/д – дата платежного документа, при переносе данных из "1С:Бухгалтерия предприятия" заполняется автоматически;
  • Ссылка в источнике – ссылка на платежный документ в "1С:Бухгалтерия предприятия", заполняется автоматически при переносе данных;
  • Комментарий – текстовое поле, заполняется вручную.
    • Важно! Проверка заполнения данных, используемых для автозаполнения проектной задачи в документе "Синхронизация фактических движений денежных средств" идет по приоритету:
  • Реквизит "Проектная задача по умолчанию для ДДС" в элементе справочника Договоры контрагентов;
  • Реквизит "Проектная задача по умолчанию для ДДС" в элементе справочника Контрагенты;
  • Реквизит "Проектная задача по умолчанию для ДДС" в элементе справочника Статьи движения денежных средств;
  • Значение в табличной части "Все обороты по кор. счету на задачу" обработки "Синхронизация с 1С:РМ" в базе "1С:Бухгалтерия предприятия 3.0".

    • Дополнительно

    Информация, введенная в систему посредством документа "Синхронизация фактических движений денежных средств", используется при формировании отчетов: План-фактный анализ ДДС, Скользящий БДДС проекта, Скользящий БДР, Объемы, БДДС.
