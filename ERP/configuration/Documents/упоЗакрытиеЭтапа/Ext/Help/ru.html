Документ Закрытие этапа

Назначение

Документ предназначен для закрытия этапов работ проекта и изменения статуса проектной задачи с текущего на "Закрыта". Документ автоматически устанавливает процент готовности задач в статусе "Закрыта" равным 100%.

Документ регистрирует статус "Закрыта" для проектных задач любого типа: "Веха", "Модель пакета работ", "Этап". В случае закрытия задачи с типом "Этап", все подчиненные по СДР этапу задачи так же переводятся в статус "Закрыта".

При включении в Параметрах подсистемы PM на закладке "Основные параметры" константы "Строгий контроль изменения закрытых этапов", установка проектным задачам статуса "Закрыта" запрещает отражение фактических данных (трудочасов, выполненных объемов, доходов, расходов, поступлений и выплат) по ним.

При включении в Параметрах подсистемы PM на закладке "Оценка исполнителей и подрядчиков" константы "Включить использование оценки исполнителей и подрядчиков", документ позволяет оценивать исполнителей (трудовые ресурсы) и подрядчиков (контрагенты).

Для работы с документом в системе существуют следующие роли профилей групп доступа:

  • Добавление изменение закрытия этапа (без отмены проведения) – дает пользователю право на работу с документом (добавление, изменение, проведение и т.д.), кроме отмены проведения документа. Включена в стандартные профили групп доступа "Руководитель проектного офиса", "Руководитель проектов и/или подразделений (с доступом к финансовой информации) " и "Руководитель проектов и/или подразделений (без доступа к финансовой информации)";
  • Право на отмену закрытия этапа – дает пользователю право на отмену проведения документа. Включена в стандартный профиль групп доступа "Руководитель проектного офиса".

    • Форма объекта

    К основным реквизитам документа "Закрытие этапа " относятся следующие:

  • Номер документа – формируется автоматически при записи документа;
  • Дата – формируется автоматически, по умолчанию в реквизит подставляется текущая системная дата;
  • Проект – проект, задача которого подлежит закрытию. Поле заполняется автоматически корневым проектом задачи указанной в реквизите "Этап";
  • Этап – проектная задача подлежащая закрытию. Выбирается подбором из иерархической структуры проекта;
  • Комментарий – произвольный текст;
  • Сложность – значение показателя, выбранного в качестве показателя сложности в Параметрах подсистемы PM на закладке "Оценка исполнителей и подрядчиков", зарегистрированное для закрываемой проектной задачи. Реквизит отображается только при включении опции "Включить использование оценки исполнителей и подрядчиков" в Параметрах подсистемы PM.

    • Табличная часть "Оценки исполнителей и подрядчиков"

    Табличная часть "Оценки исполнителей и подрядчиков" служит для оценивания трудовых ресурсов и подрядчиков (контрагентов), участвовавших в выполнении проектной задачи, при выполнении процедуры закрытия этой задачи. В документе используется два вида оценок: КТУ (для исполнителей) и КПЭ (для исполнителей и подрядчиков). Переключение между видами оценок производится при помощи соответствующих кнопок КТУ/КПЭ.

    Важно! Табличная часть "Оценки исполнителей и подрядчиков" доступна только при включении опции "Включить использование оценки исполнителей и подрядчиков" в Параметрах подсистемы PM.

    Для заполнения табличной части используется кнопка Заполнить.

    Важно! Табличная часть заполняется списком трудовых ресурсов, по которым списывались часы на закрываемую проектную задачу и все задачи, подчиненные ей, и/или подрядчиков (контрагентов), указанных в документах Регистрация фактических движений денежных средств по закрываемой проектной задаче и всем задачам, подчиненным ей. Для подрядчиков и соответствующих ролей трудовых ресурсов должны быть созданы настройки оценки (записи в регистре сведений Настройки оценки ролей исполнителей и подрядчиков, создаются в Параметрах подсистемы PM).

    Оценка КТУ

    Табличная часть содержит следующие колонки:

  • Трудовой ресурс/подрядчик – трудовой ресурс, по которому списывались часы на закрываемую проектную задачу и все задачи, подчиненные ей / контрагент, указанный в документах Регистрация фактических движений денежных средств по закрываемой проектной задаче и всем задачам, подчиненным ей;
  • Роль – роль трудового ресурса, указанная в проектной задаче (для контрагента указывается значение "Подрядчик");
  • Трудозатраты – фактические трудозатраты исполнителей, зарегистрированные документом Табель учета рабочего времени/Распределение рабочего времени за неделю;
  • % трудозатрат – процент трудозатрат исполнителя от общего количества фактических трудозатрат;
  • КТУ – обобщенная количественная оценка трудового вклада исполнителя в общие результаты работы. Заполняется вручную;
  • Средняя оценка – средняя оценка КПЭ.

    • Оценка КПЭ

    Табличная часть содержит следующие колонки:

  • Трудовой ресурс/подрядчик – трудовой ресурс, по которому списывались часы на закрываемую проектную задачу и все задачи, подчиненные ей / контрагент, указанный в документах Регистрация фактических движений денежных средств по закрываемой проектной задаче и всем задачам, подчиненным ей;
  • Роль – роль трудового ресурса, указанная в проектной задаче (для контрагента указывается значение "Подрядчик");
  • Колонки с названиями, значением и весом оценок – колонки с оценками трудовых ресурсов/подрядчиков и весовыми коэффициентами. Список колонок зависит от настроек оценки исполнителей и подрядчиков, созданных в Параметрах подсистемы PM.
  • Средняя – среднее значение оценки, рассчитывается автоматически на основе значений оценок и их весовых коэффициентов.
  • Средняя = (Значение _1 * Вес_1 + Значение _2 * Вес_2 + … + Значение _N * Вес_ N)/( Вес_ 1 + Вес_ 2 + … + Вес_ N)

    • Важно! Оценка дается по закрываемой задаче, но в регистр Оценка исполнителей подрядчиков записывается оценка и для всех подчиненных задач. При этом для оценок исполнителей/подрядчиков по подчиненным задачам в регистре устанавливается признак "Косвенная". Если подчиненные задачи оценивались отдельно, то главной считается новейшая по дате оценка без признака "Косвенная".
