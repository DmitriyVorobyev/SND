Документ Регистрация владельца ресурсов

Назначение

Документ "Регистрация владельца ресурсов" предназначен для регистрации в системе факта перехода того или иного трудового ресурса в ведение конкретного сотрудника.

Владелец ресурса — сотрудник предприятия, в ведении которого находится ресурс, то есть, тот, кто получает информацию, адресованную системой трудовому ресурсу, и вводит в систему информацию, адресованную трудовым ресурсом системе.

Форма объекта

При создании документа "Регистрация владельца ресурсов" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически.
  • Дата — по умолчанию - текущая дата.
  • Сотрудник — из справочника Сотрудники выбирается сотрудник, которому переходит в ведение тот или иной ресурс.

    • Табличная часть "Сотрудник является владельцем следующих ресурсов" заполняется следующим образом:

  • С помощью универсального механизма заполнения табличной части — кнопки Подобрать;
  • Вручную — по кнопке Добавить на панели инструментов или с помощью клавиши Insert.

    • Важно! В один момент времени одним и тем же ресурсом может владеть только один сотрудник.
