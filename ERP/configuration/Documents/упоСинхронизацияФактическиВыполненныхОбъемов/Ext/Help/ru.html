Документ Синхронизация фактически выполненных объемов

Назначение

Документ "Синхронизация фактически выполненных объемов" предназначен для регистрации фактически выполненных объемов в процессе выполнения проекта.

В отличие от документа Регистрация фактически выполненного объема, документ "Синхронизация фактически выполненных объемов" позволяет регистрировать факт выполнения объемов сразу по нескольким проектам.

Форма объекта

Закладка "Доходные объемы"

На данную закладку заносятся данные о фактически выполненных доходных объемах.

Информация в табличную часть "Доходные объемы" документа вводится при помощи кнопки Добавить.

Табличная часть содержит поля:

  • N – номер строки;
  • Проект – проект, элемент справочника Проекты, в состав которого входит проектная задача, для которой регистрируется факт объемов. Заполняется автоматически при выборе проектной задачи;
  • Проектная задача – проектная задача, для которой регистрируется факт выполненных доходных объемов;
  • Номенклатура – номенклатура, по которой вводится факт выполнения, элемент справочника Номенклатура;
  • Количество – количество выполненных объемов;
  • Единица измерения – единица измерения номенклатуры, элемент справочника Упаковки;
  • Стоимость – стоимость единицы номенклатуры;
  • Сумма – сумма выполненных объемов в денежном выражении;
  • Валюта – валюта договора с контрагентом–заказчиком, элемент справочника Валюты;
  • Контрагент – контрагент–заказчик, элемент справочника Контрагенты;
  • Договор – договор с контрагентом–заказчиком, элемент справочника Договоры контрагентов;
  • Подразделение – подразделение–исполнитель, элемент справочника Подразделения. По умолчанию заполняется значением из карточки проекта (реквизит "Подразделение доходов" на закладке "Значения по умолчанию");
  • Специальность – роль–исполнитель, элемент справочника Роли трудовых ресурсов. По умолчанию заполняется значением из карточки проекта (реквизит "Роль доходов" на закладке "Значения по умолчанию");
  • СС/СП – признак "Собственные силы" / "Субподряд", элемент справочника Собственные силы/субподряд. По умолчанию заполняется значением из карточки роли-исполнителя (реквизит "СС/СП");
  • Исполнитель – контрагент-подрядчик, элемент справочника Контрагенты / собственный трудовой ресурс, элемент справочника Трудовые ресурсы.
  • Заказ/Договор – договор с контрагентом–подрядчиком, элемент справочника Договоры контрагентов;
  • Дата – дата, на которую будут отнесены фактически выполненные объемы;
  • Статья – статья доходов, на которую будут отнесены фактически выполненные объемы, элемент справочника Статьи доходов по проектам.
