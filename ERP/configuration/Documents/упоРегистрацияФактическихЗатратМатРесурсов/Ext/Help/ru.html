Документ Регистрация затрат материальных ресурсов

Назначение

Для каждой проектной задачи существует свой план материальных затрат, но в процессе выполнения проекта фактические затраты материальных ресурсов могут расходиться с плановыми. Документ "Регистрация затрат материальных ресурсов" предназначен для регистрации фактических затрат на использование материальных ресурсов в процессе выполнения проекта.

Форма объекта

При создании документа "Регистрация затрат материальных ресурсов" необходимо заполнить следующие реквизиты:

  • Номер документа — уникальный номер документа (формируется автоматически);
  • Дата — дата документа (по умолчанию подставляется текущая дата);
  • Проект — элемент справочника Проекты, заполняется автоматически, в зависимости от выбранной проектной задачи;
  • Проектная задача — документ Проектная задача, по которой регистрируются затраты материальных ресурсов;
  • Включить затраты на мат. ресурсы в расходную часть БДР проекта – если флаг установлен, то регистрируемые затраты материальных ресурсов будут учтены бюджете доходов и расходов как фактические расходы.

    • Заполнение табличной части "Затраты материальных ресурсов по проектным задачам"

    Данные о фактических затратах материальных ресурсов заносятся в табличную часть документа. Табличную часть можно заполнить следующими способами:

  • Вручную (кнопка командной панели Добавить);
  • Через универсальную форму подбора (кнопка командной панели Подобрать);
  • Автоматическое заполнение по данным документа-основания Проектная задача (при создании документа на основании проектной задачи, либо с помощью кнопки командной панели Заполнить → По документу-основанию).

    • Стоимость использования материальных ресурсов можно вводить как вручную, так и при помощи ранее заданной с помощью документа Регистрация стоимости ресурса или Регистрация стоимости ресурсов нормированной стоимости использования ресурсов:

  • Норма стоимости — элемент справочника Нормы стоимости, используется для автоматического расчета стоимости материальных ресурсов, перечисленных в табличной части. Расчет стоимости производится при помощи кнопки Пересчитать по норме.

    • Табличная часть включает в себя следующие поля:

  • Ресурс – материальный ресурс, использованный в процессе выполнения проектной задачи, элемент справочника Номенклатура;
  • Количество – количество использованных материальных ресурсов;
  • Единица нормирования – единица нормирования ресурса, элемент справочника Упаковки и единицы измерения, либо Единицы измерения времени;
  • Стоимость – стоимость единицы материального ресурса;
  • Общая стоимость – общая стоимость использованных материальных ресурсов;
  • Вид операции – используется в качестве дополнительного аналитического разреза при анализе, элемент справочника Виды операций.

    • Если был установлен флаг "Включить затраты на мат. ресурсы в расходную часть БДР проекта", то в табличной части будут дополнительно доступны поля:

  • Статья – статья, на которую будут отнесены затраты на использование материального ресурса, элемент справочника Статьи затрат по проектам;
  • Дата начисления – дата, на которую будут отнесены фактические расходы;
  • Контрагент – контрагент–поставщик, элемент справочника Контрагенты;
  • Договор – договор с контрагентом-поставщиком, элемент справочника Договоры контрагентов;
  • Валюта – валюта расходов, элемент справочника Валюты. При заполнении табличной части вручную по умолчанию выбирается валюта управленческого учета, установленная в Параметрах подсистемы PM. При заполнении табличной части по данным документа-основания (при создании документа на основании проектной задачи, либо с помощью кнопки командной панели Заполнить → По документу-основанию), выбирается валюта, указанная в плане затрат материальных ресурсов.

    • Заполнение табличной части "Распределение затрат"

  • Кнопка Добавить – добавляет новую строку в табличную часть;
  • Кнопка Заполнить → Заполнить по умолчанию – в табличную часть добавляется одна строка, в которой автоматически заполняются реквизиты значениями из табличной части "Материальные ресурсы" документа Проектная задача;
  • Кнопка Заполнить → Выделить НДС – выделяет сумму НДС из стоимости использованных материальных ресурсов, распределенной по подразделениям, при этом считается что стоимость использованных материальных ресурсов указана с НДС. Для каждой из строк табличной части "Распределение затрат" вычисляется сумма НДС по ставке, указанной в договоре (при установленном флаге "Включить затраты на мат. ресурсы в расходную часть БДР проекта"), либо в константе "Ставка НДС по умолчанию" в Параметрах подсистемы PM. Вычисленные суммы НДС вычитаются из строк распределения использованных материальных ресурсов и собираются в отдельной строке с признаком "НДС" в аналитике "СС/СП".

    • Важно! Поиск ставки НДС для расчетов производится в следующей последовательности (используется первое найденное значение):

  • Договор, указанный в строке табличной части "Затраты материальных ресурсов по проектным задачам";
  • Реквизит "Настройка распределения БДР по умолчанию" на закладке "Опции проектной модели" в карточке проекта;
  • Константа "Ставка НДС по умолчанию" в Параметрах подсистемы PM.

    • Табличная часть "Распределение доходных объемов" позволяет распределить строчки из табличной части "Затраты материальных ресурсов по проектным задачам" по следующим аналитикам:

  • Подразделение – элемент справочника Подразделения;
  • Специальность – элемент справочника Роли трудовых ресурсов;
  • СС/СП – признак собственные силы / субподряд, элемент справочника Собственные силы/субподряд;
  • Количество – количество использованных материальных ресурсов;
  • Сумма – сумма затрат в денежном выражении.

    • Дополнительно

    Информация, введенная в систему посредством документа "Регистрация затрат материальных ресурсов", используется при формировании отчета Затраты материальных ресурсов (план-факт), а также План-фактный анализ БДР, План-фактный анализ БДР по подразделениям, Скользящий БДР, Объемы, БДДС, Скользящий БДР проекта, Анализ БДР по БДДС, если был установлен флаг "Включить затраты на мат. ресурсы в расходную часть БДР проекта".
