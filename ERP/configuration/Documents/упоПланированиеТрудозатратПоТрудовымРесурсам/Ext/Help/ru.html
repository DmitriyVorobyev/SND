Документ Планирование трудозатрат по трудовым ресурсам

Назначение

С помощью документа "Планирование трудозатрат по трудовым ресурсам" можно выполнять задачи:

  • Анализировать список проектных задач, ожидающих назначения исполнителей;
  • Анализировать список исполнителей, не назначенных на проектные задачи;
  • Назначать трудовые ресурсы на выполнение проектных задач;
  • Анализировать текущую загрузку трудовых ресурсов (исполнителей ПЗ) по проектам, проектным задачам;
  • Анализировать наличие перегрузок исполнителей (в табличном виде и в виде диаграммы (гистограммы));
  • Выравнивать загрузку трудовых ресурсов;
  • Выстраивать равномерную загрузку исполнителей;
  • Анализировать фактические данные трудозатрат по трудовым ресурсам.

    • Форму списка документов можно открыть из раздела "Трудозатраты проектов".

    Важно! Документ "Планирование трудозатрат по трудовым ресурсам" работает только с Окончательным уровнем планирования, т.е. с данными трудозатрат по ролям по Окончательному уровню планирования и данными трудозатрат по трудовым ресурсам.

    Важно! Пользователь имеет право на изменение проектных задач, если он является диспетчером руководителя проекта или руководителя проектной задачи. Проверка не производится, если в Параметрах подсистемы PM включена опция "Отключить разграничение доступа пользователя к проектным документам".

    Форма объекта

    На командной панели расположены поля и кнопки для управления настройками, формирования и поведения документа:

  • Кнопка Провести и закрыть – провести и закрыть документ;
  • Кнопка Записать – сохранить изменения в документе, но не проводить его;
  • Кнопка Провести – провести документ;
  • Кнопка Перейти → Анализ изменений по документу – открыть отчет Анализ изменений по документу "Планирование трудозатрат по трудовым ресурсам". Отчет позволяет получить информацию о первоначальных трудозатратах трудовых ресурсов (по данным проекта, если они есть), об измененных трудозатратах, внесенных в табличную часть документа, а также вывести отклонения, полученные в результате внесения новых данных. Отчет отображает изменения, внесенные при последней корректировке табличной части документа, промежуточные значения отчет не отображает;
  • Кнопка Заполнить – заполнить документ в соответствии с выбранными настройками периода и отбором по ролям и проектам;
  • Кнопка Диаграмма Ганта – показать/скрыть диаграмму Ганта, на которую можно вывести текущие и новые (по скорректированным данным документа) сроки проектной задачи с отбором по трудовому ресурсу;
  • Кнопка Диаграмма – показать/скрыть диаграмму для графического отображения трудозатрат и наличия простоев и перегрузок по трудовым ресурсам за период с отбором по трудовому ресурсу;

    • Вкладка "Основное"

    На вкладке "Основное" расположены поля и опции для настройки формирования данных в табличной части документа:

  • Номер – формируется автоматически;
  • Дата – дата создания документа (по умолчанию – текущая дата);
  • Кнопка Период с … по … – выбор периода времени, для которого формируется документ (выбранный период отображается прямо на кнопке);

    • Отборы

  • Подразделения – в данном поле можно указать отбор только тех трудозатрат, которые относятся к ролям, зарегистрированным в указанных подразделениях;
  • Роли – в данном поле можно указать отбор только тех трудозатрат, которые относятся к указанным ролям;
  • Проекты – в данном поле можно указать список проектов, по которым нужно провести отбор трудозатрат;

    • Настройки

  • Порядок группировок – выбор порядка группировки данных:
  • Трудовой ресурс / Задача (используется по умолчанию);
  • Трудовой ресурс / Роль / Проект / Задача;
  • Проект / Задача / Роль / Трудовой ресурс.
  • Не записывать сроки задач – если опция отключена, при проведении документа сроки проектных задач будут изменены в соответствии с распределением загрузки трудовых ресурсов (новые даты начала и завершения проектной задачи можно увидеть в колонках "Сроки по загрузке ТР"). Если опция включена, при проведении документа сроки задач изменяться не будут.

    • Вкладка "Трудозатраты"

    На вкладке "Трудозатраты" расположены кнопки для работы с табличной частью документа и табличная часть, в которой отображаются данные по трудозатратам трудовых ресурсов в разрезе проектных задач.

  • Кнопка Установить запись для всех строк, на которые есть права редактирования – установить флаг "Записать" для всех строк табличной части, на редактирование которых у текущего пользователя есть права. В этом случае все внесенные изменения отразятся в регистрах системы и будут доступны для анализа в отчетах;
  • Кнопка Отменить запись для всех строк, на которые есть права редактирования – снять флаг "Записать" у всех строк табличной части, на редактирование которых у текущего пользователя есть права. В этом случае данные сохранятся в документе, но не попадут в регистры системы и будут доступны для анализа только из самого документа;
  • Кнопка Свернуть уровни – сворачивает строки табличной части документа до верхнего уровня;
  • Кнопка Развернуть уровни – разворачивает строки табличной части документа до нижнего уровня;
  • Кнопка Настройка колонок → Факт – показать/скрыть колонки с отображением фактических трудозатрат трудового ресурса, введенных с помощью документов Табели учета рабочего времени или Распределение рабочего времени за неделю;
  • Кнопка Настройка колонок → По ролям – показать/скрыть колонку с отображением плановых трудозатрат роли трудового ресурса;
  • Кнопка Настройка колонок → Тек. значения – показать/скрыть колонки с отображением текущих плановых трудозатрат трудового ресурса;
  • Кнопка Настройка колонок → План за периодом – показать/скрыть колонки ("До периода", "За периодом") с отображением плановых трудозатрат до и после выбранного периода;
  • Кнопка Настройка колонок → Тек. сроки – показать/скрыть колонки ("Дата нач.", "Дата зав.") с отображением текущих сроков начала и завершения проектной задачи;
  • Кнопка Настройка колонок → Тек. сроки (ДГ) – показать/скрыть отображение текущих сроков проектной задачи на диаграмме Ганта;
  • Кнопка Настройка колонок → Выходные – показать/скрыть колонки с датами, выпадающими на выходные и нерабочие дни по установленному в Параметрах подсистемы PM "Рабочему календарю по умолчанию";
  • Уровень группировок – позволяет выбрать одну из настроек уровня группировок строк в табличной части документа. Доступные варианты настроек уровня группировок строк зависят от выбранного порядка группировки:
  • для порядка группировки "Трудовой ресурс / Задача" – Трудовые ресурсы, Задачи;
  • для порядка группировки "Трудовой ресурс / Роль / Проект / Задача" – Трудовые ресурсы, Роли, Подразделения, Задачи;
  • для порядка группировки "Проект / Задача / Роль / Трудовой ресурс" – Проекты, Задачи, Роли, Трудовые ресурсы;

    • Табличная часть заполняется по кнопке Заполнить.

    Важно!

  • Проектные задачи в статусе "Закрыта" или "Завершена", на которые не были назначены трудовые ресурсы, не попадают в документ.
  • Проектные задачи в статусе "Закрыта" или "Завершена" с назначенными трудовыми ресурсами попадают в документ без возможности редактирования. Фон таких задач закрашен серым цветом.

    • Для каждой задачи отображаются ее новые (по данным загрузки трудовых ресурсов) и текущие сроки (текущей версии проекта), а также данные трудозатрат за периодом документа:

  • До периода – количество плановых трудозатрат по проектной задаче до периода документа;
  • За периодом – количество плановых трудозатрат по проектной задаче после периода документа;

    • за все время проектной задачи:

  • Факт – фактические трудозатраты;
  • Роль – плановые трудозатраты по роли;
  • Нов. – плановые трудозатраты, распределенные на исполнителя, с учетом новых данных (введенных текущим документом);
  • Тек. – плановые трудозатраты, распределенные на исполнителя;

    • и за период документа (период планирования):

  • Факт – фактические трудозатраты;
  • Роль – плановые трудозатраты по роли;
  • Назначено ч. – плановые трудозатраты, распределенные на исполнителя, с учетом новых данных (введенных текущим документом);
  • Тек. – плановые трудозатраты, распределенные на исполнителя;
  • Откл. – отклонение новых плановых трудозатрат от текущих.

    • Трудозатраты детализируются по дням и по видам данных:

  • Факт – фактические трудозатраты за день;
  • Нов. – плановые трудозатраты за день по документу;
  • Тек. – плановые текущие трудозатраты за день (исполнителя);
  • Откл. – отклонение новых плановых трудозатрат от текущих.

    • Важно! В колонках "Нов." и "Тек." при порядке группировок "Трудовой ресурс / Задача" или "Трудовой ресурс / Роль / Проект / Задача" на верхнем уровне иерархии перегрузка трудового ресурса выделяется красным цветом. Перегрузкой трудового ресурса на конкретную дату считается превышение общей плановой загрузки этого ресурса по задачам всех проектов количества плановых трудочасов по рабочему календарю, указанному в Параметрах подсистемы PM как "Рабочий календарь по умолчанию".

    Также в табличную часть выводится:

  • Остаток загрузки по ролям – остатки плановых трудозатрат ролей трудовых ресурсов по Окончательному уровню планирования, не распределенные по исполнителям;
  • Трудовые ресурсы, по которым в указанном периоде нет загрузки (исполнители, не назначенные на проектные задачи). Фон таких задач и ресурсов закрашен серым цветом.

    • Важно! При отключении проверки разграничений доступа опцией "Отключить разграничение доступа пользователя к проектным документам", задачи для которых пользователь не является диспетчером руководителя проекта или руководителя проектной задачи, будут недоступны для редактирования. Такие строки выделяются белым фоном, затемненной иконкой объекта (, , ) и серым текстом.

    Назначить трудовой ресурс исполнителем проектной задачи можно:

  • путем перетаскивания проектной задачи, у которой нет исполнителя на трудовой ресурс (при порядке группировок "Проект / Задача / Роль / Трудовой ресурс" перетаскивается строка "Остаток по роли");
  • путем перетаскивания трудового ресурса на проектную задачу (при порядке группировок "Проект / Задача / Роль / Трудовой ресурс" трудовой ресурс перетаскивается на строку "Остаток по роли");
  • двойным щелчком левой кнопкой мыши по проектной задаче без трудовых ресурсов вызвать контекстное меню и выбрать пункт "Назначить ресурс";
  • двойным щелчком левой кнопкой мыши по полю "Нет назначенной ПЗ" вызвать контекстное меню и выбрать пункт "Назначить на задачу" (при порядке группировок "Трудовой ресурс / Задача" и "Трудовой ресурс / Роль / Проект / Задача");
  • двойным щелчком левой кнопкой мыши по трудовому ресурсу вызвать контекстное меню и выбрать пункт "Назначить на задачу" (при порядке группировок "Проект / Задача / Роль / Трудовой ресурс").

    • Важно! Назначить трудовой ресурс на проектную задачу можно только в том случае, если для этой задачи имеется план трудозатрат по ролям, которые может выполнять данный трудовой ресурс.

    При назначении трудового ресурса на проектную задачу выводится диалог, в котором можно настроить параметры назначения:

  • Добавить в очередь – если опция включена, загрузка трудового ресурса будет распределена по проектной задаче, начиная с первого свободного дня после окончания загрузки по уже назначенным задачам, с полной загрузкой дня в соответствии с настройками основного рабочего календаря. Прочие параметры назначения будут недоступны. Если опция отключена, загрузка трудового ресурса будет распределена по проектной задаче в соответствии с указанными параметрами.
  • Профиль распределения – элемент справочника Профили распределения трудозатрат. Реквизит указывает, как именно будут распределены трудозатраты по времени, и какая загрузка трудового ресурса потребуется для выполнения работ по проектной задаче. По умолчанию выбирается значение, указанное в проектной задаче для соответствующей роли;
  • Дата старта – дата, с которой начнется распределение загрузки данного трудового ресурса. Дата начала распределения не может быть меньше даты начала проектной задачи;
  • Минимальная дата старта – дата старта проектной задачи, минимальная дата, с которой возможно распределение загрузки данного трудового ресурса;
  • Количество часов – плановая загрузка трудового ресурса в часах. Рассчитывается на основании количества часов по роли, указанного в проектной задаче, и доли трудозатрат;
  • Количество часов по роли за период – количество часов по роли, которое можно распределить на трудовой ресурс за период документа без перегрузки;
  • Количество часов по роли за все время – количество часов по роли за весь период проектной задачи;
  • Распределять на период планирования – если опция включена, трудозатраты будут распределены в пределах периода документа, независимо от количества. Если опция отключена, период документа может быть автоматически увеличен, если распределяемое количество трудозатрат превышает допустимое количество трудочасов за выбранный период (с учетом профиля распределения).
  • Доля трудозатрат, % – указывается доля участия трудового ресурса в данной проектной задаче. Рассчитывается на основании количества часов по роли, указанного в проектной задаче, и количества часов, распределяемого по трудовому ресурсу.

    • Назначение трудового ресурса производится кнопкой Назначить.

    Для отмены назначения необходимо дважды щелкнуть левой кнопкой мыши на строке проектной задачи (при порядке группировок "Трудовой ресурс / Задача" и "Трудовой ресурс / Роль / Проект / Задача") или трудового ресурса (при порядке группировок "Проект / Задача / Роль / Трудовой ресурс)" и в контекстном меню выбрать пункт "Отменить назначение".

    Важно! При повторном назначении трудового ресурса на задачу, новое значение трудозатрат добавляется к уже распределенному и происходит перераспределение трудозатрат в соответствии с новым (выбранным при повторном назначении) профилем распределения.

    Для внесения / корректировки плановых трудозатрат по дням нужно ввести необходимое количество часов трудозатрат в колонку "Нов." выбранного дня.

    При необходимости, можно полностью перенести запланированную загрузку роли по задаче на день вперед / назад. Для этого необходимо щелкнуть правой кнопкой мыши на строке и в контекстном меню выбрать пункт "Сдвинуть на период вправо" / "Сдвинуть на период влево".

    Важно! Корректировка плановых трудозатрат может привести к изменению сроков проектной задачи. Новые даты начала и завершения проектной задачи можно увидеть в колонках "Сроки по загрузке ТР". Изменения вступят в силу после проведения документа, если нажата кнопка Записывать сроки задач.

    Также в строках табличной части возможно вручную установить флаг "Записать" для записи данных в регистры системы по отдельным проектным задачам.

    Важно! Если документом "Планирование трудозатрат по трудовым ресурсам" производилось назначение трудовых ресурсов на проектную задачу, то после проведения документа, назначенные исполнители будут отображаться в документе Проектная задача на закладке "Исполнители", с вариантом распределения трудозатрат "Ручное распределение" и документом "Планирование трудозатрат по трудовым ресурсам" в качестве документа ручного распределения.

    Важно! Если документом "Планирование трудозатрат по трудовым ресурсам" производилась корректировка трудозатрат исполнителей, уже назначенных на проектные задачи, то после проведения документа, варианты распределения трудозатрат этих трудовых ресурсов, независимо от установленных ранее значений, будут изменены на "Ручное распределение".

    Диаграмма Ганта

    Диаграмма Ганта, на которой можно вывести текущие и новые (по скорректированным данным документа) сроки проектной задачи с отбором по трудовому ресурсу. Отображается при нажатой кнопке Диаграмма Ганта.

  • Диаграмма по ресурсу – в данном поле можно указать трудовой ресурс, по которому будет производиться отбор данных для отображения на диаграмме Ганта.

    • Диаграмма

    Диаграмма для графического отображения трудозатрат и наличия простоев и перегрузок по трудовым ресурсам за период документа. Отображается при нажатой кнопке Диаграмма.

  • Диаграмма по ресурсу – в данном поле можно указать трудовой ресурс, по которому будет производиться отбор данных для отображения на диаграмме.

    • Важно! При определении перегрузок и простоев на диаграмме учитывается количество плановых трудочасов на дату по рабочему календарю, указанному в Параметрах подсистемы PM как "Рабочий календарь по умолчанию", а также количество трудовых ресурсов в документе. Пример: используется производственный календарь с восьмичасовым рабочим днем и в документе установлен отбор по роли, которую могут выполнять пять трудовых ресурсов, таким образом, на диаграмме количество доступных для загрузки трудочасов за день будет равно сорока часам. При установленном отборе по трудовому ресурсу, количество плановых трудочасов на дату берется по одному ресурсу.

    Двойным щелчком левой кнопки мыши по столбцу дня на диаграмме можно перейти к этому дню в табличной части. Если при этом включен отбор по трудовому ресурсу, переход осуществляется с учетом отбора.
