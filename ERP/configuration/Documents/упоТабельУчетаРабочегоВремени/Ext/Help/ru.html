Документ Табель учета рабочего времени

Назначение

Документ "Табель учета рабочего времени" предназначен для ввода в систему данных о распределении рабочего времени, затраченного трудовым ресурсом в течение дня, по проектным и внепроектным задачам, а также для ввода в систему данных о потерянном (затраченном непродуктивно) рабочем времени.

В зависимости от выбранного значения настройки "Распределять рабочее время" в Параметрах подсистемы PM, в табеле будут отображаться только проектные задачи, только задания (с видом "Поручение") или все вместе.

Важно! При отключенной в Параметрах подсистемы PM константе "Разрешить списание часов на проектные задачи проекта в статусе "Остановлен"" в документе недоступно списание фактических трудозатрат по задачам и заданиям проекта в статусе "Остановлен", начиная с даты регистрации документа Остановка проектных работ.

Важно! При отключенной в Параметрах подсистемы PM константе "Разрешить списание рабочего времени по закрытым и завершенным задачам и закрытым заданиям" в документе недоступно списание фактических трудозатрат по проектным задачам в статусе "Завершена" и "Закрыта" и заданиям в статусе "Закрыто".

Форма объекта

При заполнении формы элемента документа "Табель учета рабочего времени" необходимо заполнить следующие реквизиты:

  • День – дата, за которую заполняется табель, по умолчанию подставляется текущая дата, можно изменить. Система не позволяет проводить документы за будущие дни, такие документы можно только записать;
  • Ресурс – сотрудник, по которому вводится табель, значение выбирается из справочника Трудовые ресурсы.

    • Важно! При выборе и/или изменении реквизита "Трудовой ресурс" производится проверка: имеет ли текущий пользователь системы полномочия владельца для выбранного трудового ресурса. В случае если текущий пользователь не имеет таких полномочий, значение реквизита либо исключается из списка выбора (при выборе значения из списка), либо очищается (при ручном изменении значения).

    Документ разделен на две области:

  • Слева – указывается список задач / заданий (с видом "Поручение"), над которыми трудовой ресурс непосредственно трудился в этот день и их длительность выполнения;
  • Справа - представлены четыре закладки:
  • На закладке "Проектные задачи" отображается список проектных задач и поручений, привязанных к проектным задачам;
  • На закладке "Внепроектные задачи" отображаются списки внепроектных задач и поручений, не привязанных к проектным задачам;
  • На закладке "Потери времени" отображается список причин потерь рабочего времени;
  • На закладке "Дополнительно" расположены настройки автосохранения документа.

    • Закладка "Проектные задачи"

    Закладка "Проектные задачи" заполняется автоматически проектными задачами и/или привязанными к проектным задачам заданиями (с видом "Поручение"), в зависимости от настройки распределения рабочего времени в Параметрах подсистемы PM (константа "Распределять рабочее время").

    Проектные задачи включаются в табличную часть, если выполняются следующие условия:

  • Дата табеля учета рабочего времени (реквизит "День") больше или равна дате начала проектной задачи;
  • Дата табеля учета рабочего времени (реквизит "День") больше или равна дате назначения трудового ресурса на проектную задачу (значения даты в колонке "Период" регистра сведений Выделенные трудовые ресурсы).

    • Пользователь не может вручную добавлять строки на закладку "Проектные задачи", заполнение табличной части производится автоматически при заполнении реквизитов "День" и "Ресурс".

  • Кнопка Заполнить – перезаполняет (обновляет) перечень проектных задач и/или поручений.
  • Кнопка Доп. информация – выводит дополнительную информацию по проектной задаче / поручению:
  • РП – руководитель проекта, к которому относится задача / поручение;
  • Дата начала – плановая дата начала задачи / поручения;
  • Дата завершения – плановая дата завершения задачи / поручения;
  • Длительность (план) – количество плановых трудозатрат по роли трудового ресурса по проектной задаче;
  • Длительность (факт) – количество фактических трудозатрат по роли трудового ресурса по проектной задаче;
  • Подразделение – подразделение, в состав которого включена роль трудового ресурса;
  • Роль – роль трудового ресурса;
  • Детальное планирование  – признак детального планирования трудового ресурса. Флаг устанавливается автоматически, если на дату табеля учета рабочего времени (реквизит "День") трудовой ресурс был запланирован с использованием обработки Оперативная загрузка специалистов или документа Планирование трудозатрат по трудовым ресурсам.
    При установленном флаге задача выделяется жирным шрифтом.
    Доступен отбор по проектным задачам, у которых установлен флаг.
  • Кнопка Упорядочить список по возрастанию – упорядочивает список проектных задач / поручений по возрастанию по выделенному реквизиту;
  • Кнопка Упорядочить список по убыванию – упорядочивает список проектных задач / поручений по убыванию по выделенному реквизиту.

    • Автоматическое заполнение производится в соответствие со следующими правилами:

  • отчетный день попадает в период, указанный в качестве срока проектной задачи или задания;
  • выбранный трудовой ресурс был назначен на выполнение проектной задачи или задания.

    • Закладка "Внепроектные задачи"

    На закладке "Внепроектные задачи" расположены две табличные части.

    Верхняя табличная часть заполняется элементами справочника Внепроектные задачи.

  • Кнопка Создать – позволяет создать новый элемент справочника Внепроектные задачи.
  • Кнопка Создать группу – позволяет создать новую группу в справочнике Внепроектные задачи.
  • Кнопка Создать новый элемент копированием текущего - позволяет создать новый элемент справочника Внепроектные задачи путем копирования выделенного элемента.
  • Кнопка Найти – открывает форму поиска данных в списках.
  • Кнопка Отменить поиск – отменяет результаты поиска. Кнопка становится активной, если к списку уже применялись какие-либо условия поиска.

    • Нижняя табличная часть при помощи кнопки Заполнить поручения заполняется списком поручений, не привязанных к проектным задачам. Заполнение производится в соответствие со следующими правилами:

  • отчетный день попадает в период, указанный в качестве срока поручения (если сроки в поручении не установлены, оно доступно для списания трудозатрат на любую дату);
  • выбранный трудовой ресурс был назначен исполнителем поручения;
  • поручение находится в статусе "Выдано", "Выполняется", "Уточняется".

    • Закладка "Потери времени"

    Табличная часть "Потери времени" заполняется элементами справочника Причины потерь рабочего времени.

  • Кнопка Создать – позволяет создать новый элемент справочника Причины потерь рабочего времени.
  • Кнопка Создать группу – позволяет создать новую группу в справочнике Причины потерь рабочего времени.
  • Кнопка Создать новый элемент копированием текущего - позволяет создать новый элемент справочника Причины потерь рабочего времени путем копирования выделенного элемента.
  • Кнопка Найти – открывает форму поиска данных в списках.
  • Кнопка Отменить поиск – отменяет результаты поиска. Кнопка становится активной, если к списку уже применялись какие-либо условия поиска.

    • Закладка "Дополнительно"

    Позволяет настроить автосохранение документа через указанный в секундах интервал времени.

    Заполнение табличной части документа

    Ручной ввод данных в табличную часть для документа "Табель учета рабочего времени" не предполагается.

    Заполнение табличной части данными производится перетаскиванием строки, выбранной на закладках "Проектные задачи", "Внепроектные задачи" или "Потери времени" на поле табличной части.

    После перетаскивания строки пользователь вручную указывает время в часах, затраченное на задачу в течение рабочего дня, в ячейке "Длительность" (при этом автоматически изменяется значение в ячейке "Окончание"), либо время начала и окончания работы над задачей в ячейках "Начало" и "Окончание" (при этом значение в ячейке "Длительность" рассчитывается автоматически). Строки в табличной части идут последовательно, т.е. следующая задача начинается сразу после завершения предыдущей.

    Дополнительно можно указать:

  • Вид операции – выбор значения из справочника Виды операций.
  • Для проектных задач и связанных с ними поручений доступны виды операций, для которых указан раздел учета рабочего времени "Проектная задача" (по умолчанию используется вид операции "Явка");

    • Важно! Вид операции заполнится автоматически из документа Проектная задача, если в документе на закладке "Параметры" заполнен реквизит "Вид операции" и в виде операции в реквизите "Раздел учета рабочего времени" установлено значение "Проектная задача".

  • Для внепроектных задач доступны виды операций, для которых указан раздел учета рабочего времени "Внепроектная задача" (по умолчанию используется вид операции, указанный в элементе справочника Внепроектные задачи);
  • Для поручений, не привязанных к проектным задачам:
  • Если поручение на привязано ни к какому объекту базы, доступны виды операций, для которых указан раздел учета рабочего времени "Внепроектная задача";
  • Если поручение привязано к элементу справочника Внепроектные задачи, доступны виды операций, для которых указан раздел учета рабочего времени "Внепроектная задача" (по умолчанию используется вид операции, указанный в объекте поручения);
  • Если поручение привязано к элементу справочника Причины потерь рабочего времени, доступны виды операций, для которых указан раздел учета рабочего времени "Потеря рабочего времени";
  • Если поручение привязано к прочим объектам базы, доступны виды операций, для которых не указан раздел учета рабочего времени.
  • Для причин потерь рабочего времени доступны виды операций, для которых указан раздел учета рабочего времени "Потеря рабочего времени" (по умолчанию используется вид операции, указанный в элементе справочника Причины потерь рабочего времени).
  • Комментарий – текстовое поле для расшифровок выполненных работ.

    • На командной панели табличной части расположены следующие кнопки:

  • Кнопка Добавить – добавляет новую строку в табличную часть. В добавленной строке пользователь не может вручную выбрать Проект и Задачу, т.к. предполагается перетаскивание строки с закладок "Проектные задачи", "Внепроектные задачи" или "Потери времени".
  • Кнопка Обед – предназначена для быстрого ввода времени, затраченного на обеденный перерыв.
  • Кнопки Переместить вверх / Переместить вниз – позволяют перемещать вверх / вниз выделенную строку в табличной части, при этом задача сдвигается на более раннее / позднее время в течение рабочего дня.
  • Кнопка Учитывать тек. время – если кнопка нажата, при добавлении новой строки в табличную часть, для нее в ячейках "Начало" и "Окончание" будет автоматически указано текущее системное время. При этом будут изменены значения в ячейках "Окончание" и "Длительность" у предыдущей задачи (если она есть).
  • Кнопка Заполнить по оперативной загрузке – позволяет автоматически заполнить табличную часть документа на основании данных обработки Оперативная загрузка специалистов по выбранному трудовому ресурсу на выбранный рабочий день.

    • Важно! Стоимость фактических трудозатрат по Предварительному и Окончательному уровням планирования рассчитывается следующим образом:

  • Предварительный – стоимость трудозатрат рассчитывается в зависимости от настройки расчета стоимости фактических трудозатрат по ролям в Параметрах подсистемы PM (константа "Расчет стоимости фактических трудозатрат по ролям" в группе "Настройки распределения рабочего времени"), с учетом зарегистрированных документами Регистрация стоимости ресурса / Регистрация стоимости ресурсов ставок трудового ресурса или роли.
  • Окончательный - по умолчанию стоимость трудозатрат рассчитывается в зависимости от ставки трудового ресурса. Если на дату регистрации фактических трудозатрат ставка трудового ресурса не найдена, то расчет ведется по ставке роли.

    • Рассчитанную фактическую стоимость трудозатрат можно проанализировать отчетами Затраты трудовых ресурсов (план-факт), План-фактный анализ использования ресурсов, Освоенный объем по трудозатратам при выборе в настройках соответствующего уровня планирования.

    Анализ использования рабочего времени

    Данные, введенные в систему при помощи документов "Табель учета рабочего времени", можно свести воедино и проанализировать при помощи следующих отчетов:

  • Затраты трудовых ресурсов (план-факт);
  • Использование рабочего времени;
  • План-фактный анализ использования ресурсов;
  • Освоенный объем по трудозатратам;
  • Трудозатраты по уровням планирования.
