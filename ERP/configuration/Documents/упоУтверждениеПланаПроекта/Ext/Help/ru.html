Документ Утверждение плана проекта

Назначение

Жизненный цикл проекта состоит из ряда последовательных стадий: Инициация проекта → Утверждение проекта → Старт (запуск) проекта → Выполнение проекта → Остановка проекта → Возобновление проекта → Завершение проекта. Документ "Утверждение плана проекта" переводит проект из статуса "Запланирован" в состояние "Утвержден" и отражает факт согласования и утверждения календарно-ресурсного плана проекта.

В процессе проведения документа в системе фиксируется базовый план проекта, который в дальнейшем используется при анализе течения и результатов проекта. В базовый план входят: содержание проекта (проектные задачи и проектные вехи), расписание проекта (календарные сроки проектных задач и вех) и ресурсы проекта (на уровне ролей трудовых ресурсов).

Важно! Документ "Утверждение плана проекта" для одного и того же проекта может быть введен только один раз.

Документом "Утверждение плана проекта" можно утвердить календарно-ресурсный план проекта, который находится в состоянии "Запланирован". Рекомендуется вводить этот документ в режиме ввода на основании, основанием служит документ Регистрация проекта.

Форма объекта

При создании документа "Утверждение плана проекта" необходимо заполнить следующие реквизиты:

  • Номер документа – формируется автоматически при записи документа;
  • Дата – по умолчанию текущая дата;
  • Проект – элемент справочника Проекты, при вводе на основании данное поле заполняется автоматически;
  • Документ-основание – в данное поле автоматически вписывается документ Регистрация проекта, на основании которого был введен документ "Утверждение плана проекта".
  • Комментарий – произвольный текст.
