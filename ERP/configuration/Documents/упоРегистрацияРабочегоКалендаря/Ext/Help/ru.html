Документ Регистрация рабочего календаря

Назначение

Документ "Регистрация рабочего календаря" предназначен для регистрации в системе рабочих календарей с целью "разметки" года на рабочие дни. Для каждого дня года определяется рабочее количество часов. Как правило, в системе регистрируются календари с продолжительностью один год.

Документ "Регистрация рабочего календаря" позволяет:

  • Создавать и хранить в системе информацию о рабочих календарях.

    • Форма объекта

    При создании документа "Регистрация рабочего календаря" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию - текущая дата;
  • Рабочий календарь — выбирается из справочника Рабочие календари;
  • Календарный год — выбирается год, для которого регистрируется данный рабочий календарь;
  • Настройка календаря — из справочника Настройки рабочих календарей выбирается та настройка, на основании которой будет генерироваться данный рабочий календарь.

    • На закладке "Исключения" табличная часть заполняется списком тех дней года, для которых количество рабочих часов отличается от базовой настройки данного рабочего календаря. Новая строка добавляется кнопкой Добавить.

    Табличная часть содержит следующие колонки:

  • N — номер строки;
  • День — день, для которого количество рабочих часов отличается от базовой настройки данного рабочего календаря;
  • Количество часов — количество рабочих часов за указанный день. Если количество часов равно 0, день считается нерабочим.

    • Важно! На один и тот же год в системе может быть зарегистрирован только один рабочий календарь. При попытке вторичной регистрации рабочего календаря на тот же самый год проведение документа блокируется и выдается сообщение об ошибке.

    Важно! При проведении / перепроведении / отмене проведения / удалении документа "Регистрация рабочего календаря", из регистра сведений Рабочие календари удаляется информация обо всех рассчитанных ранее смещениях (быстрых переходах к следующим или предыдущим датам) по календарю, указанному в документе. После этого рекомендуется выполнить оптимизацию расчета сроков для расчета новых смещений кнопкой Нужно оптимизировать расчет сроков в карточке соответствующего элемента справочника Рабочие календари. Оптимизация расчета сроков также может быть выполнена автоматически при помощи регламентного задания "Оптимизация рабочих календарей" (см. Регламентные и фоновые задания).
