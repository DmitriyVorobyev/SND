Документ Завершение проекта

Назначение

Жизненный цикл проекта состоит из ряда последовательных стадий: Инициация проекта → Планирование проекта ­→ Старт проекта (запуск проекта) → Выполнение проекта → Завершение проекта → Возобновление проекта. Документ "Завершение проекта" предназначен для фиксирования в системе факта окончания проектных работ.

Документом "Завершение проекта" можно закрыть проект, который находится в состоянии "Запланирован", "Утвержден", "Выполняется" или "Остановлен". Рекомендуется вводить этот документ в режиме ввода на основании, основанием служат документы Регистрация проекта, Утверждение плана проекта, Старт проектных работ, Остановка проектных работ, Возобновление проекта в зависимости от этапа, на котором проект закрывается.

Форма объекта

При создании документа "Завершение проекта" необходимо заполнить следующие реквизиты:

  • Номер документа – формируется автоматически при записи документа;
  • Дата – по умолчанию текущая дата;
  • Проект – элемент справочника Проекты, при вводе на основании данное поле заполняется автоматически;
  • Документ-основание – в данное поле автоматически вписывается документ, на основании которого был введен документ "Завершение проекта".
  • Комментарий – произвольный текст.
