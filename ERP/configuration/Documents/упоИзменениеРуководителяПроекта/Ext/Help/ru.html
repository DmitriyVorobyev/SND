Документ Изменение руководителя (куратора) проекта

Назначение

Документ "Изменение руководителя (куратора) проекта" предназначен для фиксации в системе факта смены руководителя или куратора проекта (лиц, ответственных за планирование и контроль выполнения проекта).

Если для каждого руководителя (куратора) проекта в системе настроен доступ только к тем проектам, руководителем (куратором) которых он является, то при изменении руководителя (куратора) проекта необходимо изменить настройки доступа к проектам. Настройка доступа к проектам описана в справке к документу Регистрация проекта.

Форма объекта

К основным реквизитам документа "Изменение руководителя (куратора) проекта" относятся следующие:

  • Номер документа – формируется автоматически при записи документа;
  • Дата – формируется автоматически, по умолчанию в реквизит подставляется текущая дата;
  • Проект – проект, в котором меняется руководитель, элемент справочника Проекты;
  • Руководитель проекта – из справочника Сотрудники выбирается сотрудник, который назначается новым руководителем выбранного проекта;
  • Куратор проекта – из справочника Сотрудники выбирается сотрудник, который назначается новым куратором выбранного проекта;
  • Комментарий – произвольный текст.
