Документ Регистрация значений показателей проектов

Назначение

Документ "Регистрация значений показателей проектов" предназначен для регистрации в системе текущих значений показателей выбранного проекта или проектной задачи. При помощи этого документа руководитель проекта может вносить в систему данные об изменениях в ключевых показателях проекта.

Важно! При помощи документа "Регистрация значений показателей проектов" можно ввести в систему значения только тех показателей, для которых установлен режим заполнения Вручную или Автоматически в документе.

Форма объекта

При создании документа "Регистрация значений показателей проектов" необходимо заполнить следующие реквизиты:

  • Номер документа — уникальный номер документа (формируется автоматически);
  • Дата — дата документа (по умолчанию подставляется текущая дата);
  • Проект — проект, для которого необходимо выполнить регистрацию показателей.
  • Проектная задача – проектная задача, для которой необходимо выполнить регистрацию показателей (заполняется только если необходимо зарегистрировать значения показателей для проектной задачи).

    • Важно! Если в документе "Регистрация значений показателей проектов" заполнен реквизит "Проектная задача", значения показателей будут зарегистрированы для проектной задачи, а не для проекта.

    Значения показателей записываются в табличную часть документа. Табличная часть содержит следующие реквизиты:

  • Индикатор — элемент справочника Показатели проектов;
  • Значение индикатора — текущее значение показателя.

    • В табличной части доступны следующие действия:

  • Кнопка Добавить — добавляет новую строку в табличную часть;
  • Кнопка Подобрать — открывает универсальную форму подбора табличной части;
  • Кнопка Заполнить — автоматически заполняет табличную часть всеми показателями проекта с режимом заполнения Автоматически в документе и Вручную. При этом учитывается принадлежность показателей:
  • если в документе заполнен реквизит "Проектная задача" — в табличную часть попадают показатели с принадлежностью Общий и Только для проектной задачи;
  • если в документе не заполнен реквизит "Проектная задача" — в табличную часть попадают показатели с принадлежностью Общий и Только для проекта;
  • Кнопка Пересчитать — выполняет расчет значений показателей, для которых установлен режим расчета Автоматически в документе.

    • Дополнительно

    Значения показателей проекта, которые были введены в систему при помощи документа, можно проанализировать при помощи отчета Анализ проектов по показателям или при помощи обработки Панель руководителя.
