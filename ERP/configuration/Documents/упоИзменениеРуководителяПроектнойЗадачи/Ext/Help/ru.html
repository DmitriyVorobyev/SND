Документ Изменение руководителя проектной задачи

Назначение

Документ "Изменение руководителя проектной задачи" предназначен для фиксации в системе факта смены руководителя проектной задачи.

Форма объекта

При создании документа "Изменение руководителя проектной задачи" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию — текущая дата;
  • Проект — элемент справочника Проекты, указывает на тот проект, которому принадлежит проектная задача;
  • Проектная задача — проектная задача, для которой производится смена руководителя;
  • Руководитель проектной задачи — из справочника Сотрудники выбирается сотрудник, который назначается новым руководителем выбранной проектной задачи. Если необходимо просто произвести смещение текущего руководителя проектной задачи, то это поле остается пустым.

    • Важно! Изменение руководителя проектной задачи автоматически происходит и для всех подчиненных данной проектной задаче проектных задач.

    Важно! При смещении текущего руководителя проектной задачи, новым руководителем проектной задачи становится руководитель проекта.
