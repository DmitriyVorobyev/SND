Документ Синхронизация фактических трудозатрат

Назначение

Документ "Синхронизация фактических трудозатрат" предназначен для ввода в систему данных о затратах рабочего времени, затраченного трудовым ресурсом по проектным и внепроектным задачам, а также данных о потерянном рабочем времени.

Документ предназначен для регистрации фактических трудозатрат в целях интеграции с внешними системами или для переноса данных о фактических трудозатратах при переходе со старых версий системы.

Форма объекта

Реквизиты документа:

  • Номер документа – уникальный номер документа (формируется автоматически);
  • Дата – дата документа, по умолчанию подставляется текущая дата.
  • Проверен – формальный признак проверки перенесенных данных. На движения документа не влияет.
  • Комментарий – текстовый комментарий.

    • Вкладка "Проектные задачи"

    При ручном заполнении документа или необходимости добавления новых строк в табличную часть документа, можно воспользоваться кнопками:

  • Добавить – добавляет новую пустую строку в табличную часть документа.
  • Заполнить → Окончательный уровелнь по предварительному – заполняет данные по количеству часов по окончательному уровню по заполненным данным по количеству часов по предварительному уровню.

    • Табличная часть "Проектные задачи" используется для отражения фактических трудозатрат по проектным задачам, содержит следующие колонки:

  • N – номер строки;
  • Дата – дата, на которую производится фиксация фактических трудозатрат;
  • Проект – проект, по проектным задачам которого производится фиксация фактических трудозатрат. Заполняется автоматически при указании проектной задачи;
  • Проектная задача – проектная задача, по которой производится фиксация фактических трудозатрат;
  • Задание – задание, по которому производится фиксация фактических трудозатрат. Элемент справочника Задания;
  • Ресурс – трудовой ресурс, по которому производится фиксация фактических трудозатрат. Элемент справочника Трудовые ресурсы;
  • Роль – роль трудового ресурса, по которой производится фиксация фактических трудозатрат. Элемент справочника Роли трудовых ресурсов;
  • Подразделени – подразделение, по которому производится фиксация фактических трудозатрат. Элемент справочника Подразделения;
  • Уровень предварительный
  • Количество – количество фактических трудозатрат в часах по уровню предварительный;
  • Сумма – стоимость фактических трудозатрат по уровню предварительный;
  • Уровень окончательный
  • Количество – количество фактических трудозатрат в часах по уровню окончательный;
  • Сумма – стоимость фактических трудозатрат по уровню окончательный;
  • Вид операции – вид операции, по которому производится фиксация фактических трудозатрат;
  • Расшифровка – произвольный текст, описание сути выполняемой задачи.

    • Вкладка "Потери времени"

    При ручном заполнении документа или необходимости добавления новых строк в табличную часть документа, можно воспользоваться кнопкой:

  • Добавить – добавляет новую пустую строку в табличную часть документа.

    • Табличная часть "Потери времени" используется для отражения потерь рабочего времени трудовыми ресурсами, содержит следующие колонки:

  • Дата – дата, на которую производится фиксация фактических трудозатрат;
  • Причина – заполняется элементами справочника Причины потерь рабочего времени;
  • Ресурс – трудовой ресурс, по которому производится фиксация потерь рабочего времени. Элемент справочника Трудовые ресурсы;
  • Роль – роль трудового ресурса, по которой производится фиксация потерь рабочего времени. Элемент справочника Роли трудовых ресурсов;
  • Подразделение – подразделение, по которому производится фиксация потерь рабочего времени. Элемент справочника Подразделения;
  • Количество – количество потерь рабочего времени в часах;
  • Вид операции – вид операции, по которому производится фиксация потерь рабочего времени;
  • Расшифровка – произвольный текст, описание сути выполняемой задачи.

    • Примечание. При проведении документа "Синхронизация фактических трудозатрат" для отражения фактических трудозатрат используется вид операции, явно указанный в документе. Выбирается из справочника Виды операций.

    Дополнительно

    После проведения документа данные табличных частей попадают в регистры сведений: Использование рабочего времени, Факт трудозатрат, Факт трудозатрат по дням.

    Данные, зарегистрированные документом, используются при формировании отчетов: Затраты трудовых ресурсов (план-факт), Использование рабочего времени, План-фактный анализ использования ресурсов, Освоенный объем по трудозатратам, Трудозатраты по уровням планирования.
