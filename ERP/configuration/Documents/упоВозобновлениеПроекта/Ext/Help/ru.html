Документ Возобновление проекта

Назначение

Жизненный цикл проекта состоит из ряда последовательных стадий: Инициация проекта → Планирование проекта ­→ Старт проекта (запуск проекта) → Выполнение проекта → Завершение проекта → Возобновление проекта. Документ "Возобновление проекта" предназначен для фиксирования в системе факта того, что работы по выполнению данного проекта возобновляются, то есть, производится перевод проекта из статуса "Остановлен" или "Завершен" в статус "Выполняется".

Документом "Возобновление проекта" можно возобновить работы по проекту, который находится в состоянии "Остановлен" или "Завершен". Рекомендуется вводить этот документ в режиме ввода на основании, основанием служат документы Остановка проектных работ или Завершение проекта.

Форма объекта

При создании документа "Возобновление проекта" необходимо заполнить следующие реквизиты:

  • Номер документа – формируется автоматически при записи документа;
  • Дата – по умолчанию текущая дата;
  • Проект – элемент справочника Проекты, при вводе на основании данное поле заполняется автоматически;
  • Документ-основание – в данное поле автоматически вписывается документ Остановка проектных работ или Завершение проекта, на основании которого был введен документ "Возобновление проекта".
  • Комментарий – произвольный текст.
