Документ Остановка проектных работ

Назначение

Жизненный цикл проекта состоит из ряда последовательных стадий: Инициация проекта → Планирование проекта ­→ Старт проекта (запуск проекта) → Выполнение проекта → Завершение проекта → Возобновление проекта. Документ "Остановка проектных работ" предназначен для фиксирования в системе факта того, что работы по выполнению данного проекта временно приостановлены, то есть, производится перевод проекта из статуса "Выполняется" в статус "Остановлен".

Документом "Остановка проектных работ" можно остановить работы по проекту, который находится в состоянии "Выполняется". Рекомендуется вводить этот документ в режиме ввода на основании, основанием служат документы Старт проектных работ или Возобновление проекта.

Форма объекта

При создании документа "Остановка проектных работ" необходимо заполнить следующие реквизиты:

  • Номер документа – формируется автоматически при записи документа;
  • Дата – по умолчанию текущая дата;
  • Проект – элемент справочника Проекты, при вводе на основании данное поле заполняется автоматически;
  • Документ-основание – в данное поле автоматически вписывается документ Старт проектных работ или Возобновление проекта, на основании которого был введен документ "Остановка проектных работ".
  • Комментарий – произвольный текст.
