Документ Формирование бизнес плана

Назначение

Документ "Формирование бизнес плана" предназначен для оценки возможности включения проекта в бизнес-план на будущий период.

Форма объекта

При создании документа "Формирование бизнес плана" заполняются следующие реквизиты:

  • Дата — дата создания документа.
  • Номер — уникальный номер документа, формируется автоматически.
  • Кнопка Создать Бизнес-план — создает элемент справочника Портфели проектов, а также создает и регистрирует в системе связанный с портфелем элемент справочника Проекты. Созданным элементам по умолчанию присваивается наименование "Формирование бизнес-плана". Структура портфеля заполняется проектами из табличной части "Проекты бизнес-плана" документа "Формирование бизнес плана". После создания портфеля проекта и проекта кнопка заменяется ссылкой на созданный портфель и кнопку Открыть структуру проекта.
  • Программа проектов — программа проектов, элемент справочника Программы проектов. Значение основного показателя инвестирования программы определяет лимит инвестирования, по которому осуществляется подбор проектов в бизнес-план. Реквизит является обязательным для заполнения.
  • Портфель проектов — элемент справочника Портфели проектов, по которому будет производиться подбор проектов в табличную часть "Проекты бизнес-плана" (реквизит "Портфель проектов" в паспорте проекта). Если реквизит не заполнен, в табличную часть подбираются все проекты, для которых созданы заявки на проект.
  • Подразделение — элемент справочника Подразделения, по которому будет производиться подбор в табличную часть "Проекты бизнес-плана" (реквизит "Бизнес-единица" в паспорте проекта). Реквизит не является обязательным для заполнения.

    • Важно! При заполнении документа, в табличную часть попадают только те проекты, для которых созданы документы Заявка на проект.

    Табличная часть документа заполняется автоматически, с учетом настроенного отбора, при помощи кнопки Заполнить проекты.

    В табличной части расположены колонки:

  • Проект — элемент справочника Проекты, по которому ведется оценка включения в бизнес-план.
  • Ранг — оценочная очередность включения проекта в бизнес-план.
  • Балл — показатель балла проекта для бизнес-плана, элемент справочника Показатели проектов, указанный в Параметрах подсистемы PM (группа "Заявки на проекты"). Заполняется значением, зарегистрированным для проекта.
  • [Значение показателя] — основной показатель инвестирования выбранной программы проектов.
  • Статус — статус связанного с проектом документа Заявка на проект.
  • Портфель — элемент справочника Портфели проектов, к которому относится проект. Заполняется из карточки проекта.
  • Подразделение — ответственное за проект подразделение. Заполняется из карточки проекта.
  • Проекты предшественники — список формируется на основании закладки "Связанные заявки" документа Заявка на проект. Если проект включен в бизнес-план, а какой-либо из предшественников – нет, ячейка будет выделена красным цветом.

    • В табличной части расположены строки:

  • Лимит по инвестициям — значение основного показателя, зарегистрированное для программы проектов. Используется для подбора проектов, не превышающих значения лимита.
  • Остаток лимита — разница между лимитом инвестиций и общей инвестиционной стоимостью проектов бизнес-плана. Выделяется красным цветом при превышении лимита.
  • Проекты бизнес-плана — общая инвестиционная стоимость всех проектов, включаемых в бизнес-план. Выделяются зеленым цветом проекты, укладывающиеся в лимит.
  • Заявки на проекты в резерве — общая инвестиционная стоимость всех проектов, находящихся в резерве.
  • Всего по заявкам — общая инвестиционная стоимость всех проектов табличной части.

    • Включение проекта в бизнес-план:

  • Кнопка Поднять ранг проекта — перемещает вверх выбранный проект в очередности включения проекта в бизнес-план.
  • Кнопка Опустить ранг проекта — перемещает вниз выбранный проект в очередности включения проекта в бизнес-план.
