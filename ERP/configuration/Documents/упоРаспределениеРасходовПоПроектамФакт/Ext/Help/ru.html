Документ Распределение расходов по проектам

Назначение

Документ предназначен для распределения фактических расходов, зарегистрированных на проектных задачах проектов с компонентой "Общефирменная деятельность", на проектные задачи проектов с компонентой "Проект" за указанный период.

Важно! Значение "Общефирменная деятельность" выбирается в реквизите "Компонент" на закладке "Параметры" справочника Проекты.

Примечание. Распределение может производиться по разным Способам распределения расходов для каждой статьи расходов.

Статья затрат при распределении между проектами не меняется. Сумма расходов относится на проектную задачу и подразделение пропорционально базам распределения, указанным в Способе распределения расходов статьи затрат. Способ распределения расходов указывается в справочнике Статьи затрат в реквизите "Способ распределения расходов по проектам". В документе "Распределение расходов по проектам" по умолчанию заполняется способ распределения расходов из статьи затрат, при необходимости его можно изменить в документе.

Форма объекта

На командной панели расположены кнопки для управления настройками формирования и поведения документа:

  • Провести и закрыть – провести и закрыть документ;
  • Записать – сохранить изменения в документе, но не проводить его;
  • Провести – провести документ;
  • Кнопка Отчеты – открывает отчет Результат распределения, который можно сформировать по текущему документу;
  • Кнопка Отчеты → Движения документа – открывает отчет о движениях документа по регистрам системы, если документ "Распределение расходов по проектам" был проведен.

    • Закладка "Основное"

    На закладке расположены поля и кнопки для настройки формирования данных в табличной части документа:

  • Номер – уникальный номер документа, формируется автоматически;
  • Дата – формируется автоматически, по умолчанию в реквизит подставляется текущая дата;
  • Кнопка Период – позволяет выбрать период, кратный календарному месяцу;
  • Сворачиваемая группа Проекты общефирменной деятельности – заполняется проектами, расходы которых будут распределяться;
  • Сворачиваемая группа Проекты для распределенияи – заполняется проектами, на которые будут распределяться расходы;
  • Ссылка Отбор – открывает настройку отборов для заполнения проектов табличной части "Проекты для распределения".

    • Заполнение табличной части "Проекты общефирменной деятельности"

  • Кнопка Заполнить – заполняет табличную часть проектами с компонентой "Общефирменная деятельность". В табличной части заполняются проекты, фактические расходы которых будут распределяться.

    • Важно! При нажатии на кнопку Заполнить устанавливаются флаги на все проекты с компонентой "Общефирменная деятельность", в том числе на те, по которым отсутствуют фактические расходы в указанном периоде.

    Табличная часть содержит следующие реквизиты:

  • Распределять — отметка о включении фактических расходов проекта общефирменной деятельности в расходы к распределению.
  • Проект — проект с компонентой "Общефирменная деятельность", элемент справочника Проекты.

    • Заполнение табличной части "Проекты для распределения"

  • Кнопка Заполнить — заполняет табличную часть проектами с компонентой "Проект", на которые будут распределяться фактические расходы.

    • Важно! При нажатии на кнопку Заполнить устанавливаются флаги на все проекты с компонентой "Проект", в том числе на те, по которым отсутствует база распределения, указанная в способе распределения.

    Табличная часть содержит следующие реквизиты:

  • Распределять — отметка о включении проекта в базу распределения фактических расходов;
  • Проект — проект с компонентой "Проект", элемент справочника Проекты.

    • Закладка "Распределение"

    На закладке расположены поля и кнопки для настройки формирования данных в табличной части документа:

  • Сворачиваемая группа Расходы к распределению – заполняется фактическими расходами, подлежащими распределению;
  • Сворачиваемая группа Распределенные расходы – заполняется фактическими распределенными расходами.

    • Заполнение табличной части "Расходы к распределению"

    Данные о фактических расходах на выбранных проектах общефирменной деятельности за указанный период кратный календарному месяцу заполняются следующими способами:

  • Кнопка Заполнить → По статьям ФОТ – автоматически заполняет табличную часть фактическими расходами за указанный период с отбором по статьям, указанным в Параметрах подсистемы PM.
  • Кнопка Заполнить → По статьям (кроме ФОТ) – автоматически заполняет табличную часть фактическими расходами за указанный период за исключением расходов по статьям, указанным в Параметрах подсистемы PM.
  • Кнопка Заполнить → По всем статьям – автоматически заполняет табличную часть фактическими расходами за указанный период.

    • Табличная часть содержит следующие реквизиты:

  • N — номер строки;
  • Подразделение — подразделение, элемент справочника Подразделения;
  • Статья расходов — статья затрат, элемент справочника Статья затрат;
  • Способ распределения расходов — способ распределения расходов, элемент справочника Способ распределения расходов;
  • Сумма — общая сумма расходов за указанный период. Недоступно для редактирования;
  • Месяц — сумма расходов за указанный месяц.

    • Заполнение табличной части "Распределенные расходы"

    Данные о фактических расходах, распределенных на проекты для распределения, заполняются следующим способом:

  • Кнопка Распределить расходы – автоматически заполняет табличную часть фактическими расходами за указанный период согласно указанному для статьи Способ распределения расходов.

    • Табличная часть содержит следующие реквизиты:

  • N — номер строки;
  • Проект — наименование проекта, элемент справочника Проект;
  • Проектная задача — наименование проектной задачи, документ Проектная задача;
  • Подразделение — наименование подразделения, элемент справочника Подразделение;
  • Статья расходов — наименование статьи расходов, элемент справочника Статья расходов;
  • Сумма — сумма расходов за указанный период;
  • К.пр — коэффициент распределения по базе из Способа распределения расходов суммы по статье на конкретную проектную задачу за указанный период;
  • К. подр. — коэффициент распределения по базе из Способа распределения расходов суммы по статье на конкретное подразделение в проектной задаче за указанный период;
  • Месяц — сумма расходов за указанный месяц.

    • Дополнительно

    Информация, введенная в систему посредством документа "Распределение расходов по проектам", используется при формировании отчетов:

  • План-фактный анализ БДР;
  • План-фактный анализ БДР по подразделениям;
  • Анализ БДР по БДДС;
  • Скользящий БДР проекта;
  • Скользящий БДР, Объемы, БДДС;
  • План-фактный анализ по портфелю;
  • План-фактный анализ по программе;
  • Тематический план.
