Документ Распределение рабочего времени за неделю

Назначение

Документ "Распределение рабочего времени за неделю" предназначен для ввода в систему данных о распределении рабочего времени, затраченного трудовым ресурсом в течение недели, по проектным и внепроектным задачам, а также для ввода в систему данных о потерянном (затраченном непродуктивно) рабочем времени.

В зависимости от выбранного значения настройки "Распределять рабочее время" в Параметрах подсистемы PM, в документе будут отображаться только проектные задачи, только задания (с видом поручения) или все вместе.

Важно! При отключенной в Параметрах подсистемы PM константе "Разрешить списание часов на проектные задачи проекта в статусе "Остановлен"" в документе недоступно списание фактических трудозатрат по задачам и заданиям проекта в статусе "Остановлен", начиная с даты регистрации документа Остановка проектных работ.

Важно! При отключенной в Параметрах подсистемы PM константе "Разрешить списание рабочего времени по закрытым и завершенным задачам и закрытым заданиям" в документе недоступно списание фактических трудозатрат по проектным задачам в статусе "Завершена" и "Закрыта" и заданиям в статусе "Закрыто".

Форма объекта

При формировании документа "Распределение рабочего времени за неделю" необходимо заполнить следующие обязательные реквизиты шапки документа:

  • Номер документа – уникальный номер документа, формируется автоматически;
  • Дата – дата документа, по умолчанию подставляется текущая дата;
  • Подразделение – элемент справочника Подразделения, заполняется автоматически при заполнении реквизита "Трудовой ресурс";
  • Трудовой ресурс – сотрудник, по которому вводится табель, значение выбирается из справочника Трудовые ресурсы;
  • Начало недели – дата начала той календарной недели, за которую отчитывается трудовой ресурс (при выборе любой даты автоматически приводится к дате начала недели).

    • Важно! При выборе и/или изменении реквизита "Трудовой ресурс" производится проверка: имеет ли текущий пользователь системы полномочия владельца для выбранного трудового ресурса. В случае если текущий пользователь не имеет таких полномочий, значение реквизита либо исключается из списка выбора (при выборе значения из списка), либо очищается (при ручном изменении значения).

    Документ содержит 4 закладки, три из них используются для ввода информации по своему разделу учета рабочего времени:

  • Проектные задачи;
  • Внепроектные задачи;
  • Потери времени;
  • Итого за неделю.

    • Примечание. Недоступные для редактирования дни выделяются символом "x".

    Если в Параметрах подсистемы PM включена опция "Регистрировать трудозатраты переходящей недели двумя документами", то данные по трудозатратам, когда конец одного месяца и начало другого выпадает на одну неделю, исполнитель должен заносить двумя документами: в первом документе исполнитель указывает трудозатраты за конец месяца, во втором – за начало следующего месяца. Если настройка отключена, то исполнитель указывает трудозатраты одним документом.

    Если в системе (раздел "Администрирование", панель "Настройка пользователей и прав") установлена дата запрета изменения данных и она попадает внутрь периода, по которому исполнитель вносит трудозатраты, документ "Распределение рабочего времени за неделю" нельзя провести, только записать данные.

    Если дата запрета изменения выпадает на конец месяца и при этом в системе включена опция "Регистрировать трудозатраты переходящей недели двумя документами", то исполнитель может заполнить и провести документ, в котором указаны данные по трудозатратам за начало следующего месяца.

    Закладка "Проектные задачи"

    Заполнение табличной части "Проектные задачи"

    Табличная часть "Проектные задачи" заполняется автоматически проектными задачами и/или поручениями, в зависимости от настройки распределения рабочего времени в Параметрах подсистемы PM (константа "Распределять рабочее время").

    Пользователь не может вручную добавлять строки в табличную часть "Проектные задачи", заполнение табличной части производится автоматически при заполнении реквизита "Трудовой ресурс" и даты начала недели.

    Автоматическое заполнение производится в соответствии со следующими правилами:

  • дата начала проектной задачи не превышает дату завершения выбранной календарной недели;
  • дата начала выбранной календарной недели не превышает дату завершения проектной задачи;
  • выбранный трудовой ресурс был назначен на выполнение проектной задачи/поручения.

    • Реквизиты табличной части "Проектные задачи":

  • Проект – заполняется автоматически проектами, на которые назначен трудовой ресурс на даты выбранной недели.
  • Рабочее задание – заполняется автоматически проектными задачами и/или поручениями, на которые назначен трудовой ресурс на даты выбранной недели.
  • Колонки с датами и днями недели – предназначены для ручного распределения количества рабочих часов трудового ресурса между доступными проектными задачами и/или поручениями.
  • Колонка "Итого" – рассчитывается автоматически по каждой проектной задаче и/или поручению.
  • Роль трудового ресурса – заполняется автоматически ролью, которую выполняет трудовой ресурс.
  • Подразделение – заполняется автоматически подразделением, к которому относится трудовой ресурс.
  • Строка "Итого" – рассчитывается автоматически и отражает количество рабочих часов за каждый день недели.

    • Таким образом, после того, как табличная часть заполнена проектными задачами и/или поручениями, необходимо ввести соответствующее количество рабочих часов для каждого из рабочих дней. Допускается ситуация, когда для какой-либо строки общее количество рабочих часов за неделю является нулевым.

    Если в Параметрах подсистемы PM включена опция "Отключить проверку общего количества часов в документах по рабочему времени", то система не проверяет количество внесенных часов за день. Если опция не включена, то система не позволит провести документ с количеством рабочих часов, превышающим 24 часа в день.

  • Кнопка Заполнить – перезаполняет табличную часть.
  • Кнопка Заполнить по оперативной загрузке – позволяет автоматически заполнить табличную часть документа на основании данных обработки Оперативная загрузка специалистов по выбранному трудовому ресурсу на выбранную рабочую неделю.

    • Заполнение табличной части "Расшифровка"

    В случае если в Параметрах подсистемы PM установлена возможность использования расшифровки трудозатрат (устанавливается при помощи константы "Использовать расшифровку трудозатрат на проектных задачах"), в документе "Распределение рабочего времени за неделю" появляется возможность вводить данные расшифровки трудозатрат по рабочим заданиям и проектным задачам.

  • Кнопка Использовать расшифровку – включает/отключает режим использования расшифровки в конкретном документе.
  • Кнопка Добавить расшифровку – добавляет строку расшифровки в табличную часть "Расшифровка". Для добавления расшифровки необходимо встать на ячейку ввода рабочих часов за определенный день недели и нажать кнопку Добавить расшифровку.
  • Кнопка Удалить расшифровку – удаляет строку расшифровки из табличной части "Расшифровка". Для удаления необходимо выделить строку в табличной части "Расшифровка" и нажать кнопку Удалить расшифровку.

    • В табличной части "Расшифровка" заполняется:

  • Вид операции – выбирается из справочника Виды операций, указывается тип выполняемой задачи;
  • Расшифровка – произвольный текст, описание сути выполняемой задачи;
  • Итого – количество затраченных часов на задачу.

    • Сумма часов по строкам табличной части "Расшифровка" отобразится в табличной части "Проектные задачи" за выбранный день недели по конкретной проектной задаче или поручению.

    Примечание. При проведении документа "Распределение рабочего времени за неделю" для проектных задач и связанных с ними поручений используется вид операции, указанный в проектной задаче, если для этого вида операции заполнено значение параметра "Раздел учета рабочего времени". В противном случае используются виды операции, указанные при расшифровке трудозатрат, или вид операции "Явка", если расшифровка не используется.

    Закладка "Внепроектные задачи"

    Заполнение табличной части "Внепроектные задачи"

    Табличная часть "Внепроектные задачи" заполняется элементами справочников Внепроектные задачи и Задания.

  • Кнопка Добавить – добавляет новую строку табличной части в соответствии с выбранным типом данных:
  • Внепроектные задачи – элемент справочника Внепроектные задачи.
  • Задание – элемент справочника Задания.
  • Кнопка Подобрать – открывает форму подбора элементов справочника Внепроектные задачи.
  • Кнопка Заполнить поручениями – автоматически заполняет табличную часть внепроектными поручениями исполнителю на даты выбранной недели.

    • Реквизиты табличной части "Внепроектные задачи":

  • Задача – заполняется: внепроектными задачами (элемент справочника Внепроектные задачи) или поручениями (элемент справочника Задания), на которые назначен трудовой ресурс на даты выбранной недели.
  • Колонки с датами и днями недели – предназначены для ручного распределения количества рабочих часов трудового ресурса между внепроектными задачами и поручениями.
  • Колонка "Итого" – рассчитывается автоматически по каждой внепроектной задаче/поручению.
  • Строка "Итого" – рассчитывается автоматически и отражает количество рабочих часов за каждый день недели.

    • Таким образом, после того, как табличная часть заполнена внепроектными задачами и/или поручениями, необходимо ввести соответствующее количество рабочих часов для каждого из рабочих дней.

    Заполнение табличной части "Расшифровка"

    Трудозатраты по внепроектным задачам каждого дня можно расшифровать в табличной части "Расшифровка", заполнение которой аналогично заполнению расшифровки по проектным задачам.

    Примечание. При проведении документа "Распределение рабочего времени за неделю":

  • Для внепроектных задач используется вид операции, указанный в элементе справочника или виды операции, указанные при расшифровке трудозатрат, если используется расшифровка;
  • Для внепроектных поручений используется вид операции, указанный в задании. Если в задании вид операции не указан, используются виды операции, указанные при расшифровке трудозатрат, или вид операции "Явка", если расшифровка не используется.

    • Закладка "Потери времени"

    Заполнение табличной части "Потери времени"

    Табличная часть "Потери времени" заполняется элементами справочника Причины потерь рабочего времени.

  • Кнопка Добавить – табличная часть заполняется элементами справочника Причины потерь рабочего времени.
  • Кнопка Подобрать – открывает форму подбора элементов справочника Причины потерь рабочего времени.

    • Реквизиты табличной части "Потери времени":

  • Причина – заполняется элементами справочника Причины потерь рабочего времени.
  • Колонки с датами и днями недели – предназначены для ручного распределения количества рабочих часов трудового ресурса на причины потерь времени.
  • Колонка "Итого" – рассчитывается автоматически по каждой причине потерь времени.
  • Строка "Итого" – рассчитывается автоматически и отражает количество рабочих часов за каждый день недели.

    • Заполнение табличной части "Расшифровка"

    Потери времени по дню можно расшифровать в табличной части "Расшифровка", заполнение которой аналогично заполнению расшифровки по проектным задачам.

    Примечание. При проведении документа "Распределение рабочего времени за неделю" для причин потери рабочего времени используется вид операции, указанный в элементе справочника или виды операции, указанные при расшифровке трудозатрат, если используется расшифровка.

    Закладка "Итого за неделю"

    Отображает введенные часы трудового ресурса за неделю со всех закладок по разделам учета: проектные задачи, внепроектные задачи, потери рабочего времени.

    Важно! Стоимость фактических трудозатрат по Предварительному и Окончательному уровням планирования рассчитывается следующим образом:

  • Предварительный – стоимость трудозатрат рассчитывается в зависимости от настройки расчета стоимости фактических трудозатрат по ролям в Параметрах подсистемы PM (константа "Расчет стоимости фактических трудозатрат по ролям" в группе "Настройки распределения рабочего времени"), с учетом зарегистрированных документами Регистрация стоимости ресурса / Регистрация стоимости ресурсов ставок трудового ресурса или роли.
  • Окончательный - по умолчанию стоимость трудозатрат рассчитывается в зависимости от ставки трудового ресурса. Если на дату регистрации фактических трудозатрат ставка трудового ресурса не найдена, то расчет ведется по ставке роли.

    • Рассчитанную фактическую стоимость трудозатрат можно проанализировать отчетами Затраты трудовых ресурсов (план-факт), План-фактный анализ использования ресурсов, Освоенный объем по трудозатратам при выборе в настройках соответствующего уровня планирования.

    Работа документа с подсистемой "Даты запрета изменения"

    В документе "Распределение рабочего времени за неделю" поддерживается 2 сценария работы с датой запрета редактирования:
  • установка даты запрета концом недели;
  • установка даты запрета концом месяца, с использованием константы "Регистрировать трудозатраты переходящей недели двумя документами" в Параметрах подсистемы PM в группе "Настройки распределения рабочего времени".
    • Для использования других сценариев установки даты запрета редактирования необходимо использовать документ Табель учета рабочего времени.

    Дополнительная информация

    Данные, введенные в систему при помощи документов "Распределение рабочего времени за неделю", можно свести воедино и проанализировать при помощи следующих отчетов:

  • Затраты трудовых ресурсов (план-факт);
  • Использование рабочего времени;
  • План-фактный анализ использования ресурсов;
  • Освоенный объем по трудозатратам;
  • Трудозатраты по уровням планирования.
