Документ Расчет итогового балла проектов

Назначение

Документ "Расчет итогового балла проектов" предназначен для расчета итогового балла по проектам в зависимости от значений показателей эффективности, рассчитываемых документом Регистрация значений показателей эффективности проектов.

Форма объекта

При создании документа "Расчет итогового балла проекта" заполняются следующие реквизиты:

  • Дата — дата создания документа.
  • Номер документа — номер документа, формируется автоматически.
  • Программа проектов — элемент справочника Программы проектов, по которому будет производиться подбор проектов в табличную часть (реквизит "Программа проектов" в паспорте проекта). Реквизит не является обязательным для заполнения.
  • Портфель проектов — элемент справочника Портфели проектов, по которому будет производиться подбор проектов в табличную часть (реквизит "Портфель проектов" в паспорте проекта). Реквизит не является обязательным для заполнения.
  • Подразделение — элемент справочника Подразделения, по которому будет производиться подбор в табличную часть (реквизит "Бизнес-единица" в паспорте проекта). Реквизит не является обязательным для заполнения.

    • Табличная часть документа заполняется автоматически, с учетом настроенного отбора, при помощи кнопки Заполнить проекты.

    Важно! При заполнении документа, в табличную часть попадают только те проекты, для которых созданы документы Заявка на проект.

    В табличной части расположены колонки:

  • Проект — элемент справочника Проекты, по которому рассчитывается балл с учетом инвестиционных показателей.
  • Портфель проектов — элемент справочника Портфели проектов, к которому относится проект. Заполняется из карточки проекта.
  • Подразделение — ответственное за проект подразделение. Заполняется из карточки проекта.
  • Балл — значение рассчитывается с учетом инвестиционных показателей по формуле:
    • Балл = (IRR – r) * 100 + PBP * 10 + PI * 500
  • IRR — внутренняя ставка доходности;
  • r — ставка дисконтирования;
  • PBP — срок окупаемости;
  • PI — индекс прибыльности.
