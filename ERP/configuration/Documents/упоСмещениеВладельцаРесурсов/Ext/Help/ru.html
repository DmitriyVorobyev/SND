Документ Смещение владельца ресурсов

Назначение

Документ "Смещение владельца ресурсов" предназначен для регистрации в системе факта того, что данный сотрудник больше не владеет тем или иным ресурсом, ранее закрепленным за ним.

Форма объекта

При создании документа "Смещение владельца ресурсов" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически.
  • Дата — по умолчанию - текущая дата.
  • Владелец ресурсов — из справочника Сотрудники выбирается сотрудник, владеющий в данным момент некоторыми ресурсами.

    • На закладке "Трудовые ресурсы" табличная часть заполняется списком трудовых ресурсов следующим образом:

  • Автоматически — с помощью кнопки Заполнить;
  • Вручную — по кнопке Добавить на панели инструментов или с помощью клавиши Insert.

    • Важно! Заполнение табличной части документа вручную не рекомендуется: если в документ будут внесены ресурсы, которыми данный сотрудник не владел, документ не будет проведен.
