(не используется) Документ Расчет календарного плана проекта

Важно! Документ устарел и не рекомендуется к использованию.

Назначение

Документ "Расчет календарного плана проекта" предназначен для автоматического расчета календарных сроков проектных задач, исходя из структуры проекта.

Важно! В использовании документа нет необходимости, если структура проекта создается и редактируется при помощи обработки Структура проекта. В этом случае, календарные сроки проектных задач рассчитываются автоматически при записи изменений в структуре проекта.

Форма объекта

При создании документа "Расчет календарного плана проекта" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию - текущая дата;
  • Проект — проект, календарные сроки которого следует рассчитать;
  • Дата начала проекта / Дата окончания проекта — планируемая дата начала/окончания проекта в зависимости от выбранного режима расчета сроков;
  • Выполнять расчет сроков по методу "от даты окончания проекта" - опция определяет режим расчета сроков. Если опция включена, расчет сроков проекта будет производиться от даты завершения проекта, которая указывается в реквизите Дата окончания проекта. Если опция отключена, расчет сроков проекта будет производиться от даты начала проекта, которая указывается в реквизите Дата начала проекта.
  • Автоматически поддерживать актуальную дату документа – если опция включена, дата документа будет автоматически изменяться на текущую (рекомендуется включить эту опцию).

    • Табличная часть "Исключения" заполняется списком исключений, то есть проектными задачами с фиксированным началом и завершением. Сроки этих задач в процессе расчета календарного плана не будут изменены. Заполнение происходит следующим образом:

  • С помощью универсального механизма заполнения табличной части — кнопки Подбор;
  • Вручную — по кнопке Добавить на панели инструментов или с помощью клавиши Insert;
  • Автоматически, с помощью кнопки Заполнить:
  • По ручному вводу – табличная часть заполняется задачами с режимом ввода Вручную;
  • По текущему плану - табличная часть заполняется всеми задачами по текущему плану проекта;
  • По факту выполнения - табличная часть заполняется задачами в статусе "Завершена".

    • Важно! Расчет календарных сроков производится в момент проведения документа, результаты расчета можно увидеть, открыв Структуру проекта.

    Важно! Если в структуре проекта содержатся ошибки, то расчет календарных сроков произведен не будет, а система выдаст сообщение об ошибке. Для более подробной диагностики ошибок в структуре проекта необходимо использовать обработку Проверка структуры проекта.
