Документ Регистрация проекта

Назначение

Жизненный цикл проекта состоит из ряда последовательных стадий: Инициация проекта → Утверждение проекта → Старт (запуск) проекта  → Выполнение проекта → Остановка проекта → Возобновление проекта → Завершение проекта. Документ "Регистрация проекта" отражает факт инициации проекта и переводит проект в статус "Запланирован".

В момент регистрации проекта в системе для проекта определяются лица, ответственные за планирование и контроль его выполнения – руководитель и куратор проекта.

Для каждого руководителя (куратора) проекта в системе можно настроить доступ только к тем проектам, руководителем (куратором) которых он является.

Для этого в системе необходимо включить механизм объединения пользователей в группы ( см. Группы пользователей) и ограничения доступа на уровне записей в параметрах системы Настройка пользователей и прав. Ограничение доступа настраивается в профиле группы доступа (см. Профили групп доступа). В качестве объекта ограничения вида доступа указывается значение "Проекты PM". Список проектов, к которым группе пользователей предоставляется доступ, настраивается непосредственно во вкладке "Ограничения доступа" группы пользователей.

Форма объекта

К основным реквизитам документа "Регистрация проекта" относятся следующие:

  • Номер документа – формируется автоматически при записи документа;
  • Дата – формируется автоматически, по умолчанию в реквизит подставляется текущая дата;
  • Проект – инициируемый проект, элемент справочника Проекты;
  • Руководитель проекта – сотрудник предприятия, выполняющий функции руководителя проекта, элемент справочника Сотрудники;
  • Куратор проекта – сотрудник предприятия, выполняющий функции куратора проекта, элемент справочника Сотрудники;
  • Календарь проекта – рабочий календарь, в соответствии с которым будет производиться расчет календарных сроков проекта, длительностей проектных задач и загрузки трудовых ресурсов, элемент справочника Рабочие календари;
  • Календарь банковских дней – рабочий календарь, в соответствии с которым будет производиться расчёт задержек поступлений и выплат денежных средств по проектным задачам, элемент справочника Рабочие календари;
  • Комментарий – произвольный текст.
