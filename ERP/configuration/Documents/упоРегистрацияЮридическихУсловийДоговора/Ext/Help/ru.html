Документ Регистрация юридических условий договора

Назначение

Документ "Регистрация юридических условий договора" предназначен для ввода в систему данных об основных условиях договора.

Форма объекта

На командной панели расположены кнопки для управления настройками формирования и поведения документа:

  • Кнопка Провести и закрыть – провести и закрыть документ;
  • Кнопка Записать – сохранить изменения в документе, но не проводить его;
  • Кнопка Провести – провести документ;
  • Кнопка Открыть задания – открывает перечень заданий по текущему документу;
  • Кнопка Открыть проектные решения – открывает перечень проектных решений по текущему документу;
  • Кнопка Создать на основании – позволяет на основании выбранного документа "Регистрация юридических условий договора" сформировать некоторые виды документов, связанные с изменением статуса (Изменение статуса договора) или условий договора ("Дополнительное соглашение"), а также выдавать задания;
  • Кнопка Печать → Печать из шаблона – формирует документ MS Word с данными договора, сформированный на основании выбранного шаблона MS Word и документа "Регистрация юридических условий договора" (параметры в шаблоне заполняются значениями реквизитов документа в соответствии с правилами, созданными в справочнике Правила заполнения шаблонов MS Word), который затем можно вывести на печать;

    • Примечание. Для возможности формирования документа для печати из шаблона необходимо:

  • Сформировать правила заполнения параметров шаблона в справочнике Правила заполнения шаблонов MS Word;
  • Сформировать шаблон – документ MS Word, представляющий собой печатную форму и содержащий параметры, которые будут заполняться значениями реквизитов документа "Регистрация юридических условий договора".
  • Создать в справочнике Связи объектов и файлов элемент для закрепления созданного шаблона MS Word за документами "Регистрация юридических условий договора".

    • После этого шаблон станет доступен для выбора при печати документа "Регистрация юридических условий договора".

  • Кнопка Заполнить → Заполнить по проекту – выбирается конкретный проект из справочника Проекты) для автоматического заполнения структуры проекта на закладке "Этапы" на основании доходной и расходной, только доходной или только расходной части бюджетов проекта:
  • По структуре – загружается структура задач выбранного проекта, данные отображаются на закладке "Этапы";
  • По данным доходов – загружается план доходов по проектным задачам выбранного проекта;
  • По данным расходов – загружается план расходов по проектным задачам выбранного проекта;
  • По данным доход/расход – загружается план доходов и расходов по проектным задачам выбранного проекта;
  • По контрагенту – загружается план доходов и расходов по контрагенту, указанному на закладке "Реквизиты договора";
  • По контрагенту и договору – загружается план доходов и расходов по контрагенту, указанному на закладке "Реквизиты договора", и выбранному договору контрагента из справочника Договоры контрагентов.
  • Кнопка Заполнить → Заполнить по шаблону – выбирается конкретный шаблон из справочника Шаблоны проектов) для автоматического заполнения структуры проекта на закладке "Этапы" на основании доходной и расходной, только доходной или только расходной части бюджетов шаблона:
  • По данным доходов – загружается план доходов по проектным задачам выбранного шаблона;
  • По данным расходов – загружается план расходов по проектным задачам выбранного шаблона;
  • По данным доходов/расходов – загружается план доходов и расходов по проектным задачам выбранного шаблона.
    • При заполнении документа по шаблону трансляция данных по опциям "Включить план доходов в БДДС" и "Включить план расходов в БДДС" не производится.

    • Важно! Заполнение документа по проекту или шаблону доступно только при установленном флаге "Использовать этапы". Набор доступных вариантов заполнения зависит от типа условий договора (реквизит "Тип юридических условий договора"). Например, для типа "Доходный" будут недоступны варианты с заполнением по данным расходов ("По данным расходов" и "По данным доход/расход" / "По данным доходов/расходов").

    Примечание. После подтверждения пользователем необходимости перезаполнения графиков, структура этапов договора будет сформирована на основании данных выбранного проекта или шаблона проекта. Далее построчно вручную заносятся или редактируются данные о суммах и статьях БДР и БДДС.

  • Кнопка Структура договора – открывает форму обработки Настройка связей для формирования связи между проектным договором и проектом;

    • Важно! Если к договору существуют дополнительные соглашения, то зайти в обработку Настройка связей необходимо из документа "Дополнительное соглашение" (кнопка Структура договора).

  • Кнопка Отчеты – открывает перечень отчетов, которые можно сформировать по текущему договору.

    • При формировании документа необходимо заполнить следующие обязательные реквизиты шапки документа:

  • Номер договора – уникальный номер договора, заполняется автоматически;
  • Дата – дата договора, по умолчанию подставляется текущая дата;
  • Вид договора – вид договора, выбирается из справочника Вид договора.
    Для корректного заполнения реквизита "Представление договора" в соответствии с Правилом формирования наименований договоров, которое задано для вида договора, рекомендуется выбирать вид договора после заполнения реквизитов закладки "Реквизиты договора" и записи документа.

    • И ряд дополнительных реквизитов документа:

  • Представление договора – наименование договора, формируется автоматически по Правилу формирования наименований договоров, при выборе вида договора, доступно для редактирования;
  • Предмет договора – текстовое описание предмета договора, вводится вручную;
  • Использовать этапы – при проставлении в документе флага становится возможной связь этапов проекта и договора. В документе появляется дополнительная закладка "Этапы", на которой вручную заносится структура договора. Данная закладка используется для формирования этапов договора, БДР и БДДС проекта по этапам проектного договора.

    • Закладка "Реквизиты договора"

    На закладке "Реквизиты договора" заполняются следующие реквизиты:

  • Тип юридических условий договора – определяет условия заполнения документа с учетом выбранного типа договора. Выбирается один из вариантов:
  • Доходный/расходный;
  • Доходный;
  • Расходный.
  • Контрагент – необходимо указать контрагента, с которым заключается данный договор, значение выбирается из справочника Контрагенты;
  • Валюта – валюта договора, значение выбирается из справочника Валюты;
  • Организация – необходимо указать организацию, от лица которой заключается данный договор, выбирается из справочника Организации (Доступно для конфигурации "1С:ERP+PM Управление проектной организацией 2");
  • Сумма договора – если флаг "Использовать этапы" снят, можно вручную заполнить сумму всего договора. Если флаг "Использовать этапы" установлен, сумма договора автоматически рассчитывается как сумма БДР всех этапов с закладки "Этапы".

    • Закладка "Этапы"

    Закладка "Этапы" доступна при включении опции "Использовать этапы" на командной панели документа.

    В табличную часть заносится структура договора вручную либо автоматически на основании проекта / шаблона проекта.

  • Схема оплаты – значение выбирается из справочника Схемы оплаты. Для документа, у которого на закладке «Реквизиты договора» указан тип юридических условий договора «Доходный / расходный», при установке или смене схемы оплаты необходима дополнительная проверка и корректировка полученных данных в табличной части;
  • Способ учета аванса – необходимо выбрать способ зачета аванса: на проект в целом или на конкретный этап.

    • При заполнении структуры договора вручную, при нажатии кнопки Добавить, доступно внесение следующих типов элементов:

  • Этап – этап работ по проекту, заполняется вручную. Для редактирования доступны колонки Этап, в которой указывается наименование, Дата начала, Дата окончания и Комментарий. Недоступные для редактирования колонки с суммами заполняются данными из подчиненных строк с типом элементов Модель, Доход / Расход;
  • Модель – конкретная задача в рамках этапа работ по проекту, заполняется вручную. Для редактирования доступны колонки Этап, в которой указывается наименование, Дата начала, Дата окончания и Комментарий. Недоступные для редактирования колонки с суммами заполняются данными из подчиненных строк с типом элементов Доход / Расход;
  • Доход / Расход – отражение дохода или расхода в привязке к определенной задаче по проекту. Для редактирования доступны колонки Этап, в которой необходимо выбрать доходную статью БДР из справочника Статьи доходов по проектам или расходную статью БДР из справочника Статьи затрат по проектам, Сумма БДР, Схема оплаты, Дата начисления/оплаты и Комментарий. Вид движения будет заполнен автоматически из статьи БДР;
  • Поступление / Выплата – отражение поступления или выплаты в привязке к определенной задаче по проекту. Для редактирования доступны колонки Этап, в которой необходимо выбрать статью поступления ил  выплаты БДДС из справочника Статьи движения денежных средств, Сумма БДДС, Дата начисления/оплаты и Комментарий. Строку поступления / выплаты можно заполнить автоматически на основании суммы дохода / расхода по данной задаче и схемы оплаты – для этого необходимо в строке "Доход" / "Расход" конкретной модели выбрать необходимую схему оплаты. Система спросит о необходимости обновления графика оплаты и в случае согласия пользователя пересчитает график оплат в соответствии с указанной схемой оплаты.

    • Для автоматического заполнения структуры договора на основании доходной и расходной, только доходной или только расходной части бюджетов проекта или шаблона, необходимо на командной панели документа нажать на кнопку Заполнить и выбрать вариант заполнения.

    Закладка "Доп. соглашения"

    На закладке "Доп. соглашения" выводится справочная информация по всем зарегистрированным дополнительным соглашениям к данному договору.

    Дополнительное соглашение к договору создается на основании документа "Регистрация юридических условий договора" (кнопка Создать на основании → Регистрация юридических условий договора).

    Формирование взаимосвязи договора и проекта.

    Для связи проектного договора и проекта необходимо воспользоваться обработкой Настройка связей. Для этого в документе "Регистрация юридических условий договора" необходимо воспользоваться кнопкой Структура договора.

    Важно! Перенос планов БДР и БДДС из документа "Регистрация юридических условий договора" в проект возможен только в том случае, если настроена связь этапов договора и этапов проекта. В случае, если сроки этапов проекта не совпадают со сроками этапов договора, их необходимо скорректировать вручную.

    Документ Дополнительное соглашение

    Назначение

    Документ "Дополнительное соглашение" предназначен для отражения условий дополнительных соглашений к проектным договорам.

    Примечание. Документ "Дополнительное соглашение" создается на основании документа "Регистрация юридических условий договора".

    Форма объекта

    При формировании документа необходимо заполнить следующие реквизиты шапки документа:

  • Номер – уникальный номер дополнительного соглашения, заполняется автоматически;
  • Дата – дата дополнительного соглашения, по умолчанию подставляется текущая дата;
  • Договор – указывается определенный договор, к которому относится данное доп. соглашение (ссылка на документ "Регистрация юридических условий договора");
  • Сумма договора
  • Если доп. соглашение относится к документу "Регистрация юридических условий договора", у которого установлен флаг "Использовать этапы", в доп. соглашении также доступна закладка "Этапы" и "Сумма договора" заполняется автоматически как сумма БДР всех этапов по проекту на этой закладке.
  • Если доп. соглашение относится к документу "Регистрация юридических условий договора", у которого не установлен флаг "Использовать этапы", в доп. соглашении отсутствует закладка "Этапы", а "Сумма договора" заполняется из документа "Регистрация юридических условий договора".

    • Закладка "Этапы"

    На закладке "Этапы" выбираются:

  • Схема оплаты – значение выбирается из справочника Схемы оплаты;
  • Способ учета аванса – необходимо выбрать способ зачета аванса: на проект в целом или на конкретный этап.

    • На закладке "Этапы" заносится структура договора вручную либо автоматически на основании проекта /шаблона проекта.

  • Кнопка Показать только измененные этапы – скрывает этапы договора, по которым отсутствуют изменения по срокам, БДР или БДДС, оставляя в табличной части только измененные этапы.

    • При заполнении вручную необходимо по кнопке Добавить указать:

  • Этап – этап работ по проекту;
  • Модель – конкретная задача в рамках этапа работ по проекту. Для модели необходимо указать даты начала и окончания работ по данной задаче;
  • Доход / Расход – отражение дохода или расхода в привязке к определенной задаче по проекту. В строке необходимо указать доходную или расходную статью БДР, сумму по данной статье и дату начисления дохода / расхода. Вид движения будет заполнен автоматически из статьи БДР;
  • Поступление / Выплата – отражение поступления или выплаты в привязке к определенной задаче по проекту. В строке необходимо указать статью поступления или выплаты БДДС, сумму по данной статье и дату начисления поступления / выплаты. Строку поступления/выплаты можно заполнить автоматически на основании суммы дохода / расхода по данной задаче и схемы оплаты – для этого необходимо в строке "Доход" / "Расход" конкретной модели выбрать необходимую схему оплаты.

    • Для автоматического заполнения структуры проекта на основании доходной и расходной, только доходной или только расходной части бюджетов проекта или шаблона, необходимо на командной панели документа нажать на кнопку Заполнить и выбрать вариант заполнения.

    Формирование взаимосвязи договора и проекта

    Формирование взаимосвязи договора и проекта производится аналогично документу "Регистрация юридических условий договора".

    Важно! Перенос планов БДР и БДДС из документа "Дополнительное соглашение" в проект возможен только в том случае, если настроена связь этапов договора и этапов проекта. В случае, если сроки этапов проекта не совпадают со сроками этапов договора, их необходимо скорректировать вручную.
