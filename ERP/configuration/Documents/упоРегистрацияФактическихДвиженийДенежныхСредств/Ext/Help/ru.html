Документ Регистрация фактических ДДС

Назначение

Для каждой проектной задачи существует свой план движений денежных средств, но в процессе выполнения проекта фактические движения денежных средств могут расходиться с плановыми. Документ "Регистрация фактических ДДС" предназначен для регистрации в системе данных о фактических поступлениях и выплатах по проектной задаче.

Форма объекта

При создании документа "Регистрация фактических ДДС" необходимо заполнить следующие реквизиты:

  • Номер документа — уникальный номер документа (формируется автоматически);
  • Дата — дата документа (по умолчанию подставляется текущая дата);
  • Проектная задача — проектная задача, по которой регистрируются поступления и выплаты;
  • Проект — заполняется автоматически, в зависимости от выбранной проектной задачи.

    • Данные о поступлениях и выплатах заносятся в табличную часть документа. Табличную часть можно заполнить следующими способами:

  • Вручную (кнопка Добавить);
  • Через универсальную форму подбора (кнопка Подобрать):
  • по статьям ДДС;
  • по контрагентам;
    • При подборе можно выбрать направление движения ДС (кнопка Подобрать → Параметры подбора).
  • Автоматическое заполнение по данным текущего плана БДДС (кнопка Заполнить).
    • Для ручного ввода доступны следующие поля табличной части:
  • Контрагент – контрагент-заказчик/контрагент-исполнитель, элемент справочника Контрагенты;
  • Договор – договор с контрагентом, элемент справочника Договоры контрагентов;
  • Статья ДДС – статья движения денежных средств, элемент справочника Статьи движения денежных средств;
  • Направление – направление движения ДС (Выплата/Поступление);
  • Дата движения – дата, на которую будут отнесены движения ДС;
  • Валюта - валюта договора с контрагентом, элемент справочника Валюты;
  • Сумма – сумма движения ДС в денежном выражении;
  • Номер п/п – номер платежного документа;
  • Дата п/п – дата платежного документа;
  • Комментарий – текстовое поле.

    • Дополнительно

    Информация, введенная в систему посредством документа "Регистрация фактических ДДС", используется при формировании отчета План-фактный анализ ДДС.
