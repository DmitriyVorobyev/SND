Документ Изменение статуса договора

Назначение

Документ предназначен для ввода в систему данных о текущем статусе договора.

Рекомендуется создавать этот документ в режиме ввода на основании, основанием служит документ "Регистрация юридических условий договора" или документ "Дополнительное соглашение".

После  проведения изменения статус отражается в договоре или дополнительном соглашении к нему соответственно.

Форма объекта

В документе необходимо заполнить следующие реквизиты:

  • Номер – номер документа, присваивается автоматически при записи документа.
  • Дата – дата документа, по умолчанию подставляется текущая дата.
  • Документ основание – выбирается договор, у которого необходимо изменить статус (ссылка на документ Регистрация юридических условий договора).
  • Статус  – указывается статус для выбранного договора, значение выбирается из справочника Статусы объектов.
  • Комментарий – произвольный текст.
