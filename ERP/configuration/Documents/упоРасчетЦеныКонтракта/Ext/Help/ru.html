Объект доступен только в приложении "1С:PM Управление проектами КОРП" (1С:PM КОРП).


Документ Расчет цены контракта

Назначение

Документ "Расчет цены контракта" предназначен для расчета планируемой себестоимости контракта (тендера), возможной прибыли и рентабельности, на основании информации о стоимости контракта (тендера), количестве человеко-часов, требующихся на реализацию контракта, и сумм прочих затрат.

Форма объекта

К основным реквизитам документа "Расчет цены контракта" относятся следующие:

  • Номер документа – формируется автоматически;
  • Дата – формируется автоматически, по умолчанию в реквизит подставляется текущая дата;
  • Контрагент – контрагент-заказчик, элемент справочника Контрагенты;
  • Договор контрагента – договор с контрагентом-заказчиком, элемент справочника Договоры контрагентов;
  • Программа проекта – элемент справочника Программы проектов. Этот реквизит показывает, какой программе проектов принадлежит данный контракт;
  • Портфель проекта – элемент справочника Портфели проектов. Этот реквизит показывает, какому портфелю проектов принадлежит данный контракт;
  • Проект – проект, к которому принадлежит контракт, элемент справочника Проекты;
  • Номер конкурса – номер объявленного конкурса (тендера), строка;
  • Предмет конкурса – предмет объявленного конкурса (тендера), строка;
  • Статус документа – статус документа, справочник Статусы объектов;

    • Закладка "Параметры расчета"

    На данной закладке отображаются реквизиты, описывающие основные параметры контракта.

  • Вид конкурса – вид объявленного конкурса, элемент справочника Виды конкурсов;
  • Тип контракта – тип контракта, элемент справочника Типы контрактов;
  • Страна – страна в которой будут выполняться работы;
  • Место – адрес выполнения работ, строка;
  • Валюта – валюта контракта, элемент справочника Валюты;
  • Курс – курс валюты;
  • Дата объявления конкурса – дата объявления конкурса (тендера);
  • Дата подачи документов заказчику – дата передачи документов заказчику, объявившему конкурс (тендер);
  • Дата подведения итогов – дата подведения итогов конкурса (тендера);
  • Дата начала работ по плану – плановая дата начала работ по договору;
  • Дата окончания работ по плану – плановая дата окончания работ по договору;
  • Продолжительность, мес. – плановая продолжительность работ по договору/;
  • Лимит конкурса – предельная сумма контракта.

    • Табличная часть "Параметры расчета"

    В данной табличной части отображаются реквизиты, влияющие на расчет себестоимости контракта и результаты расчета цены контракта по видам основных операций.

    Параметры расчета:

  • Норма стоимости внутренняя – внутренняя норма стоимости ролей трудовых ресурсов требующихся для выполнения контракта, справочник Нормы стоимости;
  • Норма стоимости внешняя – внешняя норма стоимости ролей трудовых ресурсов требующихся для выполнения контракта, справочник Нормы стоимости;
  • Поправка на инфляцию – поправочный коэффициент, влияющий на общую стоимость контракта;
  • Кнопка Пересчитать сумму контракта по внешней ставке – пересчитывает сумму контракта по внешней ставке для строк, у которых установлен флаг в колонке "Сумма контракта".

    • Важно! Кнопка Пересчитать сумму контракта по внешней ставке активна только при установленных флагах в колонке "Сумма контракта".

    Таблица с результатами расчета цены контракта:

  • Раздел – раздел контракта, доступные значения "ПИР, НИР", "Оборудование, "ПНР", "СМР" и "Прочее", набор доступных значений определяется составом разделов выбранных в параметрах документа (кнопка Параметры);
  • Затраты – общая сумма затрат по разделу;
  • Процент наценки – процент наценки к сумме затрат по разделу, если установлен флаг, то процент наценки вводится вручную, если нет, то рассчитывается;
  • Сумма наценки – сумма наценки, расчетный показатель, вычисляемый как разность между суммой контракта и суммой затрат;
  • Сумма контракта – сумма контракта по разделу, если установлен флаг, то сумма контракта вводится вручную, если нет, то рассчитывается;
  • Дата актирования – реквизит обязательный для заполнения, используется для заполнения данных по выручке в Тематическом плане на основании документа "Расчет цены контракта" при помощи обработки "Актуализация тематического плана" (обработка "Актуализация тематического плана" доступна из обработки Структура проекта при нажатии кнопки Еще → Актуализировать → программу по проектам).

    • Примечание. При формировании структуры проекта из документа "Расчет цены контракта" данные по выручке не переносятся.

    В нижней части закладки "Параметры расчета" выводится общая сумма контракта, с учетом поправки на инфляцию, и отклонение общей суммы контракта от лимита.

    Закладки "ПИР, НИР", "ПНР", "СМР" и "Прочее"

    На этих закладках расположены элементы управления, которые используются для ввода в систему информации о требуемых трудозатратах для выполнения контракта и о требуемых дополнительных затратах. Эти элементы управления, в свою очередь, разнесены по нескольким закладкам:

    Закладка "Трудозатраты"

    На закладке располагается табличная часть, при помощи которой настраивается состав ролей трудовых ресурсов и предполагаемый объём трудозатрат. Табличная часть содержит следующие реквизиты:

  • Вид операции – элемент справочника Виды операций, используется в качестве дополнительного аналитического разреза при анализе;
  • Подразделение – элемент справочника Подразделения, указывает на то Подразделение, которое требуется для выполнения работ в рамках выполнения контракта;
  • Специальность – элемент справочника Роли трудовых ресурсов, указывает на ту роль, которая требуется для выполнения работ в рамках выполнения контракта;
  • СС/СП – признак выполнения работ собственными силами или субподрядчиками, элемент справочника Собственные силы/субподряд;
  • Статья затрат – элемент справочника Статьи затрат по проектам, т.е. та статья, на которую будут отнесены трудозатраты;
  • Количество часов – количество трудозатрат, которые потребуются для выполнения контракта;
  • Ставка внутренняя – стоимость одной единицы трудозатрат по внутренней ставке, заполняется автоматически при выборе специальности, может быть изменено вручную;
  • Сумма по внутренней ставке – полная стоимость привлечения трудового ресурса к выполнению контракта по внутренней ставке;
  • Ставка внешняя – стоимость одной единицы трудозатрат по внешней ставке, заполняется автоматически при выборе специальности, может быть изменено вручную;
  • Сумма по внешней ставке – полная стоимость привлечения трудового ресурса к выполнению контракта по внешней ставке;
  • Оценочная сумма – оценочная стоимость привлечения трудового ресурса к выполнению контракта, заполняется вручную.

    • Закладка "Дополнительные затраты"

    Эта табличная часть используется для ввода информации о тех финансовых затратах, запланированных в рамках проектной задачи, которые не связаны с непосредственным использованием трудовых ресурсов. Табличная часть содержит следующие реквизиты:

  • Вид операции – элемент справочника Виды операций, используется в качестве дополнительного аналитического разреза при анализе;
  • Статья затрат – элемент справочника Статьи затрат по проектам, т.е. та статья, на которую будут отнесены трудозатраты;
  • Тип расчета – тип расчета дополнительных затрат, возможны следующие варианты:
  • Вручную – сумма дополнительных затрат вносится вручную, реквизиты "Показатель" и "Количество часов" не заполняются;
  • Ставка часа – сумма рассчитывается как произведение значений реквизитов "Показатель" и "Количество часов" указанных вручную;
  • Ставка часа от собственных трудозатрат – количество часов рассчитывается как общее количество трудочасов указанных в табличной части "Трудозатраты" с отбором по признаку "Собственные силы", показатель (ставка часа) вносится вручную;
  • Процент от собственных трудозатрат – сумма рассчитывается как произведение значения реквизита "Показатель" указанного вручную на общую сумму трудозатрат по внутренней ставке указанных в табличной части "Трудозатраты" с отбором по признаку "Собственные силы";
  • Процент от группы затрат – при выборе данного типа расчета необходимо указать набор элементов справочника Статьи затрат по проектам, при этом сумма рассчитывается как произведение значения реквизита "Показатель" указанного вручную на общую сумму трудозатрат по внутренней ставке указанных в табличной части "Трудозатраты" с отбором по признаку "Собственные силы" и отбором по выбранным статьям, плюс общая сумма дополнительных затрат из табличной части "Дополнительные затраты" с отбором по выбранным статьям, исключая значение по текущей строке.
  • Группа статей затрат - элемент справочника Группы статей затрат, используется в качестве дополнительного аналитического разреза при анализе;
  • Показатель – показатель расчета;
  • Количество часов – количество трудочасов, используется только для типов расчета "Ставка часа" и "Ставка часа от собственных трудозатрат";
  • Сумма – сумма дополнительных затрат.

    • Важно! При расчете дополнительных затрат, с использованием типов расчета "Ставка часа от собственных трудозатрат" и "Процент от собственных трудозатрат", производится отбор по реквизитам "Вид операции" и "Тип расчета".
    Если реквизит "Вид операции" заполнен, то будет произведен отбор совместно по реквизитам "Вид операции" и "Тип расчета".
    Если реквизит "Вид операции" не заполнен, то будет произведен отбор только по реквизиту "Тип расчета".

    Закладка "Оборудование"

    На этой закладке расположены элементы управления, которые используются для ввода в систему информации о требуемых затратах на закупку оборудования и о требуемых дополнительных затратах. Эти элементы управления, в свою очередь, разнесены по нескольким закладкам:

    Закладка "Оборудование продаваемое"

  • Ставка таможенного оформления – величина процента таможенного оформления.

    • Эта табличная часть используется для ввода состав оборудования и предполагаемые затраты на закупку, доставку и таможенное оформление. Табличная часть содержит следующие реквизиты:

  • Оборудование – элемент справочника Номенклатура, продаваемое оборудование в рамках выполнения контракта;
  • Вид операции – элемент справочника Виды операций, используется в качестве дополнительного аналитического разреза при анализе;
  • Количество – количество продаваемого оборудования;
  • Статья затрат – элемент справочника Статьи затрат по проектам, т.е. та статья, на которую будут отнесены затраты на закупку оборудования;
  • Наценка / скидка – процент наценки (положительное число) или процент скидки (отрицательное число) к стоимости закупки оборудования;
  • Цена закупки (EXW) – закупочная цена оборудования;
  • Стоимость закупки (EXW) – стоимость оборудования по закупочной цене;
  • Цена продажи (EXW) – цена продажи оборудования с учетом наценки / скидки;
  • Стоимость продажи (EXW) - стоимость продажи оборудования с учетом наценки / скидки;
  • Процент доставки – процент доставки для единицы оборудования от стоимости закупки;
  • Стоимость закупки (CIP) – стоимость закупки оборудования с учетом стоимости доставки;
  • Стоимость продажи (CIP) – стоимость продажи оборудования с учетом стоимости доставки;
  • Таможенная пошлина – процент таможенной пошлины для единицы оборудования;
  • Процент таможенной пошлины – процент для расчета таможенной стоимости от цены закупки;
  • Таможенная стоимость закупки (CIP) – таможенная стоимость, от которой будет рассчитываться стоимость пошлины. Рассчитывается как цена закупки оборудования, умноженная на процент таможенной пошлины;
  • Стоимость оформления – стоимость таможенного оформления одной единицы оборудования. Рассчитывается как величина процента таможенного оформления, указанного в параметре "Ставка таможенного оформления, %", умноженная на таможенную стоимость;
  • Стоимость пошлины – сумма таможенной пошлины единицы оборудования. Рассчитывается как закупочная цена оборудования, умноженная на Процент таможенной пошлины;
  • Ставка НДС – ставка НДС уплачиваемого на таможне;
  • Сумма НДС – сумма НДС уплачиваемого на таможне. Рассчитывается как сумма таможенной стоимости закупки, стоимости оформления и стоимости пошлины, умноженная на ставку НДС;
  • Всего таможенных платежей – сумма стоимости таможенного оформления, стоимости пошлины и суммы НДС.

    • Закладка "Дополнительные затраты"

    Эта табличная часть используется для ввода информации о тех финансовых затратах, запланированных в рамках проектной задачи, которые не связаны непосредственно с закупкой оборудования, доставкой и таможенным оформлением. Табличная часть содержит следующие реквизиты:

  • Вид операции – элемент справочника Виды операций, используется в качестве дополнительного аналитического разреза при анализе;
  • Статья затрат – элемент справочника Статьи затрат по проектам, т.е. та статья, на которую будут отнесены дополнительные затраты;
  • Сумма – сумма дополнительных затрат.

    • Закладка "Итоги конкурса"

    На данной закладке отображаются реквизиты, описывающие итоги проведения конкурса (тендера):

  • Вид конкурса – вид объявленного конкурса (тендера), элемент справочника Виды конкурсов;
  • Статус конкурса – статус конкурса (тендера), доступные значения "Выиграли", "Проиграли", "Прочее";
  • Победитель – победитель конкурса (тендера), элемент справочника Контрагенты;
  • Лимит конкурса – предельная сумма контракта;
  • Дата объявления конкурса – дата объявления конкурса (тендера);
  • Дата подведения итогов – дата подведения итогов конкурса (тендера);
  • Сумма победителя – сумма контракта, предложенная победителем конкурса (тендера);
  • Наша сумма – сумма контракта, предложенная нашей организацией.

    • Табличная часть "Итоги конкурса"

    В данной табличной части вносятся данные об участниках проводимого конкурса (тендера):

  • Контрагент – контрагент, участвовавший в конкурсе (тендере), элемент справочника Контрагенты;
  • Сумма – сумма контракта, предложенная контрагентом;
  • Балл – балл выставленный контрагенту;
  • Место – место занявший контрагент по итогам конкурса (тендера);
  • Подача – дополнительный признак;
  • Допуск – дополнительный признак;
  • Комментарий – текстовое поле для комментариев.
