Документ Смещение трудового ресурса с роли

Назначение

Документ "Смещение трудового ресурса с роли" предназначен для снятия ранее установленного соответствия между трудовым ресурсом и его ролями, то есть, для ввода в систему данных о том, что трудовой ресурс более не может выполнять те или иные роли.

Документ "Смещение трудового ресурса с роли" позволяет:

  • Отменять установленное соответствие между трудовым ресурсом и его ролями.

    • Форма объекта

    При создании документа "Смещение трудового ресурса с роли" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию - текущая дата;
  • Трудовой ресурс — выбирается из справочника Трудовые ресурсы.

    • Табличная часть документа "Смещение ролей трудового ресурса" заполняется списком ролей. Заполнение производится следующим образом:

  • Автоматически — по кнопке Заполнить. Документ заполняется в соответствии с ранее присвоенными трудовому ресурсу ролями;
  • Вручную — по кнопке Добавить на панели инструментов или с помощью клавиши Insert.

    • Важно! Заполнение табличной части документа вручную не рекомендуется: если в документ будет внесена роль, которая до этого не была назначена трудовому ресурсу, возникнет ошибка, и документ не проведется.

  • Роли, которые мы хотим оставить за трудовым ресурсом, удаляются из табличной части документа с помощью кнопки Удалить на панели инструментов или клавиши Delete.
  • Роли, которые мы хотим снять с трудового ресурса, следует оставить в табличной части документа "Смещение трудового ресурса с роли".
