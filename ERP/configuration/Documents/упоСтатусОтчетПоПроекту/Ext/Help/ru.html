Документ Статус-отчет по проекту

Назначение

Документ "Статус-отчет по проекту" предназначен для формирования отчета по конкретному проекту, в котором выводится информация об основных показателях проекта и вопросах, на которых следует акцентировать внимание.

Форма объекта

На командной панели расположены кнопки для управления настройками, формирования и поведения документа:

  • Кнопка Провести и закрыть – провести и закрыть документ;
  • Кнопка Записать – сохранить изменения в документе, но не проводить его;
  • Кнопка Провести – провести документ;
  • Кнопка Создать на основании – позволяет на основании выбранного документа "Статус-отчет по проекту" сформировать следующий документ "Статус-отчет по проекту".
  • Кнопка Печать → Детальный статус-отчет – формирует печатную форму отчета с детализацией до проектных задач;
  • Кнопка Печать → Статус-отчет по проекту – формирует печатную форму отчета в целом по проекту;
  • Кнопка Паспорт проекта – открывает выбранный элемент справочника Проекты для просмотра и редактирования;
  • Кнопка Структура проекта – открывает обработку Структура проекта для ввода плана работ по проекту;
  • Кнопка Отчеты – открывает перечень отчетов, которые можно сформировать по текущему проекту.

    • При создании документа "Статус-отчет по проекту" заполняются следующие реквизиты:

  • Дата – дата документа (по умолчанию подставляется текущая дата);
  • Номер – уникальный номер документа (формируется автоматически);
  • Проект – элемент справочника Проекты, для которого формируется документ;
  • Предыдущий статус-отчет – сформированный ранее по тому же проекту документ "Статус-отчет по проекту", данные которого используются для отслеживания динамики проекта.

    • При создании документа "Статус-отчет по проекту" на основании созданного ранее, в новом документе автоматически будут заполнены:

  • Проект – значением проекта из документа-основания;
  • на основании заполненного проекта заполнятся закладки документа:
  • "Статус задач" – всеми задачами этого проекта, у которых не установлен флаг "Не выводить в статус отчет";
  • "Сводный статус" – сводными статусами сроков, ресурсов, бюджетов и рисков проекта;
  • "Задачи / активности" – выполненными, выполняемыми, ближайшими задачами / активностями;
  • "Риски" – рисками, зарегистрированными для проекта;
  • "Сведения о проекте" – данными из паспорта проекта;
  • Предыдущий статус-отчет – значением статус-отчета из документа-основания;
  • на основании заполненного предыдущего статус-отчета заполнятся:
  • "% динамики" на закладке "Статус задач" – динамикой изменения процента готовности проектной задачи по сравнению со значением, зафиксированным предыдущим документом "Статус-отчет по проекту";
  • "Вопросы на контроле" на закладке "Вопросы" – вопросами по проекту, находящимися на контроле;

    • Закладка "Статус задач"

    Закладка "Статус задач" содержит табличную часть, в которую выводится дерево задач проекта со статусами задач по выполнению, срокам, ресурсам, бюджетам и рискам.

    Табличная часть заполняется автоматически при выборе проекта всеми задачами этого проекта, у которых не установлен флаг "Не выводить в статус отчет".

  • Кнопка Добавить – добавляет в табличную часть новую задачу, при этом новый документ Проектная задача не создается;
  • Кнопка Заполнить – используется для перезаполнения табличной части.
  • Кнопка Пересчитать статусы сроков – используется для пересчета значений реквизита "Статус сроков" для всех проектных задач документа. Рассчитывается на основании указанного процента готовности ("% выполнения") и расчетного процента готовности (РПГ) проектной задачи.

    • Табличная часть содержит следующие колонки:

  • Задача – наименование проектной задачи из структуры проекта, либо новой задачи, добавленной при создании документа;
  • Статус задачи – статус готовности проектной задачи:
  • Запланирована;
  • Выполняется;
  • Завершена;
  • Закрыта;
  • Статусы:
  • Сроки – индикатор отставания фактического выполнения проектной задачи по срокам:
    • РПГ = Dрасч * 100%
    ─────
    D
  • РПГ – расчетный процент готовности;
  • Dрасч - продолжительность задачи с плановой даты начала по текущую дату (дни с учетом рабочего календаря);
  • D - плановая продолжительность задачи (дни с учетом рабочего календаря).
  • План – % выполнения = Расчетный процент готовности = 0;
  • Выполнено – % выполнения = 100%;
  • По графику – Расчетный процент готовности <= % выполнения < 100%;
  • Задержка – 0 < Расчетный процент готовности - % выполнения <= 25%;
  • Срыв - 25% < Расчетный процент готовности - % выполнения;
  • Ресурсы – индикатор выделения ресурсов на проектную задачу:
  • План – в проектной задаче не запланированы роли ни на предварительном, ни на окончательном уровне планирования;
  • Освобождены – статус проектной задачи "Завершена" или "Закрыта";
  • Выделены – на каждую запланированную в проектной задаче роль назначен трудовой ресурс;
  • Мало – хотя бы на одну из запланированных в проектной задаче ролей не назначен трудовой ресурс;
  • Критично – ни на одну из запланированных в проектной задаче ролей не назначен трудовой ресурс;
  • Бюджеты – индикатор отклонения выполненных объемов рассчитываемый, как отношение отклонения по стоимости к плановой стоимости выполненных работ (CV / EV):
  • CV = EV – AC;
  • AC – факт бюджета расходов на текущую дату;
  • EV = BAC * % готовности;
  • BAC – общий бюджет расходов.
  • План – по проектной задаче не запланированы расходы;
  • Соблюдение – по проектной задаче запланированы расходы (план расходов документа Проектная задача) и CV / EV = 0
  • Экономия – по проектной задаче запланированы расходы (план расходов документа Проектная задача) и 0 < CV / EV <= 0,25;
  • Превышение – по проектной задаче запланированы расходы (план расходов документа Проектная задача) и -0,25 <= CV / EV < 0;
  • Не исполняется – по проектной задаче запланированы расходы (план расходов документа Проектная задача) и CV / EV < -0,25 или 0,25 < CV / EV).
  • Риски – сводный статус рисков проектной задачи (элементов справочника Риски проектов с типом "Угроза"):
  • Не заявлены – для задачи не зарегистрировано ни одного риска;
  • Актуальны – для задачи имеется хотя бы один риск в статусе "Актуален" и нет ни одного риска в статусе "Сработал";
  • Сработали – для задачи имеется хотя бы один риск в статусе "Сработал";
  • Не актуальны – для задачи имеется хотя бы один риск в статусе "Потерял актуальность" и нет ни одного риска в статусе "Актуален" / "Сработал";
  • Закрыты – все риски задачи имеют статус "Закрыт";
  • Сроки:
  • План (нач.) – плановая дата начала проектной задачи;
  • План (кон.) – плановая дата завершения проектной задачи;
  • Прогноз (нач.) – прогнозная дата начала проектной задачи;
  • Прогноз (кон.) – прогнозная дата завершения проектной задачи;
  • % выполнения – текущий процент готовности проектной задачи;
  • % динамики – динамика изменения процента готовности проектной задачи по сравнению со значением, зафиксированным предыдущим документом "Статус-отчет по проекту". Заполняется автоматически:
  • при создании нового документа "Статус-отчет по проекту" на основании выбранного документа "Статус-отчет по проекту";
  • при ручном заполнении реквизита "Предыдущий статус-отчет" и положительном ответе на запрос системы о перезаполнении % динамики и вопросов на контроле;
  • Ответственный – руководитель проектной задачи, элемент справочника Сотрудники;
  • Комментарий – произвольный текстовый комментарий.

    • Закладка "Сводный статус"

    На закладке "Сводный статус" отображаются сводные статусы сроков, ресурсов, бюджетов и рисков проекта. Статусы можно заполнить вручную, либо при помощи кнопки Заполнить сводный статус.

    Статус

  • Сроки:
  • План – все задачи проекта имеют статус сроков "План";
  • Выполнено – хотя бы одна из задач проекта имеет статус сроков "Выполнено" и в проекте нет задач со статусом "Задержка" / "Срыв" / "По графику";
  • По графику – хотя бы одна из задач проекта имеет статус сроков "По графику" и в проекте нет задач со статусом "Задержка" / "Срыв";
  • Задержка – хотя бы одна из задач проекта имеет статус сроков "Задержка" и в проекте нет задач со статусом "Срыв";
  • Срыв – хотя бы одна из задач проекта имеет статус сроков "Срыв";
  • Ресурсы:
  • План – все задачи проекта имеют статус ресурсов "План";
  • Освобождены – хотя бы одна из задач проекта имеет статус ресурсов "Освобождены" и в проекте нет задач со статусом "Выделены" / "Мало" / "Критично";
  • Выделены – хотя бы одна из задач проекта имеет статус ресурсов "Выделены" и в проекте нет задач со статусом "Мало" / "Критично";
  • Мало – хотя бы одна из задач проекта имеет статус ресурсов "Мало" и в проекте нет задач со статусом "Критично";
  • Критично – хотя бы одна из задач проекта имеет статус ресурсов "Критично";
  • Бюджеты:
  • План – все задачи проекта имеют статус бюджетов "План";
  • Соблюдение – хотя бы одна из задач проекта имеет статус бюджетов "Соблюдение" и в проекте нет задач со статусом "Экономия" / "Превышение" / "Не исполняется";
  • Экономия – хотя бы одна из задач проекта имеет статус бюджетов "Экономия" и в проекте нет задач со статусом "Превышение" / "Не исполняется";
  • Превышение – хотя бы одна из задач проекта имеет статус бюджетов "Превышение" и в проекте нет задач со статусом "Не исполняется";
  • Не исполняется – хотя бы одна из задач проекта имеет статус бюджетов "Не исполняется";
  • Риски:
  • Не заявлены – для всех задач проекта не зарегистрировано ни одного риска;
  • Актуальны – хотя бы для одной задачи проекта имеется риск в статусе "Актуален" и нет ни одной задачи с риском в статусе "Сработал";
  • Сработали – имеется хотя бы одна задача, у которой риск определен в статусе "Сработал";
  • Не актуальны – имеется хотя бы одна задача, для которой риск находится в статусе "Потерял актуальность" и нет ни одной задачи, для которой риск зарегистрирован в статусе "Актуален" / "Сработал";
  • Закрыты – для всех задач риски имеют статус "Закрыт";
  • Краткий статус проекта – текстовое поле для ввода информации об общих итогах статуса проекта.

    • Закладка "Задачи / Активности"

  • Кнопка Заполнить задачи/активности – заполняет табличные части "Выполненные задачи/активности", "Выполняемые задачи/активности" и "Ближайшие задачи/активности".

    • Табличная часть "Выполненные задачи/активности"

    Табличная часть "Выполненные задачи/активности" заполняется проектными задачами, которые планируется завершить не позже чем через 7 календарных дней от текущей даты документа.

    Табличная часть "Выполняемые задачи/активности"

    Табличная часть "Выполняемые задачи/активности" заполняется проектными задачами, в сроки выполнения которых входит текущая дата документа.

    Табличная часть "Ближайшие задачи/активности"

    Табличная часть "Ближайшие задачи/активности" заполняется проектными задачами, которые планируется начать не позже чем через 7 календарных дней от текущей даты документа.

    Закладка "Вопросы"

  • Кнопка Заполнить вопросы – при заполненном реквизите "Предыдущий статус-отчет" заполняет табличную часть "Вопросы на контроле" вопросами из предыдущего статус-отчета.

    • Табличная часть "Вопросы на контроле"

    Табличная часть "Вопросы на контроле" заполняется вопросами по проекту, находящимися на контроле.

    Табличная часть заполняется автоматически:

  • при создании нового документа "Статус-отчет по проекту" на основании выбранного документа "Статус-отчет по проекту";
  • при ручном заполнении реквизита "Предыдущий статус-отчет" и положительном ответе на запрос системы о перезаполнении % динамики и вопросов на контроле.

    • Табличная часть "Вопросы (новые), требующие решения"

    Табличная часть "Вопросы (новые), требующие решения" заполняется новые выявленные вопросы, требующими решения.

    Закладка "Риски"

  • Кнопка Заполнить риски – заполняет табличную часть рисками, зарегистрированными для проекта;
  • Кнопка Риски – открывает справочник Риски проектов с отбором по текущему проекту для просмотра списка рисков проекта;
  • Кнопка Добавить – добавляет строку в табличную часть для внесения незарегистрированного ранее риска по проекту вручную.

    • Табличная часть содержит следующие колонки:

  • N – порядковый номер строки, заполняется автоматически;
  • Риск – наименование, описание риска. При автоматическом заполнении табличной части с использованием кнопки Заполнить риски, поле заполняется значением реквизита "Наименование" из карточки Риска проекта;
  • Тип риска – классификационная характеристика риска, которая позволяет отнести его к определённой категории в зависимости от источника или области воздействия. При автоматическом заполнении табличной части с использованием кнопки Заполнить риски, поле заполняется значением реквизита "Тип риска" из карточки Риска проекта;
  • Последствия – предполагаемые последствия или воздействия наступления риска. При автоматическом заполнении табличной части с использованием кнопки Заполнить риски, поле заполняется значением реквизита "Последствие/Воздействие" с закладки "Параметры" карточки Риска проекта;
  • Тип реакции – тип реакции на риск. При автоматическом заполнении табличной части с использованием кнопки Заполнить риски, поле заполняется значением реквизита "Тип реакции" из карточки Риска проекта;
  •  Вероятность, % - вероятность возникновения риска в %. При автоматическом заполнении табличной части с использованием кнопки Заполнить риски, поле заполняется значением реквизита "Вероятность возникновения, %" с закладки "Параметры" карточки Риска проекта;
  • Действия – описание действий по реагированию на риск. При автоматическом заполнении табличной части с использованием кнопки Заполнить риски, поле заполняется значением реквизита "Описание" стратегии реагирования на риск с закладки "Действия" карточки Риска проекта;
  • Статус – текущий статус риска, выбирается одно из предопределённых значений: "Не заявлены", "Закрыты", "Не актуальны", "Актуальны", "Сработали";
  • Ответственный – лицо ответственное за предупреждающие действия по риску, элемент справочника Сотрудники. При автоматическом заполнении табличной части с использованием кнопки Заполнить риски, поле заполняется значением реквизита "Ответственный за предупреждающие действия" с закладки "Действия" карточки Риска проекта.

    • Закладка "Сведения о проекте"

  • Кнопка Заполнить сведения о проекте – заполняет реквизиты данными из паспорта проекта, указанного в реквизите "Проект";
  • Заказчик (куратор) проекта – сотрудник предприятия, выполняющий функции куратора проекта, элемент справочника Сотрудники;
  • Руководитель проекта – сотрудник предприятия, выполняющий функции руководителя проекта, элемент справочника Сотрудники;
  • Организация — элемент справочника Организации. Этот реквизит показывает, какой организацией выполняется проект.
  • Бизнес-единица – элемент справочника Подразделения. Данный реквизит показывает, каким из подразделений предприятия выполняется проект.
  • Тип проекта – элемент справочника Типы проектов;
  • Портфель проектов – элемент справочника Портфели проектов. Данный реквизит показывает, какому портфелю проектов принадлежит данный проект.
  • Программа проектов – элемент справочника Программы проектов. Данный реквизит показывает, к какой программе проектов принадлежит данный проект.
  • Начало проекта – плановая дата начала проекта;
  • Окончание проекта – плановая дата окончания проекта;
  • Дата начала, прогноз – прогнозируемая дата старта проекта;
  • Дата завершения, прогноз – прогнозируемая дата окончания проекта;
  • Статус сроков – экспертная оценка соблюдения прогнозируемых сроков;
  • % готовности проекта – экспертная оценка готовности проекта;
  • Статус проекта – текущий статус проекта;
  • Цель проекта – описание цели проекта.

    • Закладка "Протокол встречи"

  • Дата встречи – дата проведения встречи. По умолчанию заполняется текущей датой.
  • Место встречи – место проведения встречи.

    • Табличная часть "Участники встречи"

    Табличная часть "Участники встречи" заполняется списком участников встречи.

    Табличная часть "Ход встречи"

    Табличная часть "Ход встречи" заполняется основными задачами, решаемыми в ходе встречи.

    Табличная часть "Принятые решения"

    Табличная часть "Принятые решения" заполняется принятыми в ходе встречи решениями.
