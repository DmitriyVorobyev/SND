Документ Сохранение данных проекта

Назначение

Документ "Сохранение данных проекта" предназначен для сохранения данных текущего (актуального) плана проекта при выполнении обработки Управление данными проекта.

Форма объекта

Поскольку документ является служебным и не предназначен для ручного ввода и ручной коррекции пользователем, форма документа не позволяет пользователю модифицировать ключевые реквизиты документа, эти реквизиты доступны только для чтения.

Важно! Не рекомендуется вручную выполнять какие-либо операции с документами "Сохранение данных проекта" (повторное проведение, отмена проведения), т.к. это может привести к нарушению ранее настроенного порядка проектных задач.
