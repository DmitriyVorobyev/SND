Документ Копирование задач в сводный проект

Назначение

Документ "Копирование задач в сводный проект" предназначен для формирования структуры сводных проектов, в которые отбираются проектные задачи из других проектов (создаются копии задач) по какому-либо признаку: вид операции, подразделение, сроки и т.д.

Важно! Документ позволяет копировать только задачи в статусах "Запланирована" и "Выполняется".

Форма объекта

При формировании документа необходимо заполнить следующие обязательные реквизиты:

  • Номер документа – уникальный номер документа, формируется автоматически;
  • Дата – дата документа, по умолчанию подставляется текущая дата;
  • Сводный проект – сводный проект, элемент справочника Проекты, в который будут скопированы выбранные проектные задачи.

    • Кнопка Структура проекта открывает структуру сводного проекта.

    Отбор

    В группе "Отбор" расположены настройки отбора копируемых проектных задач.

  • Вид операции – выбор вида операции, по которому будут отбираться проектные задачи для копирования;
  • Подразделение роли – отбор задач по подразделению роли трудового ресурса, указанному в карточке проектной задачи на закладке "Ресурсы" → "Роли трудовых ресурсов";
  • Период – отбор задач, входящих в указанный период (будут подобраны задачи, хотя бы частично попадающие в указанный период);
  • Отбирать задачи нескопированные ранее – если опция включена, будут подбираться проектные задачи, которые соответствуют прочим условиям отбора и ранее не копировались в указанный проект. Если опция отключена, будут подбираться все проектные задачи, соответствующие условиям отбора;
  • Проекты-источники – если опция включена, становится доступна табличная часть "Проекты-источники" для указания списка проектов, из которых будут отбираться проектные задачи для копирования. Список можно заполнить с помощью универсального механизма заполнения табличной части (кнопка Подбор) или вручную (кнопка Добавить).

  • Переносить плановые трудозатраты с окончательного уровня на предварительный – если опция включена, при копировании задачи в сводный проект у создаваемой копии задачи план трудозатрат по Окончательному уровню планирования будет перенесен на Предварительный уровень.

    • Важно! При переносе плановых трудозатрат, данные с Окончательного уровня полностью заменяют данные Предварительного уровня.

    Табличная часть "Копируемые задачи"

    Табличная часть "Копируемые задачи" заполняется (кнопка Заполнить) задачами, соответствующими установленным параметрам отбора. При необходимости, лишние задачи можно удалить вручную.

    Важно! Нельзя заполнять табличную часть без установки отбора.

    Табличная часть содержит колонки:

  • Проект – проект, в который входит копируемая проектная задача;
  • Код СДР – код СДР копируемой проектной задачи;
  • Задача – наименование копируемой проектной задачи;
  • Дата начала – плановая дата начала копируемой проектной задачи;
  • Дата завершения – плановая дата завершения копируемой проектной задачи;
  • Статус – статус копируемой проектной задачи;
  • Скопирована ранее – отметка о том, что данная проектная задача уже бала скопирована в указанный сводный проект. Колонка отображается только при отключенной опции "Отбирать задачи не скопированные ранее".

    • Важно! Если у задачи есть отметка о том, что данная проектная задача уже бала скопирована в указанный сводный проект, при проведении документа она будет повторно скопирована в этот проект (т.е. будет создана еще одна копия задачи).

    Важно! После заполнения табличной части, выбор сводного проекта и настройки отбора будут закрыты для редактирования. При необходимости изменить настройки необходимо вручную очистить табличную часть.

    После проведения документа, в структуре сводного проекта будут созданы копии отобранных проектных задач. У копий задач будут установлены те же сроки, что и у копируемых задач.

    Важно! После проведения документ будет закрыт для редактирования. Для внесения изменений необходимо отменить проведение документа. При этом будет выдано предупреждение о том, что будут удалены все копии задач, созданный документом.

    Важно! Для актуализации данных созданных копий проектных задач необходимо повторно провести документ.
