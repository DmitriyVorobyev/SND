Документ Старт проектных работ

Назначение

Жизненный цикл проекта состоит из ряда последовательных стадий: Инициация проекта → Утверждение проекта → Старт (запуск) проекта  → Выполнение проекта → Остановка проекта → Возобновление проекта → Завершение проекта. Документ "Старт проектных работ" предназначен для фиксирования в системе факта того, что начались работы по выполнению данного проекта, то есть, производится перевод проекта из статуса "Утвержден" в статус "Выполняется".

Документом "Старт проектных работ" можно начать работы по проекту, который находится в состоянии "Утвержден". Рекомендуется вводить этот документ в режиме ввода на основании, основанием служит документ Утверждение плана проекта.

Форма объекта

При создании документа "Старт проектных работ" необходимо заполнить следующие реквизиты:

  • Номер документа – формируется автоматически при записи документа;
  • Дата – по умолчанию текущая дата;
  • Проект – элемент справочника Проекты, при вводе на основании данное поле заполняется автоматически;
  • Документ-основание – в данное поле автоматически вписывается документ Утверждение плана проекта, на основании которого был введен документ "Старт проектных работ".
  • Комментарий – произвольный текст.
