Документ Ручная актуализация проекта

Назначение

Документ предназначен для ввода в систему данных о текущем состоянии и проценте выполнения проектных задач.

Использование документа имеет смысл в том случае, если изменение сроков проектных задач производится модификацией непосредственно документа Проектная задача, а изменения статуса и процента выполнения проектной задачи – при помощи документа "Ручная актуализация проекта".

Важно! Выполнить актуализацию данных о текущем состоянии и проценте выполнения проектных задач можно только для проекта, который находится в статусе "Выполняется" или "Остановлен".

Форма объекта

При создании документа "Ручная актуализация проекта" необходимо заполнить следующие реквизиты:

  • Номер документа – формируется автоматически при записи документа;
  • Дата – по умолчанию текущая дата;
  • Проект – проект-основание, по которому вводится данный документ "Ручная актуализация проекта"

    • Заполнение табличной части "Текущее состояние проектных задач"

    Для работы с табличной частью "Текущее состояние проектных задач" предусмотрены кнопки:

  • Добавить / Подобрать – открывают форму подбора в табличную часть всех проектных задач, относящихся к данному проекту, из которых необходимо выбрать проектные задачи для актуализации.
  • Заполнить → Всеми задачами – заполняет табличную часть всеми проектными задачами выбранного в документе проекта.
  • Заполнить → Задачами с фактическими трудозатратами ресурсов – заполняет табличную часть проектными задачами, по которым введены фактические трудозатраты трудовых ресурсов с помощью документов Распределение рабочего времени за неделю, Табель учета рабочего времени и Прогноз трудозатрат по ролям. При этом процент готовности будет рассчитан через отношение фактических трудозатрат к плановым. Для расчета плановых трудозатрат берутся трудозатраты по окончательному уровню планирования, а если на окончательном уровне трудозатраты не внесены, то берутся трудозатраты по предварительному уровню планирования.
  • Рассчитать → Рассчитать процент готовности этапов проекта по длительности – процент готовности этапа будет рассчитан с учетом процента готовности и длительности по вложенным в этап проектным задачам.

    • Описание процесса выполнения расчета:
    Для каждой задачи этапа:
    Выполненная длительность, ч. = [Длительность ПЗ в часах] * ([Процент готовности ПЗ] / 100)
    Плановая длительность, ч. = [Длительность ПЗ в часах]
    Суммарные значения по этапу     (суммируются полученные значения по всем проектных задачам, подчиненным этапу):
    Выполненное время, ч. = ∑ Выполненная длительность, ч.
    Плановое время, ч. = ∑ Плановая длительность, ч.
    Расчёт для этапа:
    Процент готовности этапа по длительности = (Выполненное время, ч. / Плановое время, ч.) * 100%
    Расчет выполняется для каждого этапа проекта.

  • Рассчитать → Рассчитать процент готовности этапов проекта с учетом трудозатрат – процент готовности этапа будет рассчитан с учетом процента готовности и факта по трудозатратам по вложенным в этап проектным задачам.
    Уровень планирования трудозатрат, значения по которому будут использованы для расчета процента готовности проектных задач, задается в реквизите "Настройка уровня планирования при расчете готовности проекта" в карточке проекта.

    • Описание процесса выполнения расчета:
    Для каждой задачи этапа:
    Выполненные трудозатраты, ч. = [Трудозатраты ПЗ в часах] * ([Процент готовности ПЗ] / 100)
    Плановые трудозатраты, ч. = [Трудозатраты ПЗ в часах]
    Если данные о трудозатратах на уровне планирования в ПЗ отсутствуют, вместо них используется длительность ПЗ в часах:
    Плановые трудозатраты, ч. = [Длительность ПЗ в часах]
    Суммарные значения по этапу (суммируются полученные значения по всем проектных задачам, подчиненным этапу):
    Выполненное время, ч. = ∑ Выполненные трудозатраты, ч.
    Плановое время, ч. = ∑ Плановые трудозатраты, ч.
    Расчёт для этапа:
    Процент готовности этапа с учетом трудозатрат = (Выполненное время, ч. / Плановое время, ч.) * 100%
    Расчет выполняется для каждого этапа проекта.

    При заполнении табличной части документа рекомендуется действовать следующим образом:

  • В случае, если необходимо ввести информации о подавляющем большинстве проектных задач проекта, необходимо вначале вызвать функцию автоматического заполнения табличной части (кнопка Заполнить → Всеми задачами), а затем удалить из табличной части те строки, заполнение которых не требуется.
  • В случае если необходимо ввести информацию о малом или единичном количестве проектных задач, необходимо воспользоваться универсальной формой подбора (кнопка Добавить / кнопка Подобрать).

    • Реквизиты табличной части "Текущее состояние проектных задач":

  • Проектная задача – проектная задача, относящаяся к выбранному проекту.
  • Статус задачи – зависит от процента готовности:
  • Запланирована – если 0% готовности;
  • Выполняется – если больше 0% и меньше 100% готовности;
  • Завершена – если 100% готовности.
  • Готовность, % – процент готовности.
  • Дата начала, факт – фактическая дата начала выполнения проектной задачи.
  • Дата завершения, факт – фактическая дата окончания выполнения проектной задачи.

    • Важно! Проведение документа "Ручная актуализация проекта" не оказывает никакого влияния на календарные сроки проектных задач.

    Примечание.

  • Установленный вручную процент готовности этапов может быть перезаписан при сохранении структуры проекта, если в системе установлена опция "Автоматически рассчитывать процент готовности этапов проекта" в Параметрах подсистемы PM или опция "Пересчитывать процент готовности этапов" в структуре проекта (доступна в меню кнопки "Ещё");
  • Процент готовности проектных задач, не являющихся этапами, может быть изменен вручную документе Проектная задача или в структуре проекта.
