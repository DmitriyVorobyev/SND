Документ Регистрация оперативной загрузки специалистов

Назначение

Документ "Регистрация оперативной загрузки специалистов" предназначен для оперативного распределения почасового времени трудовых ресурсов между задачами разных проектов.

Это служебный документ, не предназначенный для интерактивной работы.
