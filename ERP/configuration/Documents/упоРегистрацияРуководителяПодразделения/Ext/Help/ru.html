Документ Регистрация руководителя подразделения

Назначение

У каждого подразделения организации может быть руководитель (тот или иной сотрудник). Документ "Регистрация руководителя подразделения" предназначен для регистрации руководителей подразделений организации.

В один момент времени руководителем подразделения может являться один и только один сотрудник.

Документ "Регистрация руководителя подразделения" позволяет:

  • Фиксировать и хранить в системе информацию о том, руководителем какого подразделения является тот или иной сотрудник.

    • Важно! Поскольку справочник Подразделения имеет иерархическую структуру (подчиненность), то при назначении руководителя, эта иерархическая структура учитывается. То есть, по умолчанию, руководителем подчиненных подразделений становится назначенный сотрудник (если для них до этого не был назначен свой руководитель).

    Форма объекта

    При создании документа "Регистрация руководителя подразделения" необходимо заполнить следующие обязательные реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию — текущая дата;
  • Подразделение — из справочника Подразделения выбирается подразделение, которому назначается руководитель. Данный реквизит не заполняется в случае, если руководителя требуется сместить;
  • Руководитель — из справочника Сотрудники выбирается сотрудник, который назначается на должность руководителя подразделения данным документом.
