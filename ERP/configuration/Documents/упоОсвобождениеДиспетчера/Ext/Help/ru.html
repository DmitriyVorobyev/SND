Документ Освобождение диспетчера

Назначение

Документ "Освобождение диспетчера" предназначен для фиксирования информации о том, что диспетчер (пользователь) более не является диспетчером для того или иного сотрудника, ранее закрепленного за этим диспетчером.

Форма объекта

При создании документа "Освобождение диспетчера" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию - текущая дата;
  • Диспетчер (пользователь) — выбирается из справочника Пользователи.

    • Табличная часть документа "Освобождение диспетчера" заполняется назначаемыми на управление пользователю сотрудниками. Заполнение происходит следующим образом:

  • Автоматически — с помощью кнопки Заполнить;
  • Вручную — по кнопке Добавить на панели инструментов или с помощью клавиши Insert.

    • Важно! Заполнение табличной части документа вручную не рекомендуется: если в документ будут внесены сотрудники, которыми данный диспетчер (пользователь) не управляет, документ не проведется.
