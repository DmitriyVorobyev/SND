Документ Регистрация состава подразделения

Назначение

Документ "Регистрация состава подразделения" предназначен для управления составом подразделения и ввода в систему данных о том, в какое подразделение входит та или иная роль. Документ "Регистрация состава подразделения" позволяет:

  • Фиксировать и хранить в системе информацию о том, какая роль трудовых ресурсов в какое подразделение входит.

    • Форма объекта

    При создании документа "Регистрация состава подразделения" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию — текущая дата.
  • Подразделение — из справочника Подразделения выбирается подразделение, состав которого фиксируется данным документом.

    • Табличная часть документа заполняется списком ролей следующим образом:

  • С помощью универсального механизма заполнения табличной части — кнопки Подобрать;
  • Вручную — по кнопке Добавить на панели инструментов или с помощью клавиши Insert.
