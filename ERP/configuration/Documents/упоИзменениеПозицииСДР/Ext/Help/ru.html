Документ Изменение Позиции СДР

Назначение

Документ "Изменение позиции СДР" предназначен для пакетного пересчёта СДР-кодов проектных задач с принудительным изменением позиции выбранной проектной задачи в общем списке задач. 

Форма объекта

Поскольку документ является служебным и не предназначен для ручного ввода и ручной коррекции пользователем, форма документа не позволяет пользователю модифицировать ключевые реквизиты документа, эти реквизиты доступны только для чтения.

Реквизиты документа

Документ содержит следующие реквизиты (заполняются автоматически при создании документа):

  • Проектная задача — документ Проектная задача, та проектная задача, позицию которой необходимо изменить;
  • Направление движения по СДР — перечисление, определяет, каким именно образом будет произведено изменение позиции проектной задачи в общем списке, может принимать следующие значения:
  • Не перемещать — позиция проектной задачи не изменяется, производится только пересчёт СДР-кодов;
  • На строку вверх — проектная задача будет перемещена на одну строку вверх по своей ветке иерархии СДР;
  • На верхнюю строку — проектная задача будет перемещена на самую первую строку в своей ветке иерархии СДР;
  • На строку вниз — проектная задача будет перемещена на одну строку вниз по своей ветке иерархии СДР;
  • На нижнюю строку — проектная задача будет перемещена на самую последнюю строку в своей ветке иерархии СДР.

    • Табличных частей документ "Изменение позиции СДР" не содержит.

    Важно! Не рекомендуется вручную выполнять какие-либо операции с документами "Изменение позиции СДР" (повторное проведение, отмена проведения), т.к. это может привести к нарушению ранее настроенного порядка проектных задач.
