Документ Прогноз трудозатрат по ролям

Назначение

Документ "Прогноз трудозатрат по ролям" позволяет выявить простои или перегрузки ролей трудовых ресурсов за выбранный период по всем проектам, проанализировать причины их появления и предпринять необходимые меры для их устранения. Помимо этого, документ можно использовать для формирования отчета подразделения за выбранный период.

Документ позволяет ознакомиться с фактическими трудозатратами до периода документа и за отчетный период, перераспределить (актуализировать) загрузку роли по месяцам в соответствии со сроками проектных задач и указанными фактическими трудозатратами. Для этого необходимо распределить часы по месяцам в рамках сроков проектных задач, чтобы добиться относительно равномерной общей загрузки роли трудового ресурса за выбранный в документе период. Часы распределяются автоматически по профилям пересчета трудозатрат, с возможностью ручной корректировки. При использовании профилей пересчета трудозатрат рекомендуется заполнять документ последовательно - слева направо (сначала фактические трудозатраты, затем плановые данные по периодам).

Если нет возможности перераспределить загрузку роли так, чтобы уложиться в первоначальные сроки задачи и при этом избежать перегрузок и простоев можно поступить следующим образом:

  • Выбрать необходимую проектную задачу и из документа "Прогноз трудозатрат по ролям" двойным щелчком по задаче открыть обработку Структура проекта. Система откроет структуру проекта с позиционированием на выбранной проектной задаче. Откорректировать сроки задачи.
  • Распределить трудозатраты документа за пределами первоначальных сроков (если такие периоды попали в документ).

    • Форма объекта

    На командной панели расположены кнопки для управления настройками формирования и поведения документа:

  • Провести и закрыть – провести и закрыть документ;
  • Записать – сохранить изменения в документе, но не проводить его;
  • Провести – провести документ;
  • Перейти → Анализ выполнимости – открыть обработку Анализ выполнимости проектов. При открытии обработки через документ, в нее передаются следующие настройки из документа:
  • Период;
  • Подразделения (если указаны в документе);
  • Роли трудовых ресурсов (если указаны в документе);
  • Уровень планирования:
  • Если в документе указан уровень планирования "Предварительный", то в обработке отжата кнопка Окончательный уровень;
  • Если в документе указан уровень планирования "Окончательный", то в обработке нажата кнопка Окончательный уровень;
  • Проекты – в обработку передаются проекты, либо указанные в параметрах документа, либо те, которые попали в табличную часть документа (на вкладке "Прогноз").
  • Перейти → Анализ изменений по документу – открыть отчет Анализ изменений по документу "Прогноз трудозатрат по ролям". Отчет позволяет получить информацию о первоначальных данных заполнения табличной части документа (по данным проекта), об изменениях, внесенных в табличную часть документа, а также вывести отклонения, полученные в результате внесения новых данных. Отчет отображает изменения, внесенные при последней корректировке табличной части документа, промежуточные значения отчет не отображает;
  • Заполнить – заполнить документ в соответствии с выбранными настройками периода, порядка группировок, уровня планирования и отборами по подразделениям, ролям и проектам.

    • Вкладка "Основное"

    На вкладке "Основное" расположены поля и опции для настройки формирования данных в табличной части документа:

  • Номер – присваивается автоматически при записи документа;
  • Дата – по умолчанию текущая дата;
  • Период с … по … – выбор периода времени, для которого формируется и заполняется плановыми трудозатратами ролей трудовых ресурсов документ (выбранный период отображается прямо на кнопке);
  • Отчетный период – отчетный месяц, по которому в документе отражаются фактические трудозатраты, заполняется автоматически на основании периода документа (месяц до периода документа).

    • Отборы

  • Подразделения – позволяет установить отбор по ролям, зарегистрированным в указанных подразделениях;
  • Роли – позволяет установить отбор по указанным ролям;

    • Важно! Если установлен отбор по подразделениям, то для установки дополнительного отбора по ролям доступны только те роли, которые зарегистрированы в выбранных подразделениях документами Регистрация состава подразделения и Изменение состава подразделения. Если отбор по подразделениям не установлен, то при установке отбора по ролям к выбору доступны все роли.

  • Проекты – позволяет установить отбор по указанным проектам.

    • Настройки

  • Порядок группировок – позволяет выбрать один из двух вариантов выведения данных в табличной части:
  • Роль / Проект / Задача – группировка данных по ролям;
  • Проект / Задача / Роль – группировка данных по проектам.

    • При создании нового документа по умолчанию заполняется значением "Роль / Проект / Задача".

  • Профиль настроек – позволяет выбрать один из профилей настроек документа, элемент справочника Профили настроек документа "Прогноз трудозатрат по ролям". Автоматически заполняется значением соответствующего реквизита из Параметров подсистемы PM. При установке профиля настроек становятся недоступными для выбора / отключения опции "Актуализировать план до периода по фактическим данным", "Записывать факт отчетного период", "Записывать процент готовности", "Автоматический расчет процента готовности" и "Не уменьшать записанный процент готовности".
  • Уровень планирования – позволяет установить отбор по уровню планирования ролей:
  • Предварительный;
  • Окончательный.
  • Актуализировать план предварительного уровня по окончательному – опция доступна только при выборе уровня планирования "Окончательный". Если опция включена, при проведении документа, для вышестоящих по иерархи этапов плановые трудозатраты роли трудового ресурса по предварительному уровню планирования будут актуализированы по плановым трудозатратам роли трудового ресурса по окончательному уровню планирования (при совпадении подразделений);
  • Актуализировать план до периода по фактическим данным – если опция включена, при проведении документа, плановые трудозатраты роли трудового ресурса до периода планирования (периода документа) будут актуализированы по фактическим данным, указанным в табличной части документа в колонке "Факт до отч.периода";
  • Записывать факт отчетного периода – если опция включена, становится доступной возможность ручного ввода фактических трудозатрат роли трудового ресурса за отчетный период в табличную часть вкладки "Прогноз", а также запись внесенных данных при проведении документа;
  • Записывать процент готовности – если опция включена, становится доступной возможность расчета и ручного ввода процента готовности проектных задач в табличной части вкладки "Прогноз", а также запись внесенных данных при проведении документа;
  • Автоматический расчет процента готовности – если опция включена, процент готовности проектных задач будет рассчитываться автоматически на основании актуального плана и факта трудозатрат. Опция доступна только при включении опции "Записывать процент готовности";
  • Не уменьшать записанный процент готовности – если опция включена, при автоматическом расчете процента готовности полученное значение будет записано только в том случае, если оно больше ранее введенного. Опция доступна только при включении опции "Автоматический расчет процента готовности".

    • Вкладка "Прогноз"

    На вкладке "Прогноз" расположены кнопки для работы с табличной частью документа, кнопка вызова Диаграммы и табличная часть, в которой отображается плановая загрузка ролей трудовых ресурсов. При установке отбора по подразделениям, ролям и / или проектам на вкладке "Основное", в верхней части вкладки "Прогноз" отображается перечень выбранных параметров.

  • Отменить запись для всех – снять флаг "Записать" у всех строк табличной части. В этом случае данные сохранятся в документе, но не попадут в регистры системы и будут доступны для анализа только из самого документа;
  • Установить запись для всех – установить флаг "Записать" для всех строк табличной части. В этом случае все внесенные изменения отразятся в регистрах системы и будут доступны для анализа в отчетах;
  • Рассчитать по профилям – трудозатраты ролей трудовых ресурсов перераспределятся согласно указанным профилям пересчета для проектных задач. Если трудозатраты по периодам были внесены вручную, то данные до и за такие периоды сохранятся;
  • Выделенные строки – команда содержит опции контекстного меню, которые можно применить к выделенным проектным задачам в документе;
  • Диаграмма – показать / скрыть диаграмму для графического отображения загрузки ролей трудовых ресурсов, фактических трудозатрат, наличия простоев и перегрузок по трудовым ресурсам за период с отбором по ролям. При включении отображения диаграммы становится доступно поле "Диаграмма по роли":
  • Диаграмма по роли – роль трудового ресурса, по которой будет производиться отбор данных для отображения на диаграмме.
  • Свернуть уровни – сворачивает строки табличной части документа до верхнего уровня;
  • Развернуть уровни – разворачивает строки табличной части документа до нижнего уровня;
  • Показать легенду цветов документа – показать / скрыть легенду с описанием индикации статусов проектных задач в табличной части документа и сценарий работы с документом;
  • Уровень группировок – позволяет выбрать одну из настроек уровня группировок строк в табличной части документа. Доступные варианты настроек уровня группировок строк зависят от выбранного порядка группировки:
  • для порядка группировки "Проект / Задача / Роль" – Проекты, Задачи, Роли, Подразделения;
  • для порядка группировки "Роль / Проект / Задача" – Роли, Подразделения, Проекты, Задачи.

    • При создании документа по умолчанию заполняется значением нижнего уровня установленной группировки.

    Важно! В табличную часть документа не попадают проектные задачи в статусе "Завершена".

    Табличная часть заполняется по кнопке Заполнить:

  • Группировка "Роль/Подразделение/Проект/Задача" или "Проект/Задача/Роль/Подразделение" – заполняется в соответствии с выбранным порядком группировки:
  • Проект обозначен иконкой ();
  • Проектная задача обозначена иконкой (, , );
  • Роль обозначена иконкой ();
  • Подразделение обозначено иконкой ().
  • % готовности:
  • по строке – процент готовности проектной задачи, оцениваемый для роли подразделения. Поле становится доступным для ручного ввода только при включенной опции "Записывать процент готовности" на вкладке "Основное". Ввести / отредактировать процент готовности можно только по проектным задачам проектов, находящихся в статусе "Выполняется";
  • задачи – процент готовности задачи с учетом внесенного факта на момент заполнения документа. Рассчитывается общий процент готовности задачи по данным документа и тем данным, которые не попали в табличную часть документа, но относятся к проектной задаче. Зеленым цветом выделяются строки, в которых процент готовности проектной задачи был вручную изменен с любого значения на 100.

    • Важно! По строкам табличной части, для которых не установлен флаг в колонке "Записать", при проведении документа данные о проценте готовности не будут перенесены в соответствующие проектные задачи.

  • Текущие сроки – плановые даты начала и завершения проектной задачи;
  • Сроки по загрузке – месяцы начала и завершения проектной задачи по трудозатратам ролей трудовых ресурсов:
  • Зеленым цветом выделяются сроки по загрузке, которые либо начинаются раньше даты начала проектной задачи, либо заканчиваются раньше даты окончания проектной задачи;
  • Красным цветом выделяются сроки по загрузке, которые либо начинаются позже даты начала проектной задачи, либо заканчиваются позже даты окончания проектной задачи;
  • Х (крестик) - в прогнозируемом периоде отсутствует план трудозатрат .
  • Базовый план – данные по трудозатратам роли трудового ресурса по базовой (утвержденной) версии плана;
  • Текущий план:
  • по строке – сумма всех трудозатрат роли трудового ресурса по текущей версии плана по проектной задаче;
  • до отч.периода – трудозатраты роли трудового ресурса по текущей версии плана до периода документа;
  • [отчетный период] – трудозатраты роли трудового ресурса по текущей версии плана, запланированные на отчетный период.
  • Факт:
  • по строке – сумма всех фактических трудозатрат роли трудового ресурса по проектной задаче;
  • до отч.периода – фактические трудозатраты роли трудового ресурса до периода документа;
  • [отчетный период] – фактические трудозатраты роли трудового ресурса за отчетный период. Данные заполняются из документов Табель учета рабочего времени, Распределение рабочего времени за неделею, "Прогноз трудозатрат по ролям". Поле доступно для ручного ввода, если перечисленные документы не сформированы, а также включена опция "Записывать факт отчетного периода" на вкладке "Основное".

    • Важно! Списание фактических трудозатрат в документе возможно только для задач, на которые не назначены конкретные трудовые ресурсы. При проведении документа по внесенным данным будут списаны фактические трудозатраты ролей. При этом используется предопределенный трудовой ресурс "Сводный ресурс". В связи с отсутствием возможности регистрации стоимости Сводного ресурса, при списании будут учитываться стоимости ролей трудовых ресурсов.

    Важно! При отключенной в Параметрах подсистемы PM константе "Разрешить списание часов на проектные задачи проекта в статусе "Остановлен"" запрещено проведение документа, если фактические трудозатраты списаны на задачи проекта в статусе "Остановлен".

    Важно! При отключенной в Параметрах подсистемы PM константе "Разрешить списание рабочего времени по закрытым и завершенным задачам и закрытым заданиям" запрещено проведение документа, если фактические трудозатраты указаны для проектных задач в статусе "Завершена" или "Закрыта".

  • Остаток = Текущий план по строке – Факт по строке;
  • Прогноз (по месяцам) – распределяет трудозатраты по периодам в соответствии со сроками проектной задачи и профилем распределения трудозатрат:
  • Ячейки выделяются синим цветом, если сроки по загрузке входят в сроки проектной задачи;
  • Ячейки выделяются оранжевым цветом, если сроки по загрузке не входят в сроки проектной задачи (загрузка до начала проектной задачи или после ее завершения).
  • Ост. до зав. – остаток плановых трудозатрат роли трудового ресурса после периода планирования (периода документа) до завершения проектной задачи;
  • Итого прогноз = Прогноз (по месяцам) + Ост. до зав.;
  • Откл. от текущего плана = Текущий план – (Факт + Итого прогноз);
  • Откл. от базового плана = Базовый план – (Факт + Итого прогноз);
  • Актуальный план = Факт + Итого прогноз;
  • Записывать – при установленном флаге при проведении документа сформируются движения по регистрам системы.
  • Профиль пересчета трудозатрат – позволяет выбрать один из профилей перерасчета прогноза по трудозатратам при ручном вводе фактических трудозатрат или ручной корректировке плановых данных. Автоматически заполняется значением соответствующего реквизита из Параметров подсистемы PM (группа "Значения по умолчанию"):
  • Отклонение равномерно в периоде задачи:
  • При ручном вводе фактических трудозатрат – если значение поля "Откл. от текущего плана" <> 0, то указанное значение равномерно распределяется в периоде по месяцам.
  • При ручной корректировке плановых данных – если значение поля "Откл. от текущего плана" <> 0, то при вводе плана за любой месяц в периоде документа (например, май 20), указанное значение равномерно распределяется в периоде документа начиная со следующего месяца за откорректированным (например, июнь 20) до крайнего месяца в периоде документа.

    • И/ИЛИ

  • При ручной корректировке плановых данных – если при вводе плана за любой месяц в периоде документа образовалась разница (например, в месяце трудозатраты были – 100 часов, ввели – 50 часов, тогда разница = 50 часов), полученная разница равномерно распределяется в периоде документа начиная со следующего за откорректированным месяца до крайнего месяца в периоде документа.
  • Отклонение на следующий месяц:
  • При ручном вводе фактических трудозатрат – если значение поля "Откл. от текущего плана" <> 0, то указанное значение распределяется в первый месяц указанного периода документа.
  • При ручной корректировке плановых данных – если значение поля "Откл. от текущего плана" <> 0, то при вводе плана за любой месяц в периоде документа, указанное значение распределяется в следующий за откорректированным месяц.

    • И/ИЛИ

  • При ручной корректировке плановых данных – если при вводе плана за любой месяц в периоде документа образовалась разница, полученная разница распределяется в следующий за откорректированным месяц в периоде документа.
  • Не распределять отклонение:
  • При ручном вводе фактических трудозатрат – пересчитывается значение поля "Откл. от текущего плана".
  • При ручной корректировке плановых данных – пересчитывается значение поля "Откл. от текущего плана".

    • Важно! После проведения документа значение поля "Ост. до зав." распределяется до даты завершения проектной задачи по профилю распределения, указанному в проектной задаче при планировании в структуре проекта. Если в проектной задаче указан профиль "Вручную, по месяцам", то остаток до завершения распределяется пропорционально запланированным данным.

    В нижней части таблицы выведены итоги:

  • Мощность роли трудового ресурса помесячно и за весь выбранный период;
  • Загрузка роли трудового ресурса помесячно и за весь выбранный период;
  • Остаток = Мощность – Загрузка:
  • Если остаток = 0, то загрузка роли трудового ресурса без превышения;
  • Если остаток > 0, то отражается простой роли трудового ресурса;
  • Если остаток < 0, то отражается перегрузка роли трудового ресурса.

    • Корректировать загрузку ролей трудовых ресурсов можно следующими способами:

  • Вручную изменять значения в ячейках колонок "Прогноз".
  • Полностью перенести загрузку роли по задаче на месяц вперед / назад. Для этого необходимо щелкнуть правой кнопкой мыши на строке и в контекстном меню выбрать пункт "Сдвинуть на период вправо" / "Сдвинуть на период влево".

    • Важно! В случае, если в Параметрах подсистемы PM отключена опция "Отключить разграничение доступа пользователя к проектным документам", вносить изменения в данные документа может пользователь, который является диспетчером руководителя проекта и / или руководителя проектной задачи. Если опция "Отключить разграничение доступа пользователя к проектным документам" включена, то изменять данные документа могут все пользователи, имеющие доступ к документу.

    Важно! Если документом корректируется большое количество проектных задач, рекомендуется включить опцию "Отложенное отражение плановых трудозатрат задач" в Параметрах подсистемы PM (группа "Основные параметры"). При заполнении и проведении документа будет производится контроль отражения плановых трудозатрат.

    Примечание.

  • Строки, недоступные для редактирования, выделяются белым фоном, затемненной иконкой объекта и серым текстом. При установке курсора строка будет выделена желтым цветом.
  • Строки, доступные для редактирования, выделяются белым фоном с черным текстом. При установке курсора строка будет выделена серым цветом.
