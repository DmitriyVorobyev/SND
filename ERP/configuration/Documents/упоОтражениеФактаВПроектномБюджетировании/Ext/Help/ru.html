Документ Отражение фактических данных в проектном бюджетировании

Назначение

Документ "Отражение фактических данных в проектном бюджетировании" предназначен для отражения фактических данных в проектном бюджетировании.

Важно! Для корректного формирования фактических данных предварительно необходимо настроить правила получения фактических данных в проектном бюджетировании.

Важно! Документ доступен при включенной опции "Включить использование контура "Отражение первичных документов в проектном бюджетировании" в Параметрах подсистемы PM в разделе "Проектное бюджетирование".

Форма объекта

Документ "Отражение фактических данных в проектном бюджетировании" формируется автоматически обработкой Отражение документов в проектном бюджетировании или вручную из списка документов "Отражение фактических данных в проектном бюджетировании".

Документы, сформированные с помощью обработки, при открытии отображаются в форме первичного документа, на основании которого они были сформированы. Документы, сформированные вручную, при открытии отображаются в форме документа "Отражение фактических данных в проектном бюджетировании".

Документы, по которым требуется отразить данные, отображаются в списке непроведенными. Документы, по которым были отражены данные, отображаются в списке проведенными.

К основным реквизитам документа "Отражение фактических данных в проектном бюджетировании" относятся следующие:

  • Номер документа – уникальный номер документа, формируется автоматически;
  • Дата – дата документа, по умолчания подставляется текущая дата;
  • Кнопка Ручная корректировка - позволяет корректировать данные табличной части документа вручную;
  • Кнопка Заполнить по правилу - заполняет документ фактическими данными для отражения в проектном бюджетировании.

    • Вкладка "Основное"

    На вкладке "Основное" указываются настройки для отражения фактических данных:

  • Начало периода – дата начала периода отражения данных в проектном бюджетировании;
  • Окончание периода – дата окончания периода отражения данных в проектном бюджетировании;
  • Правило отражения – правило, по которому будут заполнены данные в документе, справочник Правила получения фактических данных для проектного бюджетирования;
  • Раздел – регистр, в который будут записаны данные при проведении документа, заполняется автоматически;
  • Тип правил – данные, на основании которых заполняется документ, заполняется автоматически;
  • Правило получения факта по статьям бюджета – заполняется в случае, если выбран тип правил со значением "Бюджетирование", заполняется автоматически.

    • Вкладка "Доходы и расходы"

    При заполнении вкладки "Доходы и расходы", при проведении документа будут сформированы записи в регистре накопления "Факт доходов и расходов (обороты)".

    Табличная часть вкладки содержит реквизиты:

  • Период – дата проведения первичного документа
  • Регистратор – первичный документ, по которому производится отражение фактических данных в проектном бюджетировании;
  • Правило отражения – правило отражения фактических данных в проектном бюджетировании, справочник Правила получения фактических данных для проектного бюджетирования;
  • Проектная задача – проектная задача, по которой производится отражение фактических данных, документ Проектная задача;
  • Статья – статья доходов или расходов, по которой формируется факт отражения данных, элемент справочника Статьи доходов по проектам/Статьи затрат по проектам;
  • Вид элемента – по значению, указанному в поле "Статья", автоматически устанавливается вид элемента: Доход или Расход;
  • Подразделение – подразделение, по которому производится отражение фактических данных, элемент справочника Подразделения;
  • Роль – элемент справочника Роли трудовых ресурсов;
  • Номенклатура – номенклатура, по которой отражаются фактические данные, элемент справочника Номенклатура;
  • Единица измерения – единица измерения указанной номенклатуры;
  • Контрагент – контрагент, по которому отражаются фактические данные, элемент справочника Контрагенты;
  • Договор – договор, по которому отражаются фактические данные, элемент справочника Договоры контрагентов;
  • Валюта – валюта взаиморасчетов, элемент справочника Валюты;
  • Сценарий – элемент справочника Сценарии товарного планирования;
  • Собственные силы/субподряд - признак собственные силы / субподряд;
  • Контрагент подрядчик – элемент справочника Контрагенты;
  • Заказ договора подряда – документ Заказ поставщику;
  • Сумма – сумма отражения данных в денежном выражении в валюте управленческого учета;
  • Сумма валютная - сумма отражения в денежном выражении в валюте;
  • Количество – отражение данных в количественном выражении.

    • Вкладка "ДДС"

    При заполнении вкладки "ДДС", при проведении документа, будут сформированы записи в регистре сведения "Факт движения денежных средств".

    Табличная часть вкладки содержит реквизиты:

  • Период – дата проведения первичного документа;
  • Регистратор – первичный документ, по которому производится отражение фактических данных в проектном бюджетировании;
  • Правило отражения – правило отражения фактических данных в проектном бюджетировании, справочник Правила получения фактических данных для проектного бюджетирования;
  • Проектная задача – проектная задача, по которой производится отражение фактических данных, документ Проектная задача;
  • Статья ДДС – статья движения денежных средств, по которой формируется факт отражения данных, справочник Статьи движения денежных средств;
  • Направление движения – автоматически устанавливается направление движения статьи ДДС;
  • Контрагент – контрагент, по которому отражаются фактические данные, элемент справочника Контрагенты;
  • Договор – договор, по которому отражаются фактические данные, элемент справочника Договоры контрагентов;
  • Дата движения – дата проведения первичного документа;
  • Валюта – валюта взаиморасчетов, элемент справочника Валюты;
  • Сумма – сумма отражения данных в денежном выражении в валюте управленческого учета;
  • Сумма валютная – сумма отражения в денежном выражении в валюте.

    • Вкладка "Ошибки заполнения"

    Вкладка "Ошибки заполнения" содержит данные об ошибках, возникающих при отражении данных.
