Документ Регистрация доходов и расходов

Назначение

Документ предназначен для ввода в систему информации о фактических доходах и расходах по проектной задаче.

Рекомендуется создавать этот документ в режиме ввода на основании, основанием служит либо документ Проектная задача, либо документ Регистрация фактически выполненного объема.

Форма объекта

При формировании документа вручную необходимо заполнить следующие обязательные реквизиты шапки документа:

  • Номер документа – уникальный номер документа, формируется автоматически;
  • Дата – дата документа, по умолчанию подставляется текущая дата;
  • Проект – проект, по проектным задачам которого производится фиксация фактических доходов и расходов.

    • Заполнение табличной части "Фактически начисляемые доходы"

    Данные о фактических доходах заносятся в табличную часть "Фактические доходы". Табличную часть можно заполнить следующими способами:

  • Кнопка Добавить – добавляет новую строку в табличную часть;
  • Кнопка Подобрать → По статьям дохода – позволяет исключить лишние строки из табличной части, оставив только строки по выбранным статьям доходов;
  • Кнопка Подобрать → По контрагентам – позволяет исключить лишние строки из табличной части, оставив только строки по выбранным контрагентам;
  • Кнопка Заполнить → По текущему плану БДР – автоматически заполняет табличную часть по данным плана доходов всех задач проекта;
  • Кнопка Заполнить → По выполненным объемам – автоматически заполняет табличную часть по доходным данным документов Регистрация фактически выполненного объема для указанного проекта.

    • Табличная часть включает в себя следующие поля:

  • Проектная задача – данные о вводимом факте являются результатом данной проектной задачи;
  • Контрагент – контрагент–заказчик, элемент справочника Контрагенты;
  • Договор – договор с контрагентом–заказчиком, элемент справочника Договоры контрагентов;
  • Валюта – валюта доходов, элемент справочника Валюты. При заполнении табличной части вручную по умолчанию выбирается валюта управленческого учета, установленная в Параметрах подсистемы PM. При заполнении табличной части по данным документа-основания (при создании документа на основании проектной задачи), либо с помощью кнопки командной панели Заполнить → По текущему плану БДР, выбирается валюта, указанная в плане доходов. При заполнении табличной части с помощью кнопки командной панели Заполнить → По выполненным объемам, подставляется валюта из строк документа Регистрация фактически выполненного объема;

    • Примечание. При указании договора, если валюта договора отличается от валюты, указанной в строке, будет предложено изменить валюту строки.

  • Номенклатура – непосредственно номенклатура, по которой вводится факт доходов (доступно, если учет доходов ведется по натуральным показателям), элемент справочника Номенклатура;
  • Единица измерения – единица измерения номенклатуры (доступно, если учет доходов ведется по натуральным показателям), элемент справочника Упаковки;
  • Количество – количество доходов (доступно, если учет доходов ведется по натуральным показателям);
  • Стоимость – стоимость единицы номенклатуры (доступно, если учет доходов ведется по натуральным показателям);
  • Сумма – сумма доходов в денежном выражении;
  • Дата – дата, на которую будут отнесены фактические доходы;
  • Статья – статья доходов, элемент справочника Статьи доходов по проектам.

    • Заполнение табличной части "Распределение доходов"

  • Кнопка Добавить – добавляет новую строку в табличную часть;
  • Кнопка Заполнить → Заполнить по умолчанию – в табличную часть добавляется одна строка, в которой автоматически заполняются реквизиты значениями из табличной части "Распределение доходов" документа Проектная задача;
  • Кнопка Заполнить → Выделить НДС – выделяет сумму НДС из фактической суммы доходов, распределенной по подразделениям, при этом считается что фактическая сумма доходов указана с НДС. Для каждой из строк табличной части "Распределение доходов" вычисляется сумма НДС по ставке, указанной в договоре, либо в константе "Ставка НДС по умолчанию" в Параметрах подсистемы PM. Вычисленные суммы НДС вычитаются из строк распределения доходов и собираются в отдельной строке с признаком "НДС" в аналитике "СС/СП".

    • Важно! Поиск ставки НДС для расчетов производится в следующей последовательности (используется первое найденное значение):

  • Договор, указанный в строке доходов;
  • Реквизит "Настройка распределения БДР по умолчанию" на закладке "Опции проектной модели" в карточке проекта;
  • Константа "Ставка НДС по умолчанию" в Параметрах подсистемы PM.

    • Если для планируемых доходов была применена обработка "Распределение БДР", то в текущий документ транслируется НДС, который рассчитан в соответствии со ставкой, указанной в обработке.

    Табличная часть "Распределение доходов" позволяет распределить строчки из табличной части "Фактически начисляемые доходы" по следующим аналитикам:

  • Подразделение – элемент справочника Подразделения;
  • Специальность – элемент справочника Роли трудовых ресурсов;
  • СС/СП – признак собственные силы / субподряд, элемент справочника Собственные силы/субподряд;
  • Исполнитель – контрагент–подрядчик;
  • Заказ/Договор – договор с контрагентом–подрядчиком;
  • Количество – количество доходов (доступно, если учет доходов ведется по натуральным показателям);
  • Сумма – сумма доходов в денежном выражении.

    • Заполнение табличной части "Фактически начисляемые расходы"

    Данные о фактических расходах заносятся в табличную часть "Фактические расходы". Табличную часть можно заполнить следующими способами:

  • Кнопка Добавить – добавляет новую строку в табличную часть;

  • Кнопка Подобрать → По контрагентам – позволяет исключить лишние строки из табличной части, оставив только строки по выбранным контрагентам;

При заполнении табличной части с помощью кнопки командной панели Заполнить → По выполненным объемам, подставляется валюта из строк документа Регистрация фактически выполненного объема;

  • Количество – количество расходов (доступно, если учет расходов ведется по натуральным показателям);
  • Стоимость – стоимость единицы номенклатуры (доступно, если учет расходов ведется по натуральным показателям);
  • Сумма – сумма расходов в денежном выражении;
  • Дата – дата, на которую будут отнесены фактические расходы;
  • Статья – статья затрат, элемент справочника Статьи затрат по проектам.

    • Дополнительно

    Информация, введенная в систему посредством документа "Регистрация доходов и расходов", используется при формировании отчетов:

  • План-фактный анализ БДР;
  • План-фактный анализ БДР по подразделениям;
  • Анализ БДР по БДДС;
  • Скользящий БДР проекта;
  • Скользящий БДР, Объемы, БДДС;
  • План-фактный анализ выполненных объемов;
  • Ведомость по выполненным и принятым объемам;
  • Освоенные объемы EVA;
  • План-фактный анализ по портфелю;
  • План-фактный анализ по программе;
  • Тематический план.
