Документ Назначение трудовых ресурсов на проектную задачу

Назначение

Документ "Назначение трудовых ресурсов на проектную задачу" предназначен для ввода в систему информации о том, какие именно трудовые ресурсы предприятия предполагается использовать для выполнения той или иной проектной задачи.

При помощи документа "Назначение трудовых ресурсов на проектную задачу" можно назначить трудовые ресурсы на выполнение проектных задач всех типов ("Модель пакета работ", "Этап", "Веха").

Форма объекта

При создании документа "Назначение трудовых ресурсов на проект" необходимо заполнить следующие реквизиты:

  • Номер документа– уникальный номер документа (формируется автоматически);
  • Дата – дата документа (по умолчанию подставляется текущая дата);
  • Проект – элемент справочника Проекты, указывает на тот проект, которому принадлежит проектная задача;
  • Проектная задача – документ Проектная задача, указывает на ту задачу, на выполнение которой необходимо назначить и/или с выполнения которой необходимо освободить трудовые ресурсы.

    • Табличные части документа "Назначение трудовых ресурсов на проектную задачу" разнесены по двум закладкам.

    Закладка Назначаемые ресурсы

    На этой закладке расположена табличная часть, в которой перечисляются трудовые ресурсы, назначаемые на выполнение проектной задачи. Табличная часть содержит следующие реквизиты:

  • Трудовой ресурс – трудовой ресурс, который привлекается к выполнению проектной задачи, элемент справочника Трудовые ресурсы. По кнопке Добавить или Подобрать доступны только те трудовые ресурсы, для которых назначены роли, указанные в документе Проектная задача на закладке "Ресурсы" → "Роли трудовых ресурсов".
  • Роль трудового ресурса – указывает на то, какие именно работы будет выполнять трудовой ресурс в рамках проектной задачи, элемент справочника Роли трудовых ресурсов. Для выбора доступны роли, указанные в документе Проектная задача на закладке "Ресурсы" → "Роли трудовых ресурсов".
  • Подразделение – указывается подразделение, к которому относится трудовой ресурс, элемент справочника Структура предприятия. Для выбора доступны подразделения, указанные в документе Проектная задача на закладке "Ресурсы" → "Роли трудовых ресурсов".
  • Вариант распределения – возможны три варианта распределения:
  • По доле трудозатрат – при данном варианте распределения трудозатраты, указанные для роли в документе Проектная задача на закладке "Ресурсы" → "Роли трудовых ресурсов" распределяются между трудовыми ресурсами согласно долям, указанным в документе "Назначение трудовых ресурсов на проектную задачу". Если несколько специалистов выполняют одну и ту же роль, с помощью долей можно в процентах задать участие каждого в конкретной проектной задаче. Если один трудовой ресурс выполняет только одну роль, то в этом случае доля трудозатрат указывается – 100 %. В результате проведения документа "Назначение трудовых ресурсов на проектную задачу" будут сформированы плановые часы для трудовых ресурсов по уровню планирования "Окончательный" с учетом сроков проектной задачи и долей трудозатрат.
  • По оперативной загрузке – при данном варианте распределения плановые данные по трудозатратам для трудовых ресурсов по уровню планирования "Окончательный" будут браться из обработки Оперативная загрузка специалистов.
  • Ручное распределение – при данном варианте распределения плановые данные по трудозатратам для трудовых ресурсов по уровню планирования "Окончательный" будут браться из документа Планирование трудозатрат по трудовым ресурсам.
  • Уровень планирования – указывается уровень планирования роли трудового ресурса, из которого берутся данные по плановым трудозатратам (по умолчанию, если есть данные по окончательному уровню планирования, указывается "Окончательный", если нет – "Предварительный"). Уровень планирования можно указать только для варианта распределения "По доле трудозатрат".
  • Доля трудозатрат, % – указывается доля участия трудового ресурса в данной проектной задаче. Долю можно указать только для варианта распределения "По доле трудозатрат".
  • Комментарий – произвольный текст.

    • Закладка Освобождаемые ресурсы

    На этой закладке расположена табличная часть, в которой перечисляются трудовые ресурсы, освобождаемые от выполнения проектной задачи.

    Для заполнения табличной части рекомендуется использовать функцию автоматического заполнения трудовыми ресурсами, которые были назначены на данную проектную задачу ранее, которая запускается посредством кнопки Заполнить.

    Важно! Освободить от выполнения проектной задачи можно только тот трудовой ресурс, который ранее был назначен на выполнение именно этой проектной задачи.

    Табличная часть содержит следующие реквизиты:

  • Трудовой ресурс – элемент справочника Трудовые ресурсы, указывает на тот трудовой ресурс, который освобождается от выполнения проектной задачи.
  • Роль трудового ресурса – элемент справочника Роли трудовых ресурсов, указывает на то, какие именно работы выполнял трудовой ресурс в рамках проектной задачи.
  • Подразделение – указывается подразделение, к которому относится трудовой ресурс, элемент справочника Структура предприятия.

    • Дополнительно

    Информация, введенная в систему посредством документа "Назначение трудовых ресурсов на проектную задачу", используется при автоматическом формировании табличной части в документах Распределение рабочего времени за неделю и Табель учета рабочего времени.
