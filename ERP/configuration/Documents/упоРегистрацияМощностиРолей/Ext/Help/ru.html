Документ Регистрация мощности ролей трудовых ресурсов

Назначение

Документ "Регистрация мощности ролей трудовых ресурсов" предназначен для того, чтобы зафиксировать в системе факт о существующих и прогнозируемых ограничениях мощности трудовых ресурсов предприятия, привлекаемых к выполнению проектных работ.

Мощность роли — это то количество трудовых ресурсов, которые могут на текущий момент времени выполнять данную роль.

Документ "Регистрация мощности ролей трудовых ресурсов" позволяет:

  • Записывать и хранить в системе информацию о мощности ресурсов;
  • Анализировать совокупное количество трудовых часов для каждого конкретного дня (с помощью отчета Мощность ролей (план));
  • Анализировать загруженность ресурсов и возможность их привлечения к выполнению новых проектов (с помощью отчета Мощность ролей (план) и обработки Анализ выполнимости проектов).

    • Форма объекта

    При создании документа "Регистрация мощности ролей трудовых ресурсов" необходимо заполнить следующие реквизиты:

  • Номер документа — формируется автоматически;
  • Дата — по умолчанию - текущая дата;
  • Календарь — выбирается из справочника Рабочие календари и показывает, для какого рабочего календаря регистрируется мощность ролей трудовых ресурсов.

    • Табличная часть документа "Регистрация мощности ролей трудовых ресурсов" заполняется списком ролей и каждой роли присваивается своя мощность. Заполнение табличной части происходит следующим образом:

  • С помощью универсального механизма заполнения табличной части — кнопки Подбор;
  • Вручную — по кнопке Добавить на панели инструментов или с помощью клавиши Insert;
  • Мощность ролей проставляется вручную.
