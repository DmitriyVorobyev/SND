Документ Регистрация дополнительных затрат

Назначение

Документ "Регистрация дополнительных затрат" предназначен для ввода в систему данных о том, какие дополнительные затраты были фактически понесены при выполнении той или иной проектной задачи.

Форма объекта

При создании документа "Регистрация дополнительных затрат" необходимо заполнить следующие реквизиты:

  • Номер документа — уникальный номер документа (формируется автоматически);
  • Дата — дата документа (по умолчанию подставляется текущая дата);
  • Проектная задача — документ Проектная задача, по которой регистрируются дополнительные затраты;
  • Проект — элемент справочника Проекты, заполняется автоматически, в зависимости от выбранной проектной задачи.

    • Данные о фактических дополнительных затратах заносятся в табличную часть документа. Табличную часть можно заполнить следующими способами:

  • Вручную (кнопка командной панели Добавить);
  • Через универсальную форму подбора (кнопка командной панели Подобрать);
  • Автоматическое заполнение по данным текущего плана проекта с отбором по выбранной проектной задаче (кнопка командной панели Заполнить → По текущему плану проекта).
  • При заполнении "По текущему плану проекта" данные берутся из регистра Актуальные планы дополнительных затрат.

    • Дополнительно

    Информация, введенная в систему посредством документа "Регистрация дополнительных затрат", используется при формировании отчета Дополнительные затраты проекта (план-факт).
