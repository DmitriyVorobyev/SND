Справочник Фазы проектов

Назначение

Справочник "Фазы проектов" предназначен для хранения информации о фазах по конкретным проектам.

Форма объекта

Справочник "Фазы проектов" может быть заполнен для конкретного проекта вручную или автоматически.

Ручное заполнение справочника можно произвести через элемент справочника Проекты на закладке "Фазы". В табличной части "Таблица фаз" по кнопке Добавить при заполнении реквизита "Фаза" есть возможность создать новый элемент.

Для создания элемента справочника "Фазы проектов" необходимо заполнить следующие реквизиты:

  • Наименование – наименование фазы;
  • Код – сформируется автоматически при записи элемента;
  • Полное наименование – полное наименование фазы;
  • Проект – заполнится автоматически проектом, для которого создаются фазы.

    • Автоматическое заполнение справочника также можно произвести через элемент справочника Проекты на закладке "Фазы". Для возможности автоматического заполнения справочника необходимо произвести следующие настройки в обработке Структура проекта:

  • Структура проекта должна быть выстроена в следующей иерархии:
  • верхний уровень – проектная задача типа "Этап";
  • на вложенном уровне – проектная задача типа "Веха" (этап является родителем для вехи).
  • Для ключевых точек (вех) проекта, которые являются воротами качества необходимо указать в проектной задаче:
  • тип проектной задачи – "Проектная задача является вехой";
  • выбрать вид операции для данной проектной задачи и при этом в выбранном из справочника Виды операций элементе должен стоять флаг "Ворота качества".

    • При данной настройке по кнопке Заполнить по структуре будет автоматически заполнена табличная часть "Таблица фаз", при этом будут созданы элементы справочника "Фазы проектов", наименования которых будут соответствовать этапам графика проекта. Первая фаза по умолчанию будет "Стартовая".
