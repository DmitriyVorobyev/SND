Справочник Произошедшие события

Назначение

Справочник "Произошедшие события" предназначен для хранения информации о произошедших, но ещё не обработанных событиях для системы оповещений.
После регистрации события обрабатываются регламентным заданием "Обработка произошедших событий", которое переносит их в регистр сведений Очередь событий для оповещений для дальнейшей отправки, после чего удаляет из справочника.
Срок хранения событий перед обработкой настраивается в параметрах информационной базы: Параметры подсистемы PM → Группа "Оповещения" → "Срок хранения событий".
