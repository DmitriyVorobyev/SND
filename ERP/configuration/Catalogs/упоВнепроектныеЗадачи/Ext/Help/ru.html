Справочник﻿ Внепроектные задачи

Назначение

Справочник "Внепроектные задачи" предназначен для хранения в информационной базе информации о задачах, по которым необходимо учитывать затраты рабочего времени трудовых ресурсов, но не входящих ни в один из проектов, выполняемых предприятием.

Информация, хранимая в справочнике, используется при заполнении документов Распределение рабочего времени за неделю и Табели учета рабочего времени.

Форма объекта

При создании элемента справочника "Внепроектные задачи" необходимо заполнить следующие обязательные реквизиты:

  • Код элемента — уникальный код элемента (формируется автоматически);
  • Наименование — наименование внепроектной задачи.
  • Вид операции – указывается вид операции внепроектной задачи. Значение выбирается из списка значений справочника Виды операций.
