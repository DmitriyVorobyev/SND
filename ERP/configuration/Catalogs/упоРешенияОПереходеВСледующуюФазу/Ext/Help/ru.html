Справочник Решения о переходе в следующую фазу

Назначение

Справочник "Решения о переходе в следующую фазу" предназначен для хранения списка возможных решений, принимаемых при завершении текущей фазы проекта.

Соответствующее решение устанавливается у Проектного решения (элемент справочника Задания с видом "Проектное решение"), являющегося основным для завершаемой фазы.

Форма объекта

При создании элемента справочника "Решения о переходе в следующую фазу" необходимо заполнить следующие обязательные реквизиты:

  • Код — уникальный код элемента (формируется автоматически);
  • Наименование — наименование решения о переходе в следующую фазу.
    • В справочник "Решения о переходе в следующую фазу" добавлены предопределенные элементы:
  • К следующему этапу;
  • Перенос решения на другую дату;
  • Повторно на предыдущий этап;
  • Прекращение проекта.
