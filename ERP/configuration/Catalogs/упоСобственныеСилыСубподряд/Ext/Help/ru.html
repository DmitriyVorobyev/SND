Справочник Собственные силы/субподряд

Назначение

Справочник "Собственные силы/субподряд" предназначен для хранения сведений о типе выполняемых работ.

Форма объекта

При заполнении формы элемента справочника "Собственные силы/субподряд" необходимо заполнить следующие обязательные реквизиты:

  • Код элемента — формируется автоматически;
  • Наименование — наименование типа проекта.
