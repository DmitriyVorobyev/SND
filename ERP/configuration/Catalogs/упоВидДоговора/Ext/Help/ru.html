Справочник Вид договора

Назначение

Справочник используется для хранения информации о видах договоров, заключаемых предприятием.

Для вида договора может быть выбрано правило формирования наименования договоров данного вида.

Форма объекта

При заполнении формы элемента справочника "Вид договора" необходимо заполнить следующие обязательные реквизиты:

  • Код – формируется автоматически при записи элемента;
  • Наименование – наименование вида договора;
  • Правило формирования наименования договора – указывается правило, действующее для данного вида договора, значение выбирается из справочника Правила формирования наименований договоров.
