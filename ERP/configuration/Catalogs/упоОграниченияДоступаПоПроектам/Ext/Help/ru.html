Справочник Ограничения доступа по проектам

Назначение

Справочник предназначен для хранения информации о составе профилей персональных групп доступа и пользователей входящих в них, а также ручной настройки доступа к проектам.

Форма объекта

На командной панели расположена кнопка Создать, при нажатии на которую, открывается обработка "Добавление пользователей для автоматического назначения ограничений по проектам".

При заполнении формы обработки необходимо указать следующие поля:

  • Профиль – выбирается элемент из предопределенного списка профилей групп доступа;

    • Табличная часть "Список пользователей" заполняется элементами справочника Пользователи. Заполнение происходит следующим образом:

  • Добавление одного элемента с помощью кнопки Добавить;
  • Добавление нескольких элементов с помощью кнопки Подбор.

    • Для выбранных пользователей будут созданы персональные группы доступа (в них, с помощью регламентного задания "Пересчет ограничений доступа по проектам", будут автоматически добавляться проекты, доступ к которым разрешен).

    Важно! Для работы функционала ограничения доступа по проектам необходимо включить опцию "Ограничивать доступ на уровне записей" (раздел "Администрирование" → "Настройки пользователей и прав" → "Группы доступа").

    Важно! Если в разделе "Администрирование" → "Настройки пользователей и прав" → "Группы доступа" включен вариант работы "Производительный", после создания индивидуальной группы доступа с помощью обработки нужно дождаться окончания выполнения регламентного задания "Обновление доступа на уровне записей".
