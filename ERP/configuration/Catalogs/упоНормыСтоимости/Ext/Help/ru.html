﻿Справочник Нормы стоимости

Назначение

Справочник "Нормы стоимости" предназначен для хранения в системе информации о нормах стоимости используемых на предприятии ресурсов. Нормы стоимости могут задаваться как для Номенклатуры, так и для Ролей трудовых ресурсов и непосредственно Трудовых ресурсов.

Норма стоимости — это структурная единица, которая позволяет для одного и того же ресурса хранить в системе несколько норм его стоимости. Например, оплата работ сотрудника в будние дни и оплата работ в выходной.

Справочник "Нормы стоимости" позволяет:

  • Создавать и хранить в системе несколько вариантов норм стоимости для одного и того же ресурса.

    • Справочник "Нормы стоимости" не является обязательным и используется лишь для дополнительного аналитического разреза.

    Важно! Если на предприятии не предполагается использовать различные варианты нормирования стоимости ресурсов, то в справочник "Нормы стоимости" рекомендуется внести только один элемент, например "Базовая норма стоимости" и использовать его.

    Форма объекта

    При заполнении формы элемента справочника "Нормы стоимости" необходимо заполнить следующие обязательные реквизиты:

  • Код элемента — формируется автоматически;
  • Наименование — наименование нормы стоимости.
