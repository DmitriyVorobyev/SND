﻿Справочник Сотрудники

Назначение

Справочник "Сотрудники" предназначен для хранения информации обо всех сотрудниках предприятия, принимающих участие в выполнении проектов.

Сотрудник — конкретное физическое лицо, занимающее определённую должность на предприятии.

Форма объекта

При заполнении формы элемента справочника "Сотрудники" необходимо заполнить следующие обязательные реквизиты:

  • Код элемента — формируется автоматически;
  • Наименование — наименование сотрудника;
  • Не отображать в списках (опция расположена в нижней части формы) – если опция включена (флаг установлен), то текущий элемент справочника не будет отображаться на формах выбора и форме списка справочника.

    • На закладках можно просмотреть дополнительную информацию о сотруднике.

    Закладка "Должности"

    На закладке "Должности" можно увидеть, на какие должности предприятия назначен данный сотрудник. Назначить сотрудника на должность можно с помощью документа Регистрация должности сотрудника.

    Серым цветом выделены ранее занимаемые сотрудником должности; черным цветом выделены актуальные должности, которые в настоящее время занимает сотрудник. 

    Закладка "Ресурсы"

    На закладке "Ресурсы" можно увидеть, владельцем каких трудовых ресурсов назначен данный сотрудник. Назначить сотрудника владельцем ресурсов можно с помощью документа Регистрация владельца ресурсов.

    Закладка "Проекты"

    На закладке "Проекты" можно увидеть, руководителем каких проектов является данный сотрудник. Назначить сотрудника руководителем проекта можно с помощью документа Регистрация проекта, либо Изменение руководителя (куратора) проекта.

    Закладка "Проектные задачи"

    На закладке "Проектные задачи" можно увидеть, руководителем каких проектных задач является данный сотрудник. Назначить сотрудника руководителем проектной задачи можно с помощью документа Изменение руководителя проектной задачи.

    Закладка "Подразделения"

    На закладке "Подразделения" можно увидеть, руководителем каких подразделений является данный сотрудник. Назначить сотрудника руководителем подразделения можно с помощью документа Регистрация руководителя подразделения.

    Закладка "Диспетчеры"

    На закладке "Диспетчеры" можно увидеть список диспетчеров – пользователей, представляющих данного сотрудника в системе. Назначить сотруднику диспетчера можно с помощью документа Регистрация диспетчера.
