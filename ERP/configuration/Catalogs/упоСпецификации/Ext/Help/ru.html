Справочник Спецификации проектной продукции

Назначение

Справочник "Спецификации проектной продукции" предназначен для хранения шаблона расходов производства проектной продукции по ролям трудовых ресурсов (трудозатратам).

Спецификация проектной продукции указывается в элементах справочника Проектная продукция.

Справочник "Спецификации проектной продукции" доступен в разделе "Объемы, выполнение, версии".

Форма объекта

При заполнении формы элемента справочника "Спецификации проектной продукции" необходимо заполнить следующие обязательные реквизиты:

  • Код – формируется автоматически;
  • Наименование – наименование спецификации проектной продукции, заполняется вручную.

    • Вкладка "Роли ТР"

  • Кнопка Добавить – добавляет новую строку в табличную часть.

    • Табличная часть содержит реквизиты:

  • № – порядковый номер строки табличной части;
  • Роль ТР – роль трудового ресурса-исполнителя, заполняется вручную из справочника Роли трудовых ресурсов;
  • Подразделение – наименование подразделения, ответственного за производство проектной продукции, заполняется вручную из справочника Подразделения;
  • Процент распределения – доля распределения трудоемкости между ролями трудовых ресурсов;
  • Профиль трудозатрат – способ распределения трудозатрат, заполняется из справочника Профили распределения трудозатрат.
