Справочник Статьи затрат по проектам

Назначение

Справочник "Статьи затрат по проектам" предназначен для хранения информации о тех статьях, в разрезе которых формируется расходная часть плана БДР.

С технической точки зрения, справочник "Статьи затрат по проектам" представляет собой аналитический разрез для любых отчетов конфигурации, в которых в том или ином качестве фигурируют финансовые показатели расходной части БДР.

Форма объекта

При создании элемента справочника "Статьи затрат по проектам" заполняются следующие реквизиты:

  • Код — уникальный код элемента (формируется автоматически);
  • Наименование — наименование статьи;
  • Полное наименование — полное наименование статьи;
  • Родитель — группа статей расходов;
  • Комментарий — текстовое поле;
  • Схема оплаты — схема оплаты, использующаяся при включении плановых расходов в план БДДС, элемент справочника Схемы оплаты.


    • Важно! При автоматическом заполнении плана БДДС на основании плана расходов, проверка схемы оплаты производится в следующей последовательности (используется первое найденное значение):

    1. Договор, указанный в строке расходов;

    2. Контрагент, указанный в строке расходов;

    3. Статья затрат, указанная в строке расходов;

    4. Реквизит "Схема оплаты по умолчанию для расходов" в проектной задаче;

    5. Реквизит "Схема оплаты по умолчанию для расходов" в карточке проекта на закладке "Дополнительно".

    Настройки отражения статьи затрат в расходах

    Настройки используются для заполнения плана расходов на основании планов трудозатрат, объемов, потребностей и дополнительных затрат.

    Отражение трудозатрат

  • Способ привязки — настройки привязки расхода (по выбранному профилю распределения, либо сводно с выбранной периодичностью (День / Неделя / Декада / Две недели / Месяц / Квартал / Полугодие / Год));
  • Профиль распределения — правило привязки расходов к срокам проектных задач, элемент справочника Профили распределения доходов и расходов;
  • Период агрегации — стоимость трудозатрат проектной задачи по статье, попадающих в период агрегации (с учетом распределения трудозатрат), привязывается к завершению периода;
  • Контрагент — контрагент по умолчанию для отражения плановых трудозатрат, распределенных на статью затрат, в плане расходов, элемент справочника Контрагенты;
  • Договор — договор контрагента по умолчанию для отражения плановых трудозатрат, распределенных на статью затрат, в плане расходов, элемент справочника Договоры контрагентов.

    • Отражение объемов, потребностей, доп. затрат

  • Профиль распределения — правило привязки расходов к срокам проектных задач, элемент справочника Профили распределения доходов и расходов;
  • Контрагент — контрагент по умолчанию для отражения плановых трудозатрат, распределенных на статью затрат, в плане расходов, элемент справочника Контрагенты;
  • Договор — договор контрагента по умолчанию для отражения плановых трудозатрат, распределенных на статью затрат, в плане расходов, элемент справочника Договоры контрагентов.

    • Распределение расходов

    В регл. учете

  • Способ распределения расходов по проектам — настройка распределения / списания косвенных расходов по направлениям деятельности и подразделениям, элемент справочника Способы распределения расходов по проектам. Заполняется из справочника выбранным способом для косвенных расходов либо выбирается предопределенный способ "Формировать НЗП" для тех статей затрат, на которых планируется отражение прямых или распределенных расходов;
  • Статья распределения расходов — статья прямых расходов, на которую будут отнесены суммы расходов после распределения статьи косвенных расходов (реклассификации), элемент справочника "Статьи затрат по проектам" ("Статьи расходов" в "1С:ERP+PM Управление проектной организацией 2"). Заполняется только для косвенных расходов.

    • В упр. учете

  • Способ распределения расходов по проектам — настройка распределения / списания косвенных расходов по направлениям деятельности и подразделениям, элемент справочника Способы распределения расходов по проектам. Заполняется из справочника выбранным способом для косвенных расходов либо выбирается предопределенный способ "Формировать НЗП" для тех статей затрат, на которых планируется отражение прямых или распределенных расходов;
  • Статья распределения расходов — статья прямых расходов, на которую будут отнесены суммы расходов после распределения статьи косвенных расходов (реклассификации), элемент справочника "Статьи затрат по проектам" ("Статьи расходов" в "1С:ERP+PM Управление проектной организацией 2"). Заполняется только для косвенных расходов.

    • Примечание. В конфигурации "1С:ERP+PM Управление проектной организацией 2" реквизит "Схема оплаты", а также реквизиты для отражения трудозатрат, объемов, потребностей, доп. затрат, а также настройки распределения расходов в регламентированном и управленческом учетах доступны по ссылке "Настройки отражения (РМ)".
