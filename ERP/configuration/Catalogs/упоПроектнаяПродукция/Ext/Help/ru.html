Справочник Проектная продукция

Назначение

Справочник "Проектная продукция" предназначен для хранения информации о производимой проектной продукции и ее элементах нормирования (шаблонах проектной продукции).

Функциональность "Проектной продукции" рекомендуется использовать в учете производства для целей:

  • Разработки проектно-сметной, конструкторской и прочей документации;
  • Как инструмент планирования и контроля выпуска продукции со сложной структурой;
  • Ведения, загрузки из сметных программ ведомостей объемов работ в проектах капитального строительства, девелоперских проектах.

    • Проектная продукция в документе Проектная задача формирует плановые данные доходных объемов, как альтернатива номенклатуры в табличной части "Субпродукты" закладки "Объемы" - "План выпуска". Из проектной продукции, отраженной в доходных объемах, можно сформировать бюджет в план доходов и поступлений денежных средств проектной задачи. На основании данных о запланированной проектной продукции в плане выпуска в проектной задаче можно сформировать план трудозатрат.

    Шаблоны проектной продукции являются элементами нормирования выпуска проектной продукции. На основе шаблонов проектной продукции создаются и заполняются элементы справочника.

    Форма объекта

    На командной панели элемента справочника "Проектная продукция" расположены следующие кнопки:

  • Кнопка Записать и закрыть – сохраняет измененные данные, введенные в элемент справочника "Проектная продукция" и закрывает форму элемента.
  • Кнопка Записать – сохраняет измененные данные, введенные в элемент справочника "Проектная продукция".
  • Кнопка Версии доп. реквизитов → Записать версию – фиксирует значения дополнительных реквизитов в разрезе версий плана проектов в регистре сведений Версии дополнительных реквизитов;
  • Кнопка Версии доп. реквизитов → Посмотреть версии – выводит перечень сохраненных значений дополнительных реквизитов в разрезе версий плана проектов в регистре сведений Версии дополнительных реквизитов.

    • Важно! Запись и просмотр версии проектной продукции возможен, если в проектной продукции заполнен реквизит "Проектная задача" на закладке "Параметры".

  • Кнопка Загрузить из файла – открывает обработку Загрузка проектной продукции, которая создает элементы справочника "Проектная продукция" в результате загрузки данных из файла в формате *.xlsx.

    • Форма элемента справочника "Проектная продукция" состоит из общей части и закладок.

    При заполнении общей части справочника "Проектная продукция" заполняются следующие реквизиты:

  • Код – формируется автоматически;
  • Код ПП – формируется автоматически при создании проектной продукции из кода проекта, кода типа проектной продукции и порядкового номера проектной продукции в проектной задаче. Реквизит доступен для редактирования;
  • Шаблон – данная опция определяет тип элемента справочника. Если опция включена, то элемент справочника "Проектная продукция" с установленным признаком "Шаблон" является элементом нормирования выпускаемой проектной продукции и предназначена для быстрого заполнения реквизитов новых элементов проектной продукции данными реквизитов выбранного шаблона. Если опция выключена, тогда элемент справочника является производимой проектной продукцией. Реквизит доступен для редактирования;

    • Примечание. При заполнении проектной продукции в плане выпуска документа Проектная задача выбираются шаблоны проектной продукции. При сохранении документа Проектная задача на основании выбранных шаблонов создаются элементы справочника "Проектная продукция", связанные с проектной задачей.

  • Статус – информационный реквизит, статус проектной продукции.

    • Примечание.Проектная продукция сразу после создания не имеет статуса. Статусы проектной продукции присваиваются регламентным заданием "Расчет статусов проектной продукции" по данным о статусах связанных заданий. Основанием для обработки информации регламентным заданием является изменение статуса Задания, выданного по элементу проектной продукции в обработке АРМ Проектная продукция или удаление проектной продукции из проектной задачи.

    Важно! Реквизиты "Код ПП" и "Статус" недоступны в элементах справочника "Проектная продукция" с признаком "Шаблон".

    Закладка "Основная"

    Закладка "Основная" содержит следующую информацию:

  • Наименование – наименование проектной продукции. Заполняется вручную для шаблона или автоматически при создании производимой проектной продукции из шаблона при формировании плана выпуска в проектной задаче. Реквизит является обязательным для заполнения;
  • Родитель – проектная продукция, находящаяся на более высоком уровне структуры проектной продукции;
  • Шаблон ПП – проектная продукция с признаком "Шаблон" на основании которого была создана производимая проектная продукция;

    • Важно! Реквизит "Шаблон ПП " недоступен в элементах справочника "Проектная продукция" с признаком "Шаблон".

  • Тип продукции – тип производимой проектной продукции или шаблона, элемент справочника Тип проектной продукции;
  • Вид операции – элемент справочника Виды операций, предназначен для получения информации о трудозатратах на проект, распределении доходов и расходов;
  • Количество – количество производимой проектной продукции;
  • Ед. изм. – единица измерения производимой проектной продукции, элемент справочника Упаковки и единицы измерения;
  • Норматив – норма времени (трудозатрат) необходимая для производства указанного количества проектной продукции. Для элементов производимой проектной продукции реквизит "Норматив" может быть заполнен несколькими способами:
  • Способ 1: при создании производимой проектной продукции через проектную задачу на основании шаблона, тогда реквизит "Норматив" заполнится значением из шаблона;
  • Способ 2: при создании производимой проектной продукции в справочнике "Проектная продукция", необходимо заполнить реквизит "Шаблон ПП", тогда значение "Норматив" заполниться из шаблона;
  • Способ 3: создать новый элемент справочника "Проектная продукция" установить признак "Шаблон", заполнить значение в реквизите "Норматив", отключить признак "Шаблон" и продолжить создание элемента производимой проектной продукции.

    • Важно! Реквизит "Норматив" доступен для заполнения только в элементах справочника "Проектная продукция" с признаком "Шаблон".

    Важно! В элементах справочника "Проектная продукция" с признаком "Шаблон" значение "Норматив" может быть пересчитано автоматически, если в табличной части "Роли трудовых ресурсов" итоговое значение колонки "Норма" было скорректировано.

  • Сложность – коэффициент сложности выполнения работ по производству проектной продукции. Реквизит актуализируется автоматически, если значение в табличной части "Роли трудовых ресурсов" были скорректированы и итоговая сумма столбца "Коэф." не равна ранее внесенному значению в реквизите "Сложность". Реквизит показывает насколько реальные трудозатраты выше (>1) или ниже (<1) значения трудозатрат в реквизите "Норматив";
  • Трудоемкость – количество трудозатрат, планируемых для производства проектной продукции. Рассчитывается по формуле: Норматив * Сложность. Может указываться вручную. Для автоматического расчета трудоемкости должны быть заполнены реквизиты "Норматив" и "Сложность", так же данные могут быть транслированы/пересчитаны из итоговых значений табличной части "Роли трудовых ресурсов" после ее заполнения/изменения. Реквизит актуализируется автоматически, если его значение не равно итоговому значению столбца "ТРЗ" в табличной части "Роли трудовых ресурсов";
  • Ед. изм. времени – единица измерения трудозатрат производимой проектной продукции, элемент справочника Единицы измерения времени;
  • Скорость выполнения (дни) – плановая скорость освоения единицы проектной продукции в днях;
  • Min длительность – минимальная длительность выполнения работ для производства проектной продукции.

    • Ресурсы

  • Спецификация – ресурсная спецификация, описывающая трудозатраты, материальные расходы и расходы на оборудование, необходимые для производства проектной продукции. Элемент справочника Спецификации проектной продукции;
  • Кнопка Обновить данные из спецификации – по нажатию кнопки автоматически перезаполняется табличная часть "Роли трудовых ресурсов" по данным из указанной спецификации. Если реквизит "Спецификация" не заполнен, тогда табличная часть "Роли трудовых ресурсов" очистится.

    • Табличная часть "Роли трудовых ресурсов" содержит колонки:

  • № – порядковый номер строки табличной части;
  • Роль– роль трудового ресурса-исполнителя. Роль автоматически заполняется значением из реквизитов "Шаблон ПП" или "Спецификация", или вручную подбором из справочника Роли трудовых ресурсов;
  • Подразделение – наименование подразделения ответственного за производство проектной продукции. Подразделение автоматически заполняется значением из реквизитов "Шаблон ПП" или "Спецификация", или вручную подбором из справочника Подразделения. В списке значений отображаются только те подразделения, в состав которых данная роль трудового ресурса была включена с помощью документа Регистрация состава подразделения;
  • % – доля распределения трудоемкости между ролями трудовых ресурсов;
  • Количество – распределенное количество производимой проектной продукции между ролями трудовых ресурсов. Рассчитывается по формуле: Количество (общее) * % (по роли). Не редактируется. Для изменения значения по строке в данном столбце нужно или скорректировать "%" по строке или изменить общее значение в реквизите "Количество" на закладке "Основная";
  • Норма – распределенная норма трудозатрат между ролями трудовых ресурсов. Рассчитывается по формуле: Норматив (общий) * % (по роли). Данные могут быть отредактированы вручную для элементов справочника с признаком "Шаблон". Для производимой проектной продукции значение в столбце "Норма" корректируется изменением распределения в столбце "%" или изменением общего значения в реквизите "Норматив" на закладке "Основная" шаблона проектной продукции с перезаполнением данных;

    • Важно! Изменить значение в реквизите "Норма" через шаблон можно только в момент создания элемента справочника "Проектная продукция" и до его записи.

  • Коэф. – индивидуальный коэффициент сложности выполнения работ по производству проектной продукции для определенной роли трудового ресурса. Коэффициент может быть отредактирован вручную;
  • ТРЗ – количество трудозатрат, планируемых для производства проектной продукции для определенной роли трудового ресурса. Рассчитывается по формуле: Норма (по роли) * Коэф.(по роли), может указываться вручную;
  • Профиль распределения – способ распределения трудозатрат, заполняется автоматически данными из указанной в соответствующем реквизите Спецификации проектной продукции или  вручную из справочника Профили распределения трудозатрат.

    • Важно! Если итоговое значение по колонке "Норма" табличной части "Роли трудовых ресурсов" не равно  значению реквизита "Норматив", тогда итоговые данные транслируются из колонки "Норма" в реквизит "Норматив". Аналогично выполняется актуализация итоговых значений из колонки "Коэф." в "Сложность" и из колонки "ТРЗ" в "Трудоемкость".

    Закладка "Параметры"

    Важно! Закладка "Параметры" недоступна в элементах справочника "Проектная продукция" с признаком "Шаблон".

    Закладка "Параметры" содержит информацию:

  • Проект – реквизит, указывающий принадлежность проектной продукции проекту;
  • Проектная задача – задача, в которой выполняется производство проектной продукции. Заполняется вручную или автоматически при создании через план выпуска в документе Проектная задача. Когда в производимой проектной продукции заполнен реквизит "Проектная задача" такой элемент становится недоступным для редактирования из справочника "Проектная продукция", при этом актуализировать проектную продукцию можно изменением соответствующих данных через документ Проектная задача на закладке "Объемы" - "План выпуска" по проектной задаче доступны реквизиты:
  • Общие значения в табличной части "Субпродукты" – "Количество", "Коэф." (он же "Сложность"), "ТРЗ";
  • Значения по ролям в табличной части "Распределение объемов" – "%ТРЗ", "Коэф.", "ТРЗ".

    • Примечание. Аналогичный функционал редактирования проектной продукции может быть использован при внесении изменений в "План выпуска"через обработку Структура проекта.

  • Объект – объект, с которым связана производимая проектная продукция. Заполняется вручную элементом справочника Объекты или автоматически при создании через план выпуска в проектной задаче;
  • Комментарий – произвольный текст.

    • Закладка "Дополнительные реквизиты"

    Закладка "Дополнительные реквизиты" содержит перечень созданных дополнительных реквизитов для элемента справочника "Проектная продукция".

    Примечание. Варианты дополнительных реквизитов для использования в проектной продукции: "Ответственный", "Дата утверждения", "Дата регистрации", "Номер регистрации", специальные отметки – "Утверждено", "Согласовано", "Отклонено" и т.д.

    Дополнительные реквизиты добавляются по кнопке "Еще" - "Изменить состав дополнительных реквизитов".

    Важно! Закладка "Дополнительные реквизиты" выводится только в том случае, если добавлен хотя бы один дополнительный реквизит в элемент справочника "Проектная продукция".
