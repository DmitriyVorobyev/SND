Справочник Показатели проектов



Если в справке напротив поля или элемента интерфейса есть иконка, то элемент доступен только в приложении "1С:ERP+PM Управление проектной организацией 2" (1С:ERP+PM).

Назначение

Справочник "Показатели проектов" предназначен для хранения в системе информации о ключевых показателях проектов.

Показатель проекта — это поименованный критерий (величина простого типа), который используется руководством предприятия для мониторинга и оценки текущего состояния проектов.

Форма списка объектов справочника

На форме списка объектов справочника расположены следующие кнопки:

  • Кнопка Создать — создать новый элемент справочника;
  • Кнопка Создать группу — создать новую группу;
  • Кнопка Создать новый элемент копированием текущего — создать новый элемент справочника путем копирования выделенного показателя;
  • Кнопка Сохранить показатели в файл — выполняет выгрузку выбранных показателей в файл xml. Выгружаются показатели, которые выделены в списке (для выделения нескольких показателей необходимо использовать клавишу Ctrl).
    Для выгрузки всех показателей, зарегистрированных в информационной базе, необходимо использовать обработку Выгрузка показателей проектов, которая открывается по кнопке Загрузить показатели из файла;
  • Кнопка Загрузить показатели из файла — открывает обработку Выгрузка показателей проектов для загрузки показателей из файла xml.
    Обработку Выгрузка показателей проектов также позволяет выполнить выгрузку всех показателей, зарегистрированных в информационной базе, в файл xml;
  • Кнопка Дополнительные сведения — открывает форму Редактирование дополнительных сведений;

    • Важно! Кнопка Дополнительные сведения доступна, только если в настройках информационной базы включено использование дополнительных реквизитов и сведений (установлен флаг "Дополнительные реквизиты и сведения" в разделе "Администрирование" → "Общие настройки" → группа "Дополнительные реквизиты и сведения").

  • Кнопка Создать на основании — позволяет создать на основании выбранного объекта задание;
  • Кнопка Обновить предустановленные показатели — открывает обработку Обновление предустановленных показателей проектов для пакетного ввода в информационную базу предустановленных показателей проектов (то есть таких показателей, параметры которых определены разработчиком системы).

    • Форма объекта

    При создании элемента справочника "Показатели проектов" необходимо заполнить следующие обязательные реквизиты:

  • Код — уникальный код элемента (формируется автоматически).
  • Наименование — наименование показателя.

    • Реквизиты элемента справочника разнесены по нескольким закладкам.

    Закладка "Параметры показателя"

    На этой закладке представлены основные параметры показателя.

  • Тип значения — выбирается из простых типов (Число, Дата, Булево, Строка, Ссылка).
  • Тип ссылки — ссылка на справочник / вид документов / перечисление и т.д., из которого при регистрации значения показателя будет выбираться значение (конкретный элемент справочника / документ / значение перечисления и т.д.). Реквизит доступен только для показателя с типом значения "Ссылка".
  • Режим заполнения — перечисление, задает режим ввода значений показателя в систему:
  • Вручную — значения показателя будут вводиться вручную руководителем проекта при помощи документа Регистрация значений показателей проекта;
  • Автоматически — значения показателя будут извлекаться из информационной базы в полностью автоматическом режиме;
  • Автоматически в документе — значения показателя будут вводиться руководителем проекта при помощи документа Регистрация значений показателей проекта, но при этом будет доступна возможность извлечь из информационной базы текущее значение показателя;
  • Автоматически в документе расчет эффективности — значения показателя будут вводиться при помощи документа Регистрация значений показателей эффективности проектов, но при этом будет доступна возможность извлечь из информационной базы текущее значение показателя. Данный режим заполнения недоступен для выбора и установлен только для предопределенных показателей.
  • Лимит актуальности (дней) — имеет смысл только для тех показателей, у которых установлен режим заполнения "Вручную" или "Автоматически в документе". Реквизит задает количество дней, в течение которого введенное руководителем проекта значение показателя является актуальным. По истечении заданного срока значение показателя считается просроченным (в Панели руководителя такие значения отмечаются цветом).
  • Форматная строка — реквизит задает формат для отображения значений показателя на Панели руководителя.
  • Считать итоги по группировкам — определяет, будут или нет рассчитываться итоговые значения показателя по группировкам. Если опция включена, становится доступен параметр Выражение группировки.
  • Выражение группировки — определяет вариант расчета итоговых значений в группировке. Возможные варианты:
  • Сумма;
  • Среднее;
  • Формула — для показателей, рассчитываемых по значениям других показателей по формуле;
  • Максимум;
  • Минимум.
  • Картинка по умолчанию — реквизит задает картинку, которая по умолчанию отображается в колонке показателя на Панели руководителя.
  • Показатель инвестирования — данный признак отвечает за использование показателя в подсистеме "Заявки на проект". Если признак установлен, значения показателя, зарегистрированные документом Регистрация значений показателей проектов для фаз (вех) проекта, будут отображаться в документах Заявка на проект.
  • Принадлежность показателя:
  • Общий — показатель рассчитывается для проектов и проектных задач;
  • Только для проекта — показатель рассчитывается только для проектов;
  • Только для проектной задачи — показатель рассчитывается только для проектных задач;
  • Произвольный показатель — показатель используется для расчетов, не связанных с получением данных в разрезе проектов и проектных задач. Рассчитывается только автоматически, источником данных является запрос к информационной базе. Результатом расчета является численное значение без аналитики по проекту и проектной задаче. Например, может использоваться для расчета процентов накладных расходов, на основании которых проводится актуализация плановых расходов проектов. В таком случае, показатель рассчитывается как оборот за период по статье бюджета (сумма по регистру накопления Обороты бюджетов по указанной в параметрах запроса статье бюджета, например, «Выручка», «ФОТ производство» и т.д.) и используется в качестве значения для поля «Произвольный запрос (База)» в регистре сведений Параметры расчета процентов затрат. Недоступен для использования в обработке Панель руководителя, обработке Монитор проекта, отчете Анализ проектов по показателям, документе Регистрация значений показателей проекта.

    • Закладка "Состояния показателя"

    На этой закладке можно настроить правила отображения значений показателя на Панели руководителя. Правила задаются при помощи табличной части, которая содержит следующие реквизиты:

  • Вид сравнения — реквизит задает вид сравнения значения показателя с эталонным значением.
  • Значение — реквизит задает эталонное значение (или диапазон эталонных значений).
  • Выражение значения — используется в качестве альтернативы реквизиту "Значение" для установки эталонного значения с помощью технического текста.

    • Важно! Реквизит "Выражение значения" должен быть пустым при заполненном реквизите "Значение".

  • Картинка — реквизит задает графическое изображение, которое будет выведено на Панели руководителя рядом со значением показателя в том случае, если условие заданное этой строкой табличной части окажется выполненным.

    • Закладка "Источник"

    Эта закладка отображается только для тех элементов справочника, у которых установлен режим заполнения "Автоматически" или "Автоматически в документе".

    Вкладка "Настройка источника"

  • Выполнение запроса к информационной базе – значение показателя будет получено из результатов запроса. Запрос должен быть написан таким образом, чтобы он возвращал только одну строку;
  • Сборка из значений других показателей по формуле - значение показателя будет вычислено на основании значений других показателей по заданной пользователем формуле расчета.

    • Реквизиты и элементы управления разнесены на несколько дополнительных вкладок, видимость которых зависит от указанной принадлежности и источника данных значения показателя.

    Вкладка "Текст запроса для проекта"

    Вкладка отображается только для элементов справочника, у которых установлен тип источника данных "Выполнение запроса к информационной базе" и принадлежность "Общий" или "Только для проекта". Здесь можно настроить текст запроса и проверить его корректность.

    Вкладка "Параметры запроса для проекта"

    Вкладка отображается только для элементов справочника, у которых установлен тип источника данных "Выполнение запроса к информационной базе" и принадлежность "Общий" или "Только для проекта". Здесь можно настроить параметры запроса и указать, какие из полей запроса будут использованы для проекта и для значения показателя.

    Доступные системные параметры запроса:

  • &ТекДата – дата актуальности, установленная в Параметрах подсистемы PM в группе "Основные параметры";
  • &ТекДатаСеанса – текущая дата сеанса пользователя.

    • Вкладка "Текст запроса для проектной задачи"

    Вкладка отображается только для элементов справочника, у которых установлен тип источника данных "Выполнение запроса к информационной базе" и принадлежность "Общий" или "Только для проектной задачи". Здесь можно настроить текст запроса и проверить его корректность.

    Вкладка "Параметры запроса для проектной задачи"

    Вкладка отображается только для элементов справочника, у которых установлен тип источника данных "Выполнение запроса к информационной базе" и принадлежность "Общий" или "Только для проектной задачи". Здесь можно настроить параметры запроса и указать, какие из полей запроса будут использованы для проектной задачи и для значения показателя.

    Доступные системные параметры запроса:

  • &ТекДата – дата актуальности, установленная в Параметрах подсистемы PM в группе "Основные параметры";
  • &ТекДатаСеанса – текущая дата сеанса пользователя.

    • Вкладка "Формула расчета"

    Вкладка отображается только для элементов справочника, у которых установлен тип источника данных "Сборка из значений других показателей по формуле". Здесь можно настроить список показателей-источников (их значения используются при расчете по формуле), настроить формулу расчета и проверить ее корректность.

    Важно! Источником данных для расчета значения показателя по формуле могут служить только такие показатели, у которых либо установлен тип источника "Выполнение запроса к информационной базе", либо установлен режим заполнения "Вручную". Показатели, у которых установлен тип источника "Сборка из значений других показателей по формуле" в качестве источника данных использоваться не могут.

    Примечание! Если тип источника данных для расчета значения показателя установлен в "Выполнение запроса к информационной базе", то в качестве значения показателя будет браться значение из первой строки результата выполнения запроса (если строк несколько) по полю, которое указано на закладке "Параметры запроса для проекта/проектной задачи".

    Закладка "Дополнительная информация"

    На этой закладке представлены дополнительные параметры показателя.

  • Версия показателя – служебный реквизит, предназначенный для фиксации номера версии показателя;
  • Порядок – числовое значение, определяющее порядок сортировки показателя в отчетах;
  • Описание показателя – текстовое описание показателя;
  • Описание изменений – текстовое описание изменений при изменении версии показателя;

    • Значения показателя для всех проектов, информация по которым введена в систему, можно проанализировать при помощи отчета Анализ проектов по показателям или при помощи обработки Панель руководителя.

  • для проектной задачи с длительностью 1 сутки (24 часа) – значение показателя составит 3 дня;
  • для проектной задачи с длительностью 0,5 часа (30 минут) – значение показателя составит 1 день;
  • для проектной задачи с длительностью 8,5 часов (8 часов 30 минут) – значение показателя составит 2 дня;
  • для проектной задачи с длительностью 10 часов, из которых 1 час попадает на первый день, 8 часов – на второй день и 1 час – на третий день, значение показателя составит 3 дня.

    Периодические показатели


    Периодическими являются показатели, которые получают данные за указанный период и содержат в тексте запроса параметры &НачалоПериода и &КонецПериода. Такие показатели можно использовать только для построения графика в обработке Монитор проекта (вкладка "Показатели графика") с дополнительной настройкой периодов (вкладка "Периоды показателей графика"). Использование периодических показателей в других местах системы будет приводить к ошибке вида "Не задано значение параметра "НачалоПериода"...". В обработке Панель руководителя периодические показатели недоступны для вывода.
