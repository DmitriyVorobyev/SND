Справочник Правила получения фактических данных для проектного бюджетирования



Если в справке напротив поля или элемента интерфейса есть иконка, то элемент доступен только в приложении "1С:ERP+PM Управление проектной организацией 2" (1С:ERP+PM).

Назначение

Справочник "Правила получения фактических данных для проектного бюджетирования" предназначен для настройки получения фактических данных в проектном бюджетировании.

Важно! Справочник доступен при включенной опции "Включить использование контура "Отражение первичных документов в проектном бюджетировании" в Параметрах подсистемы PM на закладке "Проектное бюджетирование".

Форма списка объектов справочника

На форме списка объектов справочника расположены следующие кнопки:

  • Создать — создает новый элемент справочника;
  • Создать группу — создает новую группу;
  • Создать новый элемент копированием текущего — создает новый элемент справочника путем копирования выделенного правила;
  • Дополнительные сведения — открывает форму Дополнительные сведения;

    • Важно! Кнопка Дополнительные сведения доступна, только если в настройках информационной базы включено использование дополнительных реквизитов и сведений (установлен флаг "Дополнительные реквизиты и сведения" в разделе "Администрирование" → "Общие настройки" → группа "Дополнительные реквизиты и сведения").

  • Обновить предустановленные — производит пакетный ввод в информационную базу предустановленных правил проектного бюджетирования (то есть таких правил, параметры которых определены разработчиком системы).

    • Форма объекта

    Элемент справочника "Правила получения фактических данных для проектного бюджетирования" содержит реквизиты:

  • Кнопка Зарегистрировать документы к отражению — производит регистрацию документов указанных типов для отражения данных в проектном бюджетировании с даты, установленной в Параметрах подсистемы PM в группе "Проектное бюджетирование";
  • Раздел — определяет регистр, в котором будет формироваться запись при отражении фактических данных для проектного бюджетирования по документам, указанным в поле "Типы документов":
  • Доходы и расходы – будет сформирована запись в регистре сведений Факт доходов и расходов и регистре накопления Факт доходов и расходов (Обороты);
  • Движение денежных средств – будет сформирована запись в регистре сведений Факт движений денежных средств.
  • Тип правила — определяет источник, по данным которого будут формироваться значения для отражения данных в бюджетировании:
  • Бюджетирование – отражение данных в проектном бюджетировании производится по правилу получения фактических данных, настроенному для статьи бюджета. Данный тип правила доступен только для конфигурации "1С:ERP+PM Управление проектной организацией 2";
  • Произвольный запрос – позволяет настроить произвольную схему получения фактических данных.
  • Распределять факт по плану – при включенной опции, система в момент отражения данных распределяет фактическую сумму доходов / расходов согласно произведенной настройке базы распределения фактических данных.
  • База распределения – переключателем выбирается база распределения расходы или доходы. Переключатель доступен при включенной опции "Распределять факт по плану". Для проектного бюджетирования предусмотрено получение фактических данных по проектной задаче с типом "Этап" или проектной задаче с типом "Модель пакета работ" / "Веха". База распределения определяется в следующем порядке:
  • Проектная задача с типом "Этап":
  • учитываются запланированные доходы или расходы на вкладке "Фин.планы" по этапу, при отсутствии данных по этапу, учитываются данные суммарно по вложенным проектным задачам;
  • учитываются запланированные объемы на вкладке "Объемы" по этапу, при отсутствии данных по этапу, учитываются данные суммарно по вложенным проектным задачам;
  • Проектная задача типом "Модель пакета работ" / "Веха":
  • учитываются запланированные доходы или расходы на вкладке "Фин.планы" по проектной задаче;
  • учитываются запланированные объемы на вкладке "Объемы" по проектной задаче;
  • Ожидать отражение в рег.учете – опция определяет в какой момент будут формироваться данные для проектного бюджетирования. Если опция включена, то данные для проектного бюджетирования будут сформированы после отражения документов в регламентированном учете;
  • Правило отключено – опция отключает правило отражения данных для проектного бюджетирования. При установке опции, правило отражения фактических данных применяться не будет;
  • Наименование – наименование правила;
  • Формировать наименование автоматически – включенная опция формирует наименование правила автоматически по шаблону:
  • [Раздел]: [Тип правила], если тип правила "Произвольный запрос";
  • [Раздел]: [Правило получения факта по статьям бюджетов], если тип правила "Бюджетирование".

    • Важно! Изменение реквизита "Наименование" становится не доступным при включенной опции "Формировать наименование автоматически".

  • Комментарий – произвольный текстовый комментарий.

    • Важно! Для корректной работы правила отражения фактических данных для проектного бюджетирования при выборе типа правил «Бюджетирование» должны быть сопоставлены статьи доходов, статьи расходов и статьи движения денежных средств со статьями бюджета Сопоставление производится с помощью обработки Сопоставление финансовых статей.

    Табличная часть "Типы документов"

    Табличная часть "Типы документов" содержит типы документов, которыми будут формироваться записи в регистр, указанный в поле "Раздел".

    При выборе типа правила "Бюджетирование" на форме справочника доступны следующие реквизиты:

  • Правило получения факта по статьям бюджетов – выбирается правило из справочника Правила получения фактических данных по статьям бюджетов, по которому будет производиться получение фактических данных по статьям бюджета.
  • Вкладка "Сопоставление реквизитов" – содержит значение заполнения каждой аналитики при получении фактических данных:
  • Кнопка Заполнить по схеме получения данных – производит автоматическое заполнение значения аналитики по источнику данных, указанному в правилах получения факта по статьям бюджета;
  • База распр. – включенная опция указывает, по какой базе плановых данных должны распределяться фактические данные;
  • Реквизит – содержит предопределенный список реквизитов;
  • Заполнять по схеме – опция определяет способ заполнения значения аналитики;
  • Значение заполнения – указывается значение аналитики. Выбор значения аналитики определяется опцией "Заполнять по схеме". Если опция включена, значение аналитики указывается по источнику данных, установленному в правилах получения факта по статьям бюджета. Если опция отключена, то указывается конкретное значение аналитики.

    • При выборе типа правила "Произвольный запрос" на форме справочника доступны следующие реквизиты:

  • Настроить схему получения данных – открывает конструктор схемы компоновки данных

    • Примечание. Для настройки схемы получения данных необходимо запустить конфигурацию в режиме толстого клиента.

  • Кнопка Загрузить схему компоновки из файла – осуществляет загрузку настройки схемы компоновки данных из локального файла в формате *xml
  • Кнопка Выгрузить схему компоновки данных в файл – осуществляет выгрузку настройки схемы компоновки данных в локальный файл в формате *xml.
  • Вкладка "Сопоставление реквизитов" – содержит значение заполнения каждой аналитики при получении фактических данных:
  • Кнопка Заполнить по схеме получения данных – производит автоматическое заполнение значения аналитики по источнику данных, указанному в схеме компоновке данных;
  • База распр. – включенная опция указывает, по какой базе плановых данных должны распределяться фактические данные;
  • Реквизит – содержит предопределенный список реквизитов;
  • Заполнять по схеме – опция определяет способ заполнения значения аналитики;
  • Значение заполнения – указывается значение аналитики. Выбор значения аналитики определяется опцией "Заполнять по схеме". Если опция включена, значение аналитики указывается по источнику данных, указанному в схеме компоновки данных. Если опция отключена, то указывается конкретное значение аналитики.
  • Вкладка "Отбор" – содержит дополнительный отбор для настройки правил отражения фактических данных.
  • Вкладка "Параметры" – содержит параметр и его значение.
