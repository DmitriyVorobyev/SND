Справочник Настройки распределения БДР

Назначение

Справочник "Настройки распределения БДР" предназначен для хранения настроек автоматического распределения с заданными условиями плановых сумм доходов по проектным задачам в разрезе ролей и подразделений, с возможностью выделения сумм НДС как из плана доходов, так и из плана расходов. Настройка, применяемая по умолчанию, задается в Параметрах подсистемы PM, элементах справочников Проекты (вкладка "Опции проектной модели") и Портфели проектов, а также в обработке Распределение БДР.

Настройка распределения БДР используется в обработке Распределение БДР, которая вызывается в Структуре проекта из подменю "Еще" - "Распределить БДР" для всех задач проекта, а также в контекстном меню для выделенных задач структуры проекта.

В системе существует возможность хранения нескольких вариантов настроек распределения БДР.

Форма объекта

При заполнении формы элемента справочника "Настройки распределения БДР" необходимо заполнить следующие реквизиты:

  • Код – формируется автоматически;
  • Наименование – наименование настройки распределения БДР.

    • Выделение НДС

  • Ставка НДС по умолчанию – ставка НДС, которая будет применяться по умолчанию для расчета сумм НДС доходов и расходов при выделении НДС. Реквизит доступен при установке хотя бы одного из флагов: "Выделить НДС расходов", "Выделить НДС доходов";
  • Выделить НДС в плане доходов – если флаг установлен, при распределении доходов будут выделены суммы НДС из плановых сумм доходов;
  • Выделить НДС в плане расходов – если флаг установлен, при распределении доходов будут выделены суммы НДС из плановых сумм расходов;
  • Не выделять НДС в расходах по статьям затрат – в табличной части указываются статьи затрат, по которым не требуется выделять НДС. Табличная часть доступна при установке флага "Выделить НДС расходов".

    • Распределение доходов

  • Распределить доходы по расходам– определяет необходимость распределить доходы по расходам. Распределение может быть выполнено двумя способами:
  • По суммам - из сумм доходов в табличной части "Распределение доходов" будут выделены суммы, равные суммам расходов из табличной части "Распределение расходов" с теми же аналитиками "Подразделение", "Специальность" и "СС/СП". Оставшиеся части сумм доходов будут распределены в зависимости от опции Распределить доходы пропорционально трудозатратам. Если заполнен реквизит Выделить расходы СС/СП (признак из справочника Собственные силы/субподряд), то при распределении доходов будут учитываться только суммы распределенных расходов с указанным признаком. Если реквизит не заполнен, при распределении будут учитываться все суммы распределенных расходов. 
  • Пропорционально -суммы доходов будут распределены по расходам пропорционально суммам расходов. Если заполнен реквизит Выделить расходы СС/СП (признак из справочника Собственные силы/субподряд), то при распределении доходов сначала будут выделены суммы расходов с указанным признаком, а затем остаток будет распределен пропорционально суммам расходов с признаком отличным от указанного.
  • Распределить доходы пропорционально трудозатратам – если флаг установлен, суммы доходов в табличной части "Распределение доходов" будут распределены пропорционально плановым трудозатратам по ролям.

    • Важно! Если в проектной задаче запланированы трудозатраты только по предварительному уровню планирования, то распределение доходов будет производиться в разрезе ролей предварительного уровня. Если в проектной задаче есть плановые трудозатраты по окончательному уровню планирования, то распределение доходов будет производиться в разрезе ролей окончательного уровня планирования.

  • Исключить роли СС/СП – признак из справочника Собственные силы/субподряд. Трудозатраты по ролям с этим признаком не будут учитываться при распределении доходов. Если реквизит не заполнен, при распределении будут учитываться все трудозатраты. Реквизит доступен при установленном флаге Распределить доходы пропорционально трудозатратам.

    • Примечание. Проверяется признак СС/СП, указанный в элементе справочника Роли трудовых ресурсов.

  • Распределить план выпуска для задач с трансляцией в доходы – определяет необходимость распределить объемы по расходам. Распределяются объемы только типа "Номенклатура" и только тех проектных задач, у которых включена опция Включить объемы в БДР.
  • Комментарий – текстовое поле.
