Справочник﻿ Шаблоны контрагентов

Назначение

Справочник "Шаблоны контрагентов" предназначен для хранения в информационной базе шаблонов контрагентов.

Шаблон контрагента — это «"виртуальный» контрагент, который используется при сохранении финансовых планов в шаблоне проектной задачи. Например, "Заказчик", "Подрядчик", "Поставщик" и так далее.

При создании элементов шаблона проекта при помощи обработки Сохранение проекта в шаблон производится замена реальных контрагентов из справочника Контрагенты на "виртуальных" контрагентов, элементов справочника "Шаблоны контрагентов", по схеме, указанной пользователем.

При создании элементов проекта на основании шаблона при помощи обработки Создание проекта из шаблона производится замена "виртуальных" контрагентов из шаблона на элементы справочника Контрагенты по схеме, указанной пользователем.

Форма объекта

При заполнении формы элемента справочника "Шаблоны контрагентов" необходимо заполнить следующие обязательные реквизиты:

  • Код элемента — формируется автоматически;
  • Наименование — наименование шаблона проекта;
  • Полное наименование — полное наименование шаблона контрагента.
