Справочник﻿ Профили распределения доходов и расходов 

Назначение

Справочник "Профили распределения доходов и расходов" предназначен для хранения профилей распределения доходов и расходов по временным периодам.

Профиль распределения доходов и расходов — это совокупность правил привязки элементов БДР к срокам проектных задач, описывающая распределение 100% от суммы строки плана БДР по календарным периодам в рамках сроков проектной задачи.

Профиль распределения может быть построен по одному из двух способов:

  • Распределение по датам начала и завершения проектной задачи.
  • Равномерное распределение по месяцам.

    • Форма объекта

    При создании элемента справочника "Профили распределения доходов и расходов" необходимо заполнить следующие обязательные реквизиты:

  • Код элемента — уникальный код элемента (формируется автоматически);
  • Наименование — наименование профиля (есть возможность автоматического формирования);
  • Способ распределения по периоду — способ распределения суммы по календарному периоду. В зависимости от значения этого реквизита изменяется состав элементов управления, отвечающих за настройку профиля.

    • Распределение по датам начала и завершение проектной задачи

    В этом случае настройка профиля распределения представляет собой табличную часть с колонками "Способ привязки" (к началу или к завершению проектной задачи), "Задержка", "Доля суммы" (в процентах). Сумма всех долей должна составлять ровно 100%.

    Распределение производится следующим образом:

  • Для каждой строки вычисляется календарный период. Вычисление производится следующим образом: к дате начала (или к дате завершение, в зависимости от способа привязки) проектной задачи прибавляется указанная в строке задержка.
  • Для каждой строки вычисляется сумма. Вычисление производится простым взятием доли, указанной в строке профиля распределения, от общей суммы по строке плана БДР.

    • Равномерное распределение по месяцам

    В этом случае профиль представляет собой набор реквизитов, а именно:

  • Распределять только по полным месяцам. Если эта опция установлена, то период времени для распределения суммы строки плана БДР будет ограничен только полными месяцами. В случае если для конкретной проектной задачи период распределения не будет содержать в себе ни одного целого месяца, эта опция системой игнорируется.
  • Способ привязки. Может принимать одно из двух значений:
  • К началу месяца — в этом случае доходы и расходы будут начисляться на первый календарный день месяца.
  • К концу месяца — в этом случае доходы и расходы будут начисляться на последний календарный день месяца.

    • Распределение производится следующим образом: длительность проектной задачи разделяется на месяцы, а общая сумма дохода или расхода равномерно распределяется среди них.

    Дополнительно

    Профили распределения доходов и расходов используются при планировании БДР в следующих объектах конфигурации:

  • Документ Проектная задача;
  • Справочник Шаблоны проектных задач.
