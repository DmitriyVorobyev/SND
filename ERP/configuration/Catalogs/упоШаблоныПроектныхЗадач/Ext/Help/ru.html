Справочник Шаблоны проектных задач

Назначение

Справочник "Шаблоны проектных задач" предназначен для хранения в системе шаблонов проектных задач.

Справочник "Шаблоны проектных задач" подчинен справочнику Шаблоны проектов и предназначен для хранения информации об элементах шаблона проекта уровня проектной задачи. Структура реквизитов справочника фактически дублирует структуру реквизитов документа Проектная задача, за исключением календарных сроков — в шаблонах календарные сроки не используются.

Форма объекта

При заполнении формы элемента справочника "Шаблоны проектных задач" необходимо заполнить следующие обязательные реквизиты:

  • Код – формируется автоматически;
  • Название задачи - вводится наименование задачи шаблона.
  • Проект – указывается принадлежность шаблона задачи шаблону проекта выбором значения из справочника Шаблоны проектов;

    • Закладка "Параметры"

    На этой закладке представлены основные параметры шаблона проектной задачи.

  • Вид операции – указывается вид операции для шаблона задачи. Значение выбирается из списка значений справочника Виды операций.
  • Объект – указывается объект, к которому относится текущий шаблон задача. Значение выбирается из списка значений справочника Объекты.

    • Место задачи в структуре декомпозиции работ

  • Родитель – проектная задача шаблона проекта, которой в рамках СДР подчинена текущая проектная задача. Если задача-родитель не выбрана, это означает, что текущая проектная задача находится на самом верхнем уровне СДР шаблона проекта. Изменение задачи-родителя производится посредством кнопки Изменить. Кнопка Удалить очищает значение реквизита "Родитель", после записи изменений задача будет перемещена на самый верхний уровень СДР.

    • Сроки проектной задачи

  • Ручной ввод – позволяет вручную указать произвольные сроки проектной задачи, без учета связей с задачами-предшественниками;
  • При расчете сроков проекта – сроки проектной задачи будут получены автоматически при расчете расписания проекта, исходя из длительности задачи и связей с задачами-предшественниками;

    • Важно! Опции "Ручной ввод" и "При расчете сроков проекта" являются взаимоисключающими.

  • Дата начала план – плановая дата начала шаблона проектной задачи, реквизит недоступен для заполнения в шаблоне задачи при выборе режима ввода сроков "При расчете сроков проекта".
  • Дата завершения план – плановая дата завершения шаблона проектной задачи, реквизит недоступен для заполнения в шаблоне задачи при выборе режима ввода сроков "При расчете сроков проекта".

    • Тип проектной задачи

    Реквизит указывает, к какому из возможных типов принадлежит создаваемый шаблон проектной задачи:

  • Проектная задача является этапом или подэтапом проекта – такая проектная задача является контейнером для проектных задач более низких уровней декомпозиции. Содержит данные о трудозатратах и выполняемых работах.
  • Проектная задача является моделью пакета работ – проектная задача, которая находится на нижнем уровне декомпозиции. Содержит данные о трудозатратах и выполняемых работах.
  • Проектная задача является вехой – проектная задача, которая имеет нулевую длительность и не содержит данных о трудозатратах и выполняемых работах.

    • Общая календарная длительность модели пакета работ

  • Кнопка Рассчитать длительность → По ролям – рассчитывает длительность шаблона проектной задачи по плановым трудозатратам ролей. Длительность будет рассчитываться делением максимального значения плановых трудозатрат (с учетом единицы измерения, независимо от уровня планирования) на количество часов в единице измерения длительности проектной задачи. Кнопка доступна только для шаблонов задач с типом "Проектная задача является моделью пакета работ".
  • Кнопка Рассчитать длительность → По субпродуктам – рассчитывает длительность шаблона проектной задачи по данным закладки "Объемы". Если для субпродукта указаны количество и плановая скорость освоения единицы объемов в день, то делением количества на скорость будет получена длительность. Если указано несколько субпродуктов, то длительность будет браться максимальной из возможных значений. Кнопка доступна только для шаблонов задач с типом "Проектная задача является моделью пакета работ".
  • Длительность модели пакета работ – реквизит доступен только для шаблонов задач с типом "Проектная задача является моделью пакета работ", определяет длительность шаблона проектной задачи в единицах измерения, указанных в реквизите "Единица измерения времени".
  • Единица измерения времени – реквизит доступен только для шаблонов задач с типом "Проектная задача является моделью пакета работ", определяет единицу измерения длительности проектной задачи, значение выбирается из справочника Единицы измерения времени.
  • Календарь задачи – календарь, используемый для расчета длительности проектной задачи. Заполняется подбором из справочника Рабочие календари, в том случае, если для расчета сроков задачи планируется использовать календарь отличный от календаря проекта. При моделировании шаблона в обработке Панель шаблона проекта, в качестве календаря проекта используется календарь, указанный в реквизите "Рабочий календарь" обработки.
  • Длительность без учета календаря проекта - если флаг установлен, то длительность проектной задачи при расчете сроков проектной задачи будет вычисляться без учета рабочего календаря проекта или календаря проектной задачи, из расчета 168 часов в неделю (24/7). Если флаг не установлен, то, наоборот, при расчете длительность будет вычисляться по календарю проекта (задается документом Регистрация проекта) или, если заполнен реквизит "Календарь задачи", по календарю проектной задачи. Это означает, что при расчете сроков проектной задачи по длительности будут приниматься во внимание только те дни, которые определены как рабочие календарем проекта или проектной задачи. При моделировании шаблона в обработке Панель шаблона проекта, в качестве календаря проекта используется календарь, указанный в реквизите "Рабочий календарь" обработки. Опция доступна только для шаблонов задач с типом "Проектная задача является моделью пакета работ".

    • Закладка "Предусловия"

    На этой закладке представлен список предусловий шаблона проектной задачи - тех проектных задач выбранного шаблона проекта, сроки выполнения которых взаимосвязаны со сроками выполнения текущей проектной задачи. Предусловия отражают связи между разными элементами шаблона проекта.

  • Кнопка Добавить / Подобрать – открывает универсальную форму подбора табличной части вкладки предусловия.

    • В табличной части указываются следующие значения:

  • № – номер по порядку. Заполняется автоматически при выборе предшественника.
  • Задача-предшественник – задача шаблона проекта, с которой будет установлена связь у текущей задачи.
  • Тип связи – выбирается один из четырех видов связи:
  • Окончание–начало – выполнение текущей задачи начнется после завершения предыдущей (по умолчанию);
  • Начало–начало – выполнение текущей задачи начнется одновременно с предыдущей;
  • Окончание–окончание – выполнение текущей задачи закончится одновременно с предыдущей;
  • Начало–окончание – выполнение предыдущей задачи начнется после завершения текущей.
  • Задержка – указывается период задержки между выполнением текущей задачи шаблона и предыдущей задачи шаблона проекта.
  • Единица времени – единица измерения периода задержки, элемент справочника Единицы измерения времени.

    • Закладка "Ресурсы"

    На этой закладке расположены элементы управления, которые используются для ввода информации о ресурсах, запланированных к использованию в шаблоне проектной задачи. Эти элементы управления, в свою очередь, разнесены по нескольким вкладкам:

    Вкладка "Роли трудовых ресурсов"

  • Включить в БДР – если опция включена, стоимость (внутренняя) трудозатрат по ролям автоматически включается в план расходов (при загрузке данных из шаблона в проект).
  • Уровень планирования трудозатрат для БДР – выбор уровня планирования, данные которого включаются в план расходов (реквизит доступен при включении опции "Включить в БДР"):
  • Авто:
  • если в проектной задаче заполнена табличная часть только по предварительному уровню планирования, то в план расходов будут включаться данные предварительного уровня;
  • если в проектной задаче заполнена табличная часть по окончательному уровню планирования, то в план расходов будут включаться данные окончательного уровня (независимо от того, есть ли данные по предварительному уровню);
  • Предварительный по ролям;
  • Окончательный по ролям;
  • Норма стоимости – элемент справочника Нормы стоимости, используется для автоматического расчета стоимости привлечения трудовых ресурсов, перечисленных в табличной части. Расчет стоимости ресурсов по норме производится при помощи кнопки Пересчитать по норме.
  • Внешняя норма стоимости – элемент справочника Нормы стоимости, используется для автоматического расчета внешней стоимости привлечения трудовых ресурсов, перечисленных в табличной части. Расчет стоимости ресурсов по норме производится при помощи кнопки Пересчитать по норме.
  • Кнопка Добавить / Подобрать – открывает универсальную форму подбора табличной части.
  • Кнопка Основная роль – позволяет назначить основную роль трудового ресурса для шаблона проектной задачи (при этом роль выделится в табличной части полужирным шрифтом). При создании структуры проекта из шаблона проекта основная роль из шаблона проектной задачи сохраняется для проектной задачи и в обработке Структура проекта будет выводится в колонке "Основная роль". Также, при сохранении проекта в шаблон, если у проектной задачи была определена основная роль, она сохранится для шаблона проектной задачи.
  • Кнопка Заполнить → Установить общий профиль – позволяет произвести групповую установку выбранного профиля распределения трудозатрат для всех строк табличной части.

    • Табличная часть содержит следующие реквизиты:

  • Роль трудового ресурса – элемент справочника Роли трудовых ресурсов, указывает на ту роль, которая требуется для выполнения работ в рамках выполнения проектной задачи.
  • Подразделение – элемент справочника Подразделения. В списке значений отображаются только те подразделения, в состав которых данная роль трудового ресурса была включена с помощью документа Регистрация состава подразделения.
  • Уровень планирования – выбирается значение "Предварительный"/"Окончательный". Планирование по предварительному/окончательному уровням ведется независимо.
  • Трудозатраты – количество трудозатрат, которые потребуются для выполнения проектной задачи.
  • Ед. изм. – элемент справочника Единицы измерения времени. Реквизит указывает, в какой именно единице измерения представлены трудозатраты.
  • Стоимость – стоимость одной единицы трудозатрат. Стоимость привлечения трудовых ресурсов можно вводить как вручную, так и при помощи ранее заданной нормированной стоимости использования ресурсов.
  • Общая стоимость – полная стоимость привлечения трудового ресурса к выполнению проектной задачи.
  • Внешняя стоимость – внешняя стоимость одной единицы трудозатрат. Стоимость привлечения трудовых ресурсов можно вводить как вручную, так и при помощи ранее заданной нормированной стоимости использования ресурсов.
  • Общая Внешняя стоимость – полная внешняя стоимость привлечения трудового ресурса к выполнению проектной задачи.
  • Профиль распределения – элемент справочника Профили распределения трудозатрат. Реквизит указывает, как именно будут распределены трудозатраты по времени, и какая загрузка трудового ресурса потребуется для выполнения работ по проектной задаче.

    • Вкладка "Материалы и оборудование"

    Стоимость использования материальных ресурсов можно вводить как вручную, так и при помощи ранее заданной нормированной стоимости использования ресурсов.

  • Норма стоимости – элемент справочника Нормы стоимости, используется для автоматического расчета стоимости материальных ресурсов, перечисленных в табличной части. Расчет стоимости производится при помощи кнопки Пересчитать по норме.
  • Включить в БДР – флаг предназначен для включения учета введенного плана потребности в материальных ресурсах в плане расходов БДР (при загрузке данных из шаблона в проект).

    • Заполнение табличной части "Потребности":

  • Кнопка Добавить – добавляет новую строку в табличную часть.
  • Кнопка Подобрать – открывает универсальную форму подбора табличной части.
  • Кнопка Заполнить → Установить способ привязки – позволяет произвести групповую установку выбранного способа привязки к дате заказа для всех строк табличной части.
  • Кнопка Заполнить → Установить задержку заказа – позволяет произвести групповую установку срока задержки заказа в днях для всех строк табличной части.
  • Кнопка Заполнить → Установить статью затрат – позволяет произвести групповую установку выбранной статьи затрат для всех строк табличной части.
  • Кнопка Заполнить → Установить профиль распределения – позволяет произвести групповую установку выбранного профиля распределения доходов и расходов для всех строк табличной части.
  • Кнопка Заполнить → Установить контрагента – позволяет произвести групповую установку выбранного контрагента для всех строк табличной части.

    • Табличная часть содержит следующие реквизиты:

  • Номенклатура – элемент справочника Номенклатура, являющийся материалом или оборудованием;
  • Количество – количество единиц ресурса, запланированное для использования в проектной задаче;
  • Ед. изм. – единица, в которой измеряется материальный ресурс, элемент справочника Единицы измерения времени (для оборудования) или Упаковки (для материалов);
  • Стоимость – стоимость использования одной единицы материального ресурса;
  • Общая стоимость – полная стоимость использования указанного количества единиц материального ресурса;
  • Валюта – валюта договора, значение из справочника Валюты;
  • Контрагент – поставщик материальных ресурсов или оборудования, элемент справочника Контрагенты;
  • Договор – договор с поставщиком, элемент справочника Договоры контрагентов.
  • Способ привязки – настройки привязки расхода (к конкретной дате либо по выбранному профилю распределения);
  • Статья затрат – статья, на которую будут отнесены затраты по приобретению ресурсов, элемент справочника Статьи затрат по проектам;
  • Профиль / Дата привязки:
  • если способ привязки "По профилю распределения" – указывается элемент справочника Профили распределения доходов и расходов.
  • если способ привязки "К конкретной дате" – указывается дата привязки.
  • Способ привязки к дате заказа – способ привязки даты потребности в материале или оборудовании к периоду проектной задачи (к началу или к завершению задачи).
  • Задержка заказа – задержка между датой начала или завершения проектной задачи и датой потребности в материале или оборудовании.

    • Заполнение табличной части "Распределение потребностей по подразделениям":

  • Кнопка Добавить – добавляет новую строку в табличную часть.
  • Кнопка Заполнить → Заполнить по умолчанию – в табличной части добавляется одна строка, в которой автоматически заполняются реквизиты значениями из табличной части "Состав материальных ресурсов" и Параметров подсистемы PM (группа "Опции проектной модели" → "Значения заполнения по умолчанию").
  • Кнопка Заполнить → Распределить по периодам – распределяет сумму в выделенной строке табличной части "Распределение потребностей по подразделениям" по периодам пропорционально ранее распределенной сумме, при условии, что в столбце "Не распределено" есть нераспределенная сумма, а нераспределенное количество равно 0.

    • В табличной части "Распределение потребностей по подразделениям" можно распределить строчки из табличной части "Состав материальных ресурсов" по следующим аналитикам:

  • Подразделение – подразделение-исполнитель;
  • Специальность – роль трудового ресурса - исполнителя;
  • СС/СП – признак роли собственные силы / субподряд;
  • Количество – распределение количества материалов/оборудования;
  • Сумма – сумма распределения;
  • Способ привязки – способ привязки плана потребностей к датам:
  • По профилю распределения (в соответствии с настройкой профиля распределения, указанного в поле справа);
  • К конкретной дате (в соответствии с датой, указанной в поле справа);
