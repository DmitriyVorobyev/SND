Справочник Задания

Назначение

Справочник "Задания" предназначен для хранения информации о внутренних работах.

Для удобства работы с заданиями используется обработка Работа с заданиями.

Форма объекта

На форме элемента кнопка Показать/скрыть историю событий и комментарии – включает/отключает дополнительное информационное окно.

Примечание. Состав и порядок реквизитов и закладок задания можно изменить при помощи настройки формы (кнопка Еще → Изменить форму).

К основным реквизитам справочника "Задания" относятся следующие:

  • Код – формируется автоматически (скрытый реквизит);
  • Наименование – название задания;
  • Вид – вид задания, значение выбирается из предопределенных элементов справочника Виды заданий ("Поручение", "Проектное решение", "Обсуждение", "Согласование");
  • Исполнитель – трудовой ресурс, который привлекается к выполнению задания, элемент справочника Трудовые ресурсы (реквизит доступен для всех видов заданий, кроме "Согласование");
  • Роль – элемент справочника Роли трудовых ресурсов (реквизит доступен для заданий вида "Поручение" и "Согласование"):
  • для заданий вида Поручение – указывает на то, какие именно работы будет выполнять трудовой ресурс в рамках задачи;
  • для заданий вида Согласование – роль, которая требуется для выполнения работ в рамках выполнения задания;
  • Подразделение – элемент справочника Подразделения. В списке отображаются только те подразделения, в состав которых указанная роль трудового ресурса была включена с помощью документа Регистрация состава подразделения;
  • Вид согласования – определяет порядок согласования согласующими лицами, указанными на закладке "Согласующие" (реквизит доступен только для заданий вида "Согласование"). Выбирается один из вариантов:
  • Со всеми сразу;
  • По очереди.
  • Задание подразделению – признак задания (с видом "Поручение"), выдаваемого руководителю подразделения, ответственному за выполнение проектной задачи, по планированию работ этапа, либо прогнозированию трудозатрат подразделения. Флаг устанавливается автоматически при выдаче задания и недоступен для редактирования вручную;
  • Вид задания – вид задания подразделению:
  • Задание на планирование – задание на декомпозицию этапа по работам с указанием плановых сроков и распределению трудозатрат подразделения по работам на окончательном уровне планирования. Задание на планирование выдается трудовому ресурсу, владельцем которого является руководитель подразделения, назначенный руководителем проектной задачи, для которой выдается задание. Вид задания устанавливается автоматически при выдаче задания на планирование;
  • Задание на прогноз – задание на прогнозирование трудозатрат подразделения – указание фактических трудозатрат подразделения и актуализацию плановой загрузки ролей и исполнителей подразделения по фактическим данным. Задание на прогноз выдается трудовому ресурсу, владельцем которого является руководитель подразделения, назначенный руководителем проектной задачи, для которой выдается задание. Вид задания устанавливается автоматически при выдаче задания на прогноз.
  • Автор – сотрудник, создавший задание. Указывается автоматически.

    • Важно! Задание на планирование / прогноз можно выдать несколькими способами:

  • Отправить задание на планирование из обработки Структура проекта кнопкой Еще → Отправить задания на планирование (создает задания на планирование этапов для всех проектных задач текущего проекта / программы / портфеля, руководителем которых является сотрудник, не являющийся руководителем проекта).
  • Отправить задание на прогноз из обработки Структура проекта кнопкой Еще → Отправить задания на прогноз (создает задания на прогноз для всех проектных задач текущего проекта / программы / портфеля, руководителем которых является сотрудник, не являющийся руководителем проекта).
  • Создать копированием уже существующего задания на планирование / прогноз из обработки Работа с заданиями или формы задания. Данный способ позволяет выдать несколько активных заданий на планирование / прогноз по одной проектной задаче.

    • Важно! При выдаче заданий на планирование / прогноз из обработки Структура проекта проверяется наличие у задачи активного (в статусе "Выдано" / "Выполняется" / "Уточняется" / "Завершено") задания на планирование / прогноз. Если активное задание есть, новое задание на планирование / прогноз по этой задаче выдано не будет. Новое задание будет отправлено только в случае, если все ранее выданные задания на планирование / прогноз по задаче переведены в статус "Закрыто" или "Отменено".

    Примечание. Статус выданного для проектной задачи задания на планирование / прогноз отображается:

  • В обработке Структура проекта в колонке "Задание на планирование" / "Задание на прогноз" / "Задания подразделению". Если для одной проектной задачи выдано несколько заданий на планирование / прогноз, в колонке будет отображен минимальный статус из списка незакрытых заданий (статусы по возрастанию: "Выдано" → "Уточняется" → "Выполняется" → "Завершено") Если заданий с минимальным статусом несколько – будет отображен статус задания на планирование / прогноз, выданного раньше других.
  • В обработке Панель руководителя подразделения в колонке "Статус задания на планирование" / "Статус задания на прогноз" / "Статусы заданий от РП". Если для одной проектной задачи выдано несколько заданий на планирование / прогноз, в колонке будет отображен минимальный статус из списка незакрытых заданий (статусы по возрастанию: "Выдано" → "Уточняется" → "Выполняется" → "Завершено") Если заданий с минимальным статусом несколько – будет отображен статус задания на планирование / прогноз, выданного раньше других.

    • Связи

  • Портфель проектов – элемент справочника Портфели проектов. Этот реквизит показывает, какому портфелю проектов относится задание;
  • Проект – проект, к которому относится задание, элемент справочника Проекты. Обязательно заполняется для заданий вида "Обсуждение";
  • Проектная задача – проектная задача, к которой относится задание. Обязательно заполняется для заданий вида "Обсуждение", если в карточке выбранного проекта на закладке "Опции проектной модели" не включена опция "Разрешить создание обсуждений без указания проектной задачи";
  • Вид операции – вид операции задания. Значение выбирается из списка значений справочника Виды операций;
  • Объект базы – объект информационной базы, к которому относится задание;
  • Основное – признак, указывающий, является данное задание основным или нет (реквизит доступен только для заданий вида "Поручение" или "Согласование").

    • Важно! Для каждой проектной задачи может быть только одно основное задание.

    Примечание. Основное задание с видом "Поручение" для проектной задачи отображается в обработке Структура проекта в колонке "Основное поручение".

  • Синхронизировать с задачей – если опция включена, плановые даты начала и окончания задания будут определяться плановыми датами начала и завершения работ по проектной задаче. Реквизит доступен для заданий вида "Поручение" при указании проектной задачи. Опция включена по умолчанию у заданий, созданных автоматически при назначении трудового ресурса на проектную задачу.
  • Флаг автоматически снимается, когда задание переводится в статус "Завершено";
  • Флаг автоматически устанавливается снова при одновременном выполнении следующих условий:
  • До этого флаг был снят автоматически, когда задание перешло в статус "Завершено";
  • Задание из статуса "Закрыто" или "Завершено" переводится в статус "Выполняется" (кнопка Доработать) или "Выдано" (кнопка Выдать заново).

    • Примечание. Задание на планирование с включенной опцией "Синхронизировать с задачей" будет автоматически отменено, если исполнитель задания не совпадает с трудовым ресурсом, который назначен на проектную задачу.

    Закладка "Описание и сроки"

    Закладка доступна для всех видов заданий, кроме типа "Обсуждение".

  • Описание – текстовое поле с текстом задания;
  • Дата начала (план) – плановая дата начала работы над заданием;
  • Дата окончания (план) – плановая дата окончания работы над заданием;
  • Дата начала (прогноз) – прогнозная дата начала работы над заданием. Реквизит доступен для заданий всех видов, кроме "Обсуждение";
  • Дата окончания (прогноз) – прогнозная дата окончания работы над заданием. Реквизит доступен для заданий всех видов, кроме "Обсуждение";

    • Примечание. На данный момент, значения реквизитов "Дата начала (прогноз)" и "Дата окончания (прогноз)" не используются в других объектах системы.

  • Решение о переходе в следующую фазу – решение, принятое при завершении текущей фазы проекта, элемент справочника Решения о переходе в следующую фазу. Реквизит доступен для задания с видом "Проектное решение", являющегося основным для фазы проекта;
  • Результат выполнения – текстовое поле с текстом результата выполнения задания. Реквизит доступен для заданий с типом "Поручение" или "Согласование";
  • Проектное решение – текстовое поле с текстом проектного решения. Реквизит доступен для заданий с типом "Проектное решение";
  • Дата начала (факт) – фактическая дата начала работы над заданием;
  • Дата окончания (факт) – фактическая дата окончания работы над заданием.

    • Закладка "Согласующие"

    Закладка доступна только для заданий вида "Согласование".

    Закладка содержит табличную часть, в которой указывается список согласующих лиц. При создании задания вида "Согласование", для согласующих лиц создаются подчиненные задания, результатом которых является принятие решения о согласовании (Согласовано/Не согласовано). Список этих заданий отображается в табличной части "Подчиненные задания".

    Табличная часть закладки "Согласующие" содержит следующие колонки:

  • N – номер строки, определяет порядок согласования при выборе вида согласования "По очереди";
  • Согласующее лицо – элемент справочника Трудовые ресурсы;
  • Статус – результат согласования:
  • Согласовано;
  • Не согласовано.

    • Закладка "Контролеры"

    Закладка доступна для всех видов заданий, кроме типа "Обсуждение".

    Табличная часть заполняется списком сотрудников, осуществляющих контроль выполнения задания. Значение выбирается из списка значений справочника Сотрудники.

    Закладка "Тема"

    Закладка доступна для заданий вида "Обсуждение".

  • Описание – текстовое поле с описанием темы обсуждения;
  • Итог – текстовое поле с описанием итогов обсуждения.

    • Закладка "Подчиненные задания"

    Закладка доступна для заданий всех видов.

    В таблице выведены задания, подчиненные текущему заданию. Количество подчиненных заданий отображается в заголовке закладки.

    Статусы заданий

    Изменение статуса задания производится разноцветными кнопками действий на панели истории событий задания: "Выдано", "Уточняется", "Выполняется", "Завершено" и др. Панель истории событий задания включается кнопкой Показать/скрыть историю событий и комментарии. Состав кнопок действий зависит от прав пользователя на задание, роли текущего сотрудника пользователя для задания (Автор, Исполнитель), а также статуса, в котором находится задание.
