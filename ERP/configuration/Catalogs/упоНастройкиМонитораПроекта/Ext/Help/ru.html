Справочник Настройки монитора проекта

Назначение

Справочник "Настройки монитора проекта" предназначен для создания и хранения настроек вывода показателей проекта в обработку Монитор проекта.

Важно! В обработку будут выведены значения показателей только с типом принадлежности "Общий" или "Только для проекта".

Важно! Значения показателей с режимом заполнения "Вручную" и типом принадлежности "Общий" будут выводиться в обработку, только если их значения зарегистрированы для проекта.

Форма объекта

При заполнении формы элемента справочника "Настройки монитора проекта" необходимо заполнить следующие обязательные реквизиты:

  • Код – формируется автоматически;
  • Наименование – название настройки.

    • Также необходимо указать дополнительные настройки выводимых показателей, распределенные по четырем закладкам.

    Закладка "Показатели шапки"

    На закладке "Показатели шапки" кнопкой Добавить подбирается набор показателей, элементов справочника Показатели проектов, отображаемых в шапке обработки. Является обязательной настройкой, т.е. должен быть указан хотя бы один показатель.

    В данную группу выводятся показатели со всеми типами значения.

    Закладка "Показатели прогресса"

    На закладке "Показатели прогресса" кнопкой Добавить подбирается набор показателей, элементов справочника Показатели проектов, отображающих прогресс проекта в процентах в виде круговой шкалы. Является обязательной настройкой, т.е. должен быть указан хотя бы один показатель.

    Важно! В данную группу выводятся показатели только с типом значения "Число".

    Важно! Обработка Монитор проекта выводит значения показателей прогресса в диапазоне от 0% до 100%, значения за переделами диапазона будут приведены к ближайшей границе.

    Закладка "Показатели графика"

    На закладке "Показатели графика" кнопкой Добавить подбирается набор показателей, элементов справочника Показатели проектов, выводимых в обработку в виде графика. Является обязательной настройкой, т.е. должен быть указан хотя бы один показатель.

    Важно! В данную группу выводятся показатели только с типом значения "Число".

    Важно! Показатели отображаются на графике с учетом периодов, настроенных на закладке "Периоды показателей графика". Для корректного отображения значений показателей по периодам, рекомендуется подбирать на данную закладку показатели, в которых учитываются значения по периодам.

    Закладка "Периоды показателей графика"

    На данной закладке подбираются периоды отображения показателей на графике. Является обязательной настройкой, т.е. должен быть указан хотя бы один период.
