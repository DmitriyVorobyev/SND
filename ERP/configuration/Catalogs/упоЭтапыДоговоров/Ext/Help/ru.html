Справочник Этапы договоров

Назначение

Справочник "Этапы договоров"﻿ предназначен для хранения информации об этапах договоров, являющихся составной частью календарного плана работ по договору.

Форма объекта

При заполнении формы элемента справочника "Этапы договоров" необходимо заполнить следующие обязательные реквизиты:

  • Код – формируется автоматически при записи элемента;
  • Наименование – наименование этапа.
