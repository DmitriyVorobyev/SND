Справочник Проекты



Если в справке напротив поля или элемента интерфейса есть иконка, то элемент доступен только в приложении "1С:PM Управление проектами КОРП" (1С:PM КОРП).

Назначение

Основным структурным объектом учета и управления в системе является проект.

Проект – ограниченный во времени комплекс взаимосвязанных мероприятий, проводимых предприятием с целью получения уникальных продуктов и/или результатов.

Справочник "Проекты" позволяет фиксировать и хранить в системе информацию о проектах.

Форма списка объектов справочника

На форме списка объектов справочника расположены следующие кнопки:

  • Кнопка Создать – создать новый элемент справочника;
  • Кнопка Создать новый элемент копированием текущего – создает новый элемент справочника путем копирования выделенного проекта;
  • Кнопка Создать на основании – позволяет создать на основании выбранного проекта некоторые виды документов, связанные с регистрацией фактических данных по проекту, актуализацией данных проекта и т.п. В созданных таким образом документах реквизит "Проект" будет заполняться автоматически текущим значением проекта;
  • Кнопка Сделать текущим – установить выбранный проект в качестве текущего;
  • Кнопка Паспорт проекта – открывает паспорт выделенного проекта;
  • Кнопка Структура проекта – открывает обработку Структура проекта для выделенного проекта;
  • Кнопка Открыть монитор проекта – открывает обработку Монитор проекта для выделенного проекта;
  • Кнопка Схема показателей проекта – открывает обработку Дерево ключевых показателей для выделенного проекта в соответствии с указанной в реквизите "Настройка дерева ключевых показателей" (закладка "Опции проектной модели") настройкой. Если реквизит не заполнен, будет предложено выбрать настройку при открытии обработки;
  • Кнопка Сетевой график – открывает отчет Сетевой график, который показывает структуру выделенного проекта в виде сетевого графика;
  • Кнопка Статусы проекта – открывает журнал документов Статусы проекта с отобранными по выделенному проекту документами;
  • Кнопка Риски – открывает справочник Риски проектов с установленным отбором по выделенному проекту;
  • Кнопка Управление версиями проекта – открывает обработку Управление версиями проекта, которая позволяет просматривать/добавлять/редактировать/помечать на удаление версии выбранного проекта;
  • Кнопка Статус-отчеты → Открыть сводные статус-отчеты по проекту – открывает реестр документов Сводный статус-отчет по проектам, содержащих выделенный проект;
  • Кнопка Статус-отчеты → Открыть статус-отчеты по проекту – открывает реестр документов Статус-отчет по проекту с отбором по выделенному проекту;

    • Важно! Кнопка Статус-отчеты доступна при включенной опции "Использовать статус-отчеты по проектам" в Параметрах подсистемы PM в группе "Статус-отчеты по проектам".

  • Кнопка Задания → Открыть задания – открывает перечень заданий по выбранному проекту;
  • Кнопка Задания → Открыть проектные решения – открывает перечень проектных решений по выбранному проекту;
  • Кнопка Задания → Открыть задания на планирование – открывает перечень заданий на планирование этапа проекта (с признаком "Задание подразделению" и видом задания "Задание на планирование") по выбранному проекту;
  • Кнопка Задания → Открыть задания на прогноз – открывает перечень заданий на прогноз (с признаком "Задание подразделению" и видом задания "Задание на прогноз") по выбранному проекту;
  • Кнопка Хозяйственные операции проекта – открывает обработку Хозяйственные операции проекта, в которой отображаются все заведенные в системе документы, относящиеся к выбранному проекту (в том числе непроведенные, если установлен соответствующий отбор);
  • Кнопка Открыть панель руководителя по программе – открывает обработку Панель руководителя с отбором по программе проектов, в которую включен выделенный проект;
  • Кнопка Отчеты – открывает перечень отчетов, которые можно сформировать по выделенному проекту;
  • Кнопка Импорт и экспорт → Сохранение проекта в шаблон – открывает обработку Сохранение проекта в шаблон, которая позволяет перенести данные из календарно-ресурсного плана проекта в шаблон проекта;
  • Кнопка Импорт и экспорт → Создание проекта из шаблона – открывает обработку Создание проекта из шаблона, которая позволяет перенести данные из шаблона в календарно-ресурсный план проекта;
  • Кнопка Импорт и экспорт → Экспорт в MS Project – открывает обработку Выгрузка данных в MS Project, которая позволяет выгрузить структуру проекта в Microsoft Project;
  • Кнопка Импорт и экспорт → Импорт из MS Project – открывает обработку Импорт из MSP, которая позволяет загрузить график из Microsoft Project в качестве структуры выбранного проекта;
  • Кнопка Импорт и экспорт → Загрузка из сметы – открывает обработку Загрузка из сметы, которая позволяет загрузить данные из локального файла в формате *arp в качестве структуры выбранного проекта;

    • Важно! Кнопка Импорт и экспорт → Загрузка из сметы доступна при включенной опции "Использовать загрузку из сметы" в Параметрах подсистемы PM в группе "Основные параметры".

  • Кнопка БДДС проекта – открывает обработку БДДС проекта для ввода данных по статьям бюджета движения денежных средств;
  • Кнопка БДР проекта – открывает обработку БДР проекта для ввода данных по статьям бюджета доходов и расходов.
  • Кнопка Еще → Распределение БДР → Распределить БДР: Проект – запускает обработку Распределение БДР, которая позволяет выполнить распределение доходов и расходов во всех проектных задачах проекта по подразделениям с учетом трудозатрат. Распределение производится в соответствии с настройками, указанными в карточке проекта (реквизит "Настройка распределения БДР" на закладке "Опции проектной модели").
  • Кнопка Еще → Распределение БДР → Мастер распределения БДР: Проект – открывает обработку Распределение БДР, которая позволяет произвести распределение доходов и расходов во всех проектных задачах проекта по подразделениям с учетом трудозатрат. Распределение производится в соответствии с настройками, указанными непосредственно в обработке.
  • Поиск – поиск в списке элементов по части наименования реквизита ("Проект", "Руководитель проекта (сотрудник)", "Статус проекта", "Портфель проектов", "Программа проектов", "Подразделение", "Организация", "Куратор проекта");
  • Поле отбора проектов по компоненту:
  • Проекты – в список выводятся проекты с компонентом "Проект";
  • Портфели проектов – в список выводятся проекты с компонентом "Портфель проектов";
  • Программы проектов – в список выводятся проекты с компонентом "Программа проектов";
  • Кнопка Настроить список... – открывает форму настроек списка.
  • Кнопка Очистить настройки списка проектов – очищает список настроек отбора, сортировки, условного оформления и группировки;
  • Кнопка Скрыть этапы – отвечает за отображение списка проектных задач выбранного проекта. Из списка, дважды щелкнув левой кнопкой мыши на элементе, можно перейти в документ Проектная задача. По умолчанию, для увеличения производительности кнопка нажата и список проектных задач скрыт.

    • В табличной части расположены колонки "Проект", "Руководитель проекта (сотрудник)", "Статус проекта", "Портфель проектов", "Программа проектов", "Подразделение", "Организация", "Куратор проекта", в которых выводятся значения соответствующих реквизитов из формы элемента справочника "Проекты". Щелкнув левой кнопкой по заголовку колонки можно сортировать элементы (по возрастанию / по убыванию) по данному реквизиту.
