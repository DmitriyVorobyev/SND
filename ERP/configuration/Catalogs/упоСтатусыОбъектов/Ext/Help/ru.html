Справочник Статусы объектов

Назначение

Справочник "Статусы объектов" предназначен для хранения статусов объектов, например, для хранения информации о статусах договоров, заключаемых предприятием.

В системе существуют следующие предопределенные статусы:

  • Запланирован;
  • На согласовании;
  • Подписан;
  • Выполняется;
  • Приостановлен;
  • Закрыт.

Также возможно добавление новых элементов справочника вручную.

 Примечание. В приложении "1С:ERP+PM Управление проектной организацией 2": для элементов справочника Договоры контрагентов доступен выбор только из предопределённых статусов.

Форма объекта

При заполнении формы элемента справочника "Статусы объектов" необходимо заполнить следующие реквизиты:

  • Код – формируется автоматически при записи элемента;
  • Наименование – наименование статуса;
  • Полное наименование – полное наименование статуса;
  • Комментарий – произвольный текст.
