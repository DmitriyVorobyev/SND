Справочник Программы проектов

Назначение

Справочник "Программы проектов" предназначен для хранения списка программ проектов.

Программа (Program) — ряд связанных друг с другом проектов, управление которыми координируется для достижения преимуществ и степени управляемости, недоступных при управлении ими по отдельности. Программы могут содержать элементы работ, имеющих к ним отношение, но лежащих за пределами содержания отдельных проектов программы.

Справочник "Программы проектов" позволяет:

  • Фиксировать и хранить в системе информацию о списках программ проектов и их основных проектов.

    • Форма объекта

    При заполнении формы элемента справочника "Программы проектов" необходимо заполнить следующие реквизиты:

  • Код элемента – формируется автоматически (при записи);
  • Наименование – наименование программы проектов;
  • Полное наименование – полное наименование программы проектов;
  • Проект структуры – основной проект структуры программы, элемент справочника Проекты (компонент "Программа проектов"). Реквизит является обязательным и формируется автоматически при записи программы, если значение не заполнено. Проект структуры можно изменить. По кнопке  Структура программы открывается обработка Структура проекта, в ней можно добавить проектные задачи проекта структуры программы;
  • Родитель – группа программы проектов;
  • Настройка показателей панели руководителя – настройка отображения данных в Панели руководителя (кнопка  Открыть панель руководителя по программе). Данные выводятся по проектам, у которых программа проектов указана в поле "Программа";
  • Комментарий – текстовое поле.

    • В системе существует следующая связь: программа проекта → проект структуры программы → проектные задачи программы проекта → подчиненный проект → проектные задачи проекта.

    Проанализировать введенную информацию о программе проекта и подчиненных проектах (структура, БДР, БДДС, трудозатраты, объемы) можно с помощью отчета План-фактный анализ по программе.
