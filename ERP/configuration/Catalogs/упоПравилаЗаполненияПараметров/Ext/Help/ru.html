Справочник Правила заполнения шаблонов MS Word

Назначение

Справочник "Правила заполнения шаблонов MS Word" предназначен для настройки соответствия параметров шаблонов MS Word определенным реквизитам объектов системы.

Форма объекта

При заполнении формы элемента справочника "Правила заполнения шаблонов MS Word" необходимо заполнить следующие обязательные реквизиты:

  • Наименование – наименование правила;
  • Параметр Word – наименование параметра в Word (в шаблоне Word такой параметр должен быть  помещен в фигурные скобки);
  • Режим – выбор между значениями "Произвольный" и "Значение реквизита". Если выбран произвольный режим, то заполняется поле "Действие". В нем прописывается запрос, который будет выполняться для заполнения параметра. Если в качестве режима выбрано "Значение реквизита", то из справочников / документов системы выбирается реквизит, на основе которого будет заполняться параметр шаблона.
