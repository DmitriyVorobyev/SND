Справочник Группа статей затрат

Назначение

Справочник "Группа статей затрат" предназначен для хранения в информационной базе информации о статьях затрат объединенных в различные группы.

Информация, хранимая в справочнике, используется при заполнении документов Расчет цены контракта.

Форма объекта

При создании элемента справочника "Группа статей затрат" необходимо заполнить следующие обязательные реквизиты:

  • Код – уникальный код элемента (формируется автоматически);
  • Наименование – наименование группы статей затрат.

    • Табличная часть заполняется элементами справочника Статьи затрат по проектам. Новые строки добавляются вручную с помощью кнопки Добавить.
