Справочник Правила формирования наименований договоров

Назначение

Справочник "Правила формирования наименований договоров" используется для хранения информации о правилах формирования наименований договоров. Правило представляет собой последовательность выбранных реквизитов договора и/или вручную введенного текста.

Форма объекта

При заполнении формы элемента справочника "Правила формирования наименований договоров" необходимо заполнить следующие обязательные реквизиты:

  • Код – формируется автоматически при записи элемента;
  • Наименование – наименование правила.

По кнопке Добавить указываются реквизиты, значения которых будут выводиться в наименование договора:

  • Номер
  • Дата
  • Контрагент
  • Предмет договора
  • Вид договора
  • Проект
  • Схема оплаты
  • Валюта

Также в наименование договора можно вывести произвольный текст, если выбрать тип данных "Строка".
