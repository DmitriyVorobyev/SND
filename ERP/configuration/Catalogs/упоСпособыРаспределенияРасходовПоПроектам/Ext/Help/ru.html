Справочник Способы распределения расходов по проектам

Назначение

Справочник "Способы распределения расходов по проектам" хранит настройки распределения косвенных расходов, которые используются в документе Распределение расходов по проектам и в обработке Помощник распределения расходов по проектам для создания документа Реклассификация расходов.

Важно! Справочник "Способы распределения расходов по проектам" используется в "1С:ERP+PM Управление проектной организацией 2" для указания базы распределения по направлениям деятельности и по подразделениям в правилах распределения для каждой статьи косвенных расходов на вкладке "Настройки отражения (PM)" (см. Статьи затрат по проектам).

Форма объекта

На форме элемента справочника "Способы распределения расходов по проектам" расположены следующие реквизиты:

  • Код — уникальный код элемента (формируется автоматически);
  • Наименование — наименование способа распределения расходов по проектам;
  • Способ распределения по направлениям деятельности — вариант распределения расходов: 
    • Способ распределения Описание "Распределение расходов по проектам" "Помощник распределения расходов"
    По прямым В качестве базы распределения используется сумма всех прямых расходов, отнесенных на направления деятельности, связанные с проектными задачами - +
    По указанным статьям В качестве базы распределения используется сумма расходов по указанным на закладке "Статьи расходов" статьям расходов, отнесенных на направления деятельности, связанные с проектными задачами в "1С:ERP+PM" или на проектные задачи в "1С:PM" + +
    По коэффициентам Расходы распределяются на указанные на закладке "Коэффициенты: проектные задачи" проектные задачи в указанных долях (коэффициентах) + +
    По плановому распределению объемов В качестве базы распределения используются суммы дохода по плановым объемам, указанные в проектных задачах, связанных с направлениями деятельности + +
    По фактическому распределению объемов В качестве базы распределения используются суммы дохода зарегистрированных фактических объемов по проектным задачам, связанных с направлениями деятельности + +
    По фактическим трудозатратам В качестве базы распределения используются данные о фактических трудозатратах, отраженные в проектной задаче в табелях (документы Табель учета рабочего времени, Распределение рабочего времени за неделю, Прогноз трудозатрат по ролям) и документе синхронизации данных Синхронизация фактических трудозатрат + +
    По согласованным часам В качестве базы распределения используются данные об утвержденных трудозатратах, отраженных документом Согласование часов и отнесенных на проектные задачи. Способ становится доступным только при подключенном модуле "Согласование часов" + -
    По статьям ФОТ (РМ) В качестве базы распределения используется сумма фактических расходов по статьям из регистра сведений Статьи ФОТ, указанным в Параметрах подсистемы PM (группа "Статьи расходов и ФОТ") + +

    Закладка "Статьи расходов"

    На данной закладке формируется список статей расходов, сумма расходов по которым используется в качестве базы распределения расходоd.

    Важно! Закладка "Статьи расходов" доступна при способе распределения по направлениям деятельности "По указанным статьям".

    Новые строки в табличную часть добавляются вручную с помощью кнопки Добавить. Колонки табличной части:

  • Статьи расходов — элемент справочника Статьи затрат по проектам ("Статьи расходов" в "1С:ERP+PM Управление проектной организацией 2").

    • Закладка "Коэффициенты: проектные задачи"

    На данной закладке формируется список направлений деятельности с указанием долей (коэффициентов), по которым распределяются косвенные расходы.

    Важно! Закладка "Коэффициенты: направления деятельности" доступна при способе распределения по направлениям деятельности "По коэффициентам".

    Важно! Сумма долей должна быть равна 100%.

    Новые строки в табличную часть добавляются вручную с помощью кнопки Добавить. Колонки табличной части:

  • Проект — элемент справочника "Проект", заполняется автоматически при выборе проектной задачи.;
  • Проектная задача — документ "Проектная задача".
  • Доля — доля расходов, распределяемая на проектную задачу.

    • Закладка "Подразделения"

    На данной закладке формируется список подразделений, на которые распределяются косвенные расходы.

    Важно! Закладка "Подразделения" доступна при способе распределения по направлениям деятельности "На указанные подразделения".

    Новые строки в табличную часть добавляются вручную с помощью кнопки Добавить. Колонки табличной части:

  • Подразделение — элемент справочника Подразделения.

    • Закладка "Коэффициенты: подразделения"

    На данной закладке формируется список подразделений с указанием долей (коэффициентов), на которые распределяются косвенные расходы.

    Важно! Закладка "Коэффициенты: подразделения" доступна при способе распределения по направлениям деятельности "По коэффициентам".

    Важно! Сумма долей должна быть равна 100%.
