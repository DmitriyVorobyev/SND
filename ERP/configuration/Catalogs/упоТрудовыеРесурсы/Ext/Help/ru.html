﻿Справочник Трудовые Ресурсы



Если в справке напротив поля или элемента интерфейса есть иконка, то элемент доступен только в приложении "1С:ERP+PM Управление проектной организацией 2" (1С:ERP+PM).

Назначение

Справочник "Трудовые ресурсы" предназначен для хранения сведений о трудовых ресурсах предприятия, привлекаемых к выполнению проектных работ.

Трудовой ресурс — это структурная единица, которая участвует в выполнении проектных работ. Это может быть, как отдельный сотрудник, так и совокупность людских ресурсов и аппаратных средств (группа сотрудников, подразделение или даже целая организация).

Справочник "Трудовые ресурсы" позволяет:

  • Создавать и хранить записи о трудовых ресурсах предприятия.

    • Форма объекта

    При заполнении формы элемента справочника "Трудовые ресурсы" необходимо заполнить следующие обязательные реквизиты:

  • Код справочника — формируется автоматически;
  • Наименование — наименование трудового ресурса;
  • Физическое лицо — привязка трудового ресурса к элементу справочника "Физические лица";
  • Владелец ресурса – сотрудник, назначенный владельцем трудового ресурса с помощью документа Регистрация владельца ресурсов, не доступен для редактирования;
  • Не отображать в списках (опция расположена в нижней части формы)– если опция включена (флаг установлен), то текущий элемент справочника не будет отображаться на формах выбора и форме списка справочника.

    • Закладка "Статьи Затрат"

    На закладке "Статьи Затрат" заполняются статьи распределения затрат стоимости привлечения к выполнению работ трудового ресурса и процент распределения затрат.

    Данные табличной части "Распределение стоимости по статьям затрат" используются при автоматическом расчете сумм затрат в проектном бюджетировании в обработке Отражение документов в проектном бюджетировании.

  • Статья затрат — статья, на которую распределяется стоимость привлечения трудового ресурса в бюджете проекта, элемент справочника Статьи затрат по проектам.
  • Доля суммы (%) — доля стоимости трудового ресурса в %, распределяемая на указанную статью затрат.

    • Важно! Отражение расходов по статьям затрат в проектном бюджетировании может быть ограничено Правилами получения фактических данных для проектного бюджетирования.

    Примечание. Доля суммы, как по отдельной статье, так и общая по всем статьям, указанным в табличной части, может быть как больше, так и меньше 100%.

    Закладка "Стоимость"

    На закладке "Стоимость" отражается стоимость привлечения ресурса для выполнения проектных работ за единицу времени. Стоимость трудового ресурса можно зарегистрировать с помощью документа Регистрация стоимости ресурса, либо Регистрация стоимости ресурсов.

    Закладка "Роли"

    На закладке "Роли" отображаются назначения и смещения трудового ресурса с ролей документом Назначение трудового ресурса на роль. Роль выделяется жирным шрифтом, если она является активной (т.е. трудовой ресурс не смещался с роли документом Смещение трудового ресурса с роли).

    Закладка "Подразделения"

    На закладке "Подразделения" отображается список подразделений (элементов справочника Подразделения), в которые входит данный трудовой ресурс.

    Связь трудового ресурса с подразделением устанавливается при помощи документов Регистрация состава подразделения и Назначение трудового ресурса на роль.

    Закладка "Компетенции"

    На закладке "Компетенции" заполняются компетенции трудового ресурса по видам операций.

  • Вид операции — вид операции для регистрации компетенций привлекаемого ресурса;
  • СС/СП — тип работ, выполняемых ресурсом (Собственные силы или Субподряд);
  • Стоимость дня — стоимость дня привлекаемого ресурса;
  • Выработка — % выработки трудового ресурса;
  • % на управление — % затрат на управление ресурсом:
  • Вероятность срыва % — вероятность срыва сроков по виду работ трудовым ресурсом;
  • Увеличение длительности % — вероятность увеличения сроков выполнения задач трудовым ресурсом по виду работ.

    • Данные, указанные во вкладке "Компетенции", выводятся в отчет Производительность трудовых ресурсов по видам операций.
