Справочник События календаря

Назначение

Справочник "События календаря" предназначен для хранения запланированных для трудовых ресурсов событий.

Форма объекта

Элементы справочника "События календаря" рекомендуется создавать из обработки Планировщик. Также новые события можно создавать на основе элементов справочника Трудовые ресурсы.

При заполнении формы элемента справочника необходимо заполнить следующие обязательные реквизиты:

  • С – дата и время начала события;
  • По – дата и время окончания события;
  • Описание – текстовое поле для ввода описания события.

    • При установке флага "Весь день" время начала события устанавливается на начало дня (00:00), а время окончания события – на конец дня (23:59).

    Созданные события отображаются в обработке Планировщик при выводе загрузки по соответствующим трудовым ресурсам.
