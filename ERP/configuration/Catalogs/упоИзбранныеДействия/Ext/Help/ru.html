Справочник Избранные действия

Назначение

Справочник "Избранные действия" предназначен для создания списка наиболее часто совершаемых действий (например, открытие определенной настройки отчета) с целью упрощения их выполнения.

Для работы со справочником в системе существуют следующие роли профилей групп доступа:

  • Использование избранных действий (включена во все стандартные профили групп доступа, кроме "Выбор проектной задачи из справочника проекты" и "Использование защищенного функционала"):
  • Дает пользователю доступ к элементам справочника, созданным этим пользователем, либо имеющим признак "Общее";
  • Дает пользователю возможность создавать элементы справочника с любым типом действия, кроме "Произвольный код";
  • Дает пользователю возможность изменять элементы справочника, для которых он является автором;
  • Дает пользователю возможность использовать элементы справочника с любым типом действия.
  • Настройка избранных действий (включена в стандартный профиль групп доступа "Администратор НСИ проектного офиса"):
  • Дает пользователю доступ ко всем элементам справочника;
  • Дает пользователю возможность создавать элементы справочника с любым типом действия;
  • Дает пользователю возможность изменять любые элементы справочника;
  • Дает пользователю возможность использовать элементы справочника с любым типом действия.

    • Важно! Справочник позволяет выполнять действия с произвольным кодом, а так же запускать внешние обработки (проконтролировать изменение / подмену которых 1С не может). Этим могут воспользоваться злоумышленники, поэтому нужно с осторожностью подходить к выдаче прав на изменение справочника, а также обращать внимание на создаваемые действия с типами "Внешняя обработка или отчет", "Запуск внешнего приложения" и "Произвольный код".

    Форма объекта

    Форма элемента

    При заполнении формы элемента справочника "Избранные действия" необходимо заполнить следующие обязательные реквизиты:

  • Наименование — наименование выполняемого действия;
  • Код элемента — формируется автоматически;
  • Родитель — группа справочника;
  • Общее:
  • если флаг установлен, элемент справочника будет доступен для использования всем пользователям;
  • если флаг не установлен, элемент справочника будет доступен только автору и пользователям с ролью "Настройка избранных действий" или полными правами;
  • Тип действия — тип выполняемого действия:
  • Открыть вариант отчета — открытие выбранного варианта отчета с возможностью отбора по указанному проекту;
  • Дополнительная обработка или отчет — открытие дополнительной обработки или отчета из справочника Дополнительные отчеты и обработки;
  • Открыть панель руководителя с настройкой — открытие обработки Панель руководителя с выбором настройки;
  • Открыть панель руководителя подразделения с настройкой — открытие обработки Панель руководителя подразделения с выбором настройки;
  • Открыть структуру проекта с настройкой — открытие обработки Структура проекта с выбором настройки;
  • Внешняя обработка или отчет — открытие указанного файла внешней обработки или отчета;
  • Запуск внешнего приложения — запуск указанного внешнего приложения /открытие указанного файла / открытие указанной http-ссылки;
  • Произвольный код — возможность создать собственное действие;
  • Навигационная ссылка — возможность перейти к произвольному объекту текущей базы данных по навигационной ссылке, либо к произвольному объекту другой базы данных по внешней навигационной ссылке (при этом запускается клиент этой базы);
  • Произвольная ссылка — возможность перейти к выбранному объекту базы данных (конкретному документу, элементу справочника и т.д.).

    • Набор прочих настроек зависит от выбранного типа действия.

    Открыть вариант отчета

    При выборе типа действия "Открыть вариант отчета" доступны следующие настройки:

  • Вариант отчета — выбор открываемого варианта отчета из списка всех вариантов отчетов (как предопределенных, так и сохраненных пользователями);
  • Отбор по проекту — выбор проекта, по которому будет установлен отбор в открываемом варианте отчета. Если отбор по проекту не установлен, при формировании отчета будет использоваться отбор, установленный в открываемом варианте отчета.

    • Важно! Поле "Вариант отчета" не рекомендуется оставлять пустым.

    Дополнительная обработка или отчет

    При выборе типа действия "Дополнительная обработка или отчет" доступны следующие настройки:

  • Дополнительная обработка — выбор для открытия дополнительной обработки или отчета из справочника Дополнительные отчеты и обработки.

    • Важно! Поле "Дополнительная обработка" не рекомендуется оставлять пустым.

    Открыть панель руководителя с настройкой

    При выборе типа действия "Открыть панель руководителя с настройкой" доступны следующие настройки:

  • Вариант настройки — выбор сохраненной настройки обработки Панель руководителя. По умолчанию для выбора доступны все сохраненные настройки. Для отбора настроек, сохраненных текущим пользователем, необходимо отжать кнопку Показывать настройки всех пользователей на форме выбора настроек. Если настройка не указана, обработка будет открыта без каких-либо настроек.

    • Открыть панель руководителя подразделения с настройкой

    При выборе типа действия "Открыть панель руководителя подразделения с настройкой" доступны следующие настройки:

  • Вариант настройки — выбор сохраненной настройки обработки Панель руководителя подразделения. По умолчанию для выбора доступны все сохраненные настройки. Для отбора настроек, сохраненных текущим пользователем, необходимо отжать кнопку Показывать настройки всех пользователей на форме выбора настроек. Если настройка не указана, обработка будет открыта без каких-либо настроек.

    • Открыть структуру проекта с настройкой

    При выборе типа действия "Открыть структуру проекта с настройкой" доступны следующие настройки:

  • Проект — выбор проекта, структуру которого планируется открывать. Если проект не указан, будет открываться структура проекта, выбранного в качестве текущего.
  • Вариант настройки — выбор сохраненной настройки обработки Структура проекта. По умолчанию для выбора доступны все сохраненные настройки. Для отбора настроек, сохраненных текущим пользователем, необходимо отжать кнопку Показывать настройки всех пользователей на форме выбора настроек. Если настройка не указана, обработка будет открыта с настройкой по умолчанию.

    • Внешняя обработка или отчет

    При выборе типа действия "Внешняя обработка или отчет" доступны следующие настройки:

  • Внешняя обработка — указывается путь к файлу внешней обработки или отчета (.epf/.erf).

    • Важно! Данное поле не рекомендуется оставлять пустым.

    Важно! Для работы данного механизма при клиент-серверном варианте работы необходимо, чтобы сервер 1С имел доступ к файлу по указанному пути на указанном ресурсе. Таким образом, надо указать либо файл, который доступен на сервере 1С локально, либо файл на сетевом ресурсе, к которому имеет доступ пользователь, под которым запущен сервер 1С. Также позволяется указывать файлы, расположенные на компьютере локально. В случае файловой базы сервер эмулируется в том же клиенте, который запускает пользователь.

    Запуск внешнего приложения

    При выборе типа действия "Запуск внешнего приложения" доступны следующие настройки:

  • Внешнее приложение, файл или http-ссылка — указывается исполняемый файл внешнего приложения / файл / http-ссылка.

    • Важно! В целях безопасности, данное поле не рекомендуется оставлять пустым, так как в этом случае при попытке выполнить действие пользователю будет предложено самому выбрать открываемый/запускаемый объект (файл или приложение).

    Важно! Данный тип действий не позволяет запускать внешние отчеты и обработки. Для этих целей предназначен тип действий "Внешняя обработка".

    Произвольный код

    При выборе типа действия "Произвольный код" доступны следующие настройки:

  • Объект.ЗначениеПеременной1, Объект.ЗначениеПеременной2 — реквизиты составного типа (любая ссылка, строка, дата, число, булево), используемые для параметризации кода в справочнике;
  • Выполняемый код клиент — поле для ввода кода, выполняемого на клиенте (выполняется в событии ПриОткрытии);
  • Выполняемый код сервер — поле для ввода кода, выполняемого на сервере (выполняется в событии ПриСозданииНаСервере);
  • Кнопка Проверить код — выполняет проверку написанного кода.

    • Навигационная ссылка

    При выборе типа действия "Навигационная ссылка" доступны следующие настройки:

  • Навигационная ссылка — навигационная ссылка / внешняя навигационная ссылка к другой базе данных (при этом запускается клиент этой базы).

    • Произвольная ссылка

    При выборе типа действия "Произвольная ссылка" доступны следующие настройки:

  • Произвольная ссылка — выбор произвольного объекта базы данных.

    • Форма списка

    На командной панели формы списка расположены следующие кнопки:

  • Кнопка Создать — создает новый элемент справочника;
  • Кнопка Создать группу — создает новую группу;
  • Кнопка Создать новый элемент копированием текущего — создает новый элемент справочника путем копирования выбранного элемента справочника;

    • Важно! Из-за ограничения для роли "Использование избранных действий" на создание элементов справочника с типом действия "Произвольный код", при создании нового избранного действия копированием элемента с таким типом действия, в создаваемом элементе тип действия будет автоматически изменен на "Открыть вариант отчета".

  • Кнопка Изменить — открывает элемент справочника для редактирования;
  • Кнопка Добавить в избранное — добавляет элемент справочника в Избранное для быстрого доступа к нему;
  • Кнопка Обновить избранное — для отображения в Избранном добавленных элементов справочника, нужно обновить список при помощи данной кнопки.

    • Важно! Двойной щелчок по элементу справочника не открывает его, а запускает выполнение выбранного действия. Для открытия элемента используется кнопка Изменить.
