Справочник Виды причин отклонений

Назначение

Справочник "Виды причин отклонений" предназначен для хранения списка видов причин отклонений.

Важно! Справочник "Виды причин отклонений" является служебным справочником.

Форма объекта

При заполнении формы элемента справочника "Виды причин отклонений" необходимо заполнить следующие обязательные реквизиты:

  • Код – формируется автоматически при записи элемента;
  • Родитель — группа видов причин отклонений, в которую включается данный элемент;
  • Наименование — наименование вида причины отклонения;
  • Описание — текстовое поле для описания особенностей данной причины отклонения.
