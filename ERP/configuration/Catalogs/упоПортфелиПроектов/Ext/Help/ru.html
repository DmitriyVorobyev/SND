Справочник Портфели проектов

Назначение

Справочник "Портфели проектов" предназначен для хранения списка портфелей проектов, используемых на предприятии.

Проект — это временное предприятие, предназначенное для создания уникальных продуктов, услуг или результатов.
Портфель проектов — набор проектов, объединённых по неким критериям.

Справочник "Портфели проектов" позволяет:

  • Фиксировать и хранить в системе информацию о списках портфелей проектов.

    • Важно! Один и тот же проект может входить в состав только одного портфеля проектов.

    Форма объекта

    Вкладка "Основное"

  • Код — формируется автоматически;
  • Наименование — наименование портфеля проектов;
  • Полное наименование — полное наименование портфеля проектов;
  • Проект структуры — элемент справочника Проекты (компонент "Портфель проекта"), формируется автоматически (при записи). При необходимости, основным проектом портфеля можно назначить другой проект;
  • Кнопка Открыть структуру проекта — при нажатии открывается обработка Структура проекта со структурой основного проекта портфеля.
  • Родитель — группа портфеля проектов;
  • Картинка по умолчанию — картинка портфеля проектов для обработки Панель руководителя. Выбрать картинку можно при помощи кнопки Выбрать картинку.
  • Комментарий – текстовое поле.

    • В системе существует следующая связь: портфель проектов → основной проект портфеля → проектные задачи портфеля проектов → подчиненный проект → проектные задачи проекта.

    Проанализировать введенную информацию о портфеле проектов и подчиненных проектах (структура, БДР, БДДС, трудозатраты, объемы) можно с помощью отчета План-фактный анализ по портфелю.

    Вкладка "Опции проектной модели"

    Опции проектной модели, указанные в элементе справочника "Портфели проектов", будут являться значениями по умолчанию при создании проекта входящего в портфель проектов. При этом возможно изменение опций проектной модели для каждого конкретного проекта.

    Доходы

    Для бюджета доходов доступны следующие опции:

  • Ведется бюджет доходов - данная опция определяет, будет ли вестись бюджет доходов по проекту. При указании опции становится доступна табличная часть "План доходов" в документе Проектная задача.
  • Доходы по подразделениям - данная опция определяет, будет ли вестись бюджет доходов по проекту в разрезе подразделений. При указании опции становится доступны табличные части "Распределение доходов" в документах Проектная задача и Регистрация фактических доходов и расходов.
  • Доходы по объемам - при включении данной опции будет возможно планировать выполнение объемов при планировании доходов. При указании опции, в табличной части "Распределение доходов" в документах Проектная задача, становятся доступны параметры "Способ привязки" и "Профиль распределения".
  • Доходы по натуральным показателям - при включении данной опции будет возможно планировать выполнение объемов и планировать доходы в количественном выражении, в разрезе номенклатуры. При указании опции становится доступна табличная часть "Объемы" в документе Проектная задача.

    • Расходы

    Для бюджета расходов доступны следующие опции:

  • Ведется бюджет расходов - данная опция определяет, будет ли вестись бюджет расходов по проекту. При указании опции становится доступна табличная часть "План расходов" в документе Проектная задача.
  • Расходы по подразделениям - данная опция определяет, будет ли вестись бюджет расходов по проекту в разрезе подразделений. При указании опции становится доступны табличные части "Распределение расходов" в документах Проектная задача и Регистрация фактических доходов и расходов.
  • Расходы по объемам - при включении данной опции будет возможно планировать выполнение расходных объемов при планировании расходов. При указании опции, в табличной части "Распределение расходов" в документах Проектная задача, становятся доступны параметры "Способ привязки" и "Профиль распределения".
  • Расходы по натуральным показателям - при включении данной опции будет возможно планировать выполнение расходных объемов и планировать расходы в количественном выражении, в разрезе номенклатуры. При указании опции становится доступна табличная часть "Распределение потребностей" в табличной части "Потребности" в документе Проектная задача.

    • Важно! При включении опции "Расходы по натуральным показателям" также включается и блокируется для изменения опция "Планировать затраты на материалы и оборудование". При отключенной опции "Расходы по натуральным показателям" опция "Планировать затраты на материалы и оборудование" изменяется без ограничений.

  • Настройка распределения БДР – настройка распределения БДР по подразделениям с учетом трудозатрат (элемент справочника Настройки распределения БДР), применяемая по умолчанию в проектах портфеля для обработки Распределение БДР при распределении доходов и расходов проектных задач проекта.

    • Учет движения денежных средств

    Для бюджета движения денежных средств доступны следующие опции:

  • Ведется бюджет движения денежных средств – данная опция определяет, будет ли вестись бюджет движения денежных средств по проекту. При указании опции становится доступна табличная часть "План движения денежных средств" в документе Проектная задача.

    • Планирование ресурсов

  • Планировать трудозатраты по проекту - при включении данной опции становятся доступны табличные части "Роли трудовых ресурсов" и "Исполнители" в документе Проектная задача.
  • Обязательно указывать подразделения - если опция включена, при планировании трудозатрат становится обязательным заполнение подразделений для указанных ролей трудовых ресурсов. Опция доступна при включении опции "Планировать трудозатраты по проекту".

    • Важно! Опция "Обязательно указывать подразделения" обязательна для включения при планировании и актуализации работ по проектам руководителем структурного подразделения (например, при помощи обработки Панель руководителя подразделения и документов Прогноз трудозатрат по ролям и Планирование трудозатрат по трудовым ресурсам).

  • Учитывать период регистрации норм стоимости при расчете трудозатрат Ролей и ТР:
  • Если опция включена, стоимости трудозатрат ролей / трудовых ресурсов по проектной задаче будут рассчитываться по нормам, указанным в документах Регистрация стоимости ресурса / Регистрация стоимости ресурсов с учетом дат этих документов и распределения загрузки ролей / трудовых ресурсов по проектной задаче. В проектных задачах на закладке "Ресурсы" → "Роли трудовых ресурсов" будет заблокирована кнопка Пересчитать по норме и вместо колонок "Стоимость", "Общая стоимость", "Внешняя стоимость" и "Общая Внешняя стоимость" табличной части будут отображены колонки "Стоимость (ср.)", "Общая стоимость", "Внешняя стоимость (ср.)" и "Общая Внешняя стоимость", недоступные для редактирования (значение рассчитывается автоматически).
  • Если опция выключена, стоимости трудозатрат ролей / трудовых ресурсов по проектной задаче будут рассчитываться по последним данным документов Регистрация стоимости ресурса / Регистрация стоимости ресурсов.
  • Планировать затраты на материалы и оборудование - при включении данной опции становится доступна табличная часть "Материалы и оборудование" в документе Проектная задача.
  • Планировать дополнительные затраты по проектной задаче - при указании опции становится доступна табличная часть "Доп. затраты" в документе Проектная задача.
  • Норма стоимости ролей – элемент справочника Нормы стоимости, используется для автоматического расчета стоимости привлечения трудовых ресурсов, перечисленных в табличной части "Роли трудовых ресурсов" в документе Проектная задача.
  • Внешняя норма стоимости ролей – элемент справочника Нормы стоимости, используется для автоматического расчета внешней стоимости привлечения трудовых ресурсов, перечисленных в табличной части "Роли трудовых ресурсов" в документе Проектная задача.

    • Прочие опции

  • Хранить в версиях проценты готовности, статусы и фактические сроки проектных задач – если опция включена, при создании новой версии проекта, в ней дополнительно будут сохраняться данные о процентах готовности, статусах и фактических сроках проектных задач. У таких версий будет установлен признак "Версия включает данные выполнения" (для Текущей версии установлен всегда, независимо от значения опции). Особенности хранения данных выполнения при работе с версиями проекта (копировании, обновлении, загрузке) описаны в обработке Управление версиями проекта.
  • Использовать аналитику "Контрагент" / "Трудовой ресурс" для собственных сил – опция позволяет указывать Контрагента или Трудовой ресурс для собственных сил в реквизите "Исполнитель" в расшифровках табличных частей документа Проектная задача.
  • Разрешить создание обсуждений без указания проектной задачи – опция позволяет создавать задания типа "Обсуждение" без привязки к конкретной проектной задаче.
  • Разрешить списание часов на проектные задачи проекта в статусе "Остановлен" - опция позволяет Руководителю проекта списывать рабочее время, затраченное трудовыми ресурсами, для которых Руководитель проекта является владельцем, в документах Распределение рабочего времени за неделю, Табель учета рабочего времени и Прогноз трудозатрат по ролям на проектные задачи проекта, статус которого "Остановлен", вне зависимости от даты остановки проекта.

    • Важно!

  • Пользователи, кроме описанных выше, могут списать фактические трудозатраты по проекту в статусе "Остановлен" строго до даты остановки проекта (дата документа Остановка проектных работ), дата остановки в период списания не входит;
  • Опция оказывает влияние как на заполнение документов Распределение рабочего времени за неделю, Табель учета рабочего времени и Прогноз трудозатрат по ролям, так и на возможность проведения этих документов в системе.
  • Разрешить списание часов на проектные задачи проекта в статусах "Запланирован" и "Утвержден" – опция позволяет списывать рабочее время в документах Распределение рабочего времени за неделю, Табель учета рабочего времени и Прогноз трудозатрат по ролям на проектные задачи проекта, статус которого "Запланирован" или "Утвержден".
  • В расчетах с показателями Go-Get-Freeze-Move использовать значения показателей, указанные в проектной задаче:
  • если опция включена, то в отчетах, где данные рассчитываются с учетом показателей Go–Get–Freeze–Move, значения данных показателей будут браться из проектной задачи. Если для проектной задачи значения Go–Get–Freeze–Move не заполнены, то в этом случае значения для расчета в отчетах будут браться из проекта.
  • если опция выключена, то в отчетах, где данные рассчитываются с учетом показателей Go–Get–Freeze–Move, значения для расчета в отчетах будут браться из проекта.
  • Наследовать значение поля "Объект" из задачи-родителя - если опция включена, у новых проектных задач и проектных задач, у которых изменяется уровень иерархии в структуре, значение реквизита "Объект" будет наследоваться от задачи-родителя. Наследование происходит по следующим принципам:
  • У новых проектных задач реквизит "Объект" будет заполняться тем же значением, что и у задачи-родителя;
  • Если у проектной задачи изменяется задача-родитель (через обработку Структура проекта или непосредственно в карточке проектной задачи) и реквизит "Объект" заполнен значением, отличным от значения этого реквизита у нового родителя, задается вопрос о замене значения реквизита в задаче;
  • Если у проектной задачи изменяется задача-родитель (через обработку Структура проекта или непосредственно в карточке проектной задачи) и реквизит "Объект" не заполнен, значение автоматически наследуется от нового родителя;
  • Если у задачи-родителя изменяется значение реквизита "Объект" и у подчиненных задач реквизит "Объект" заполнен значением, отличным от нового значения этого реквизита у задачи-родителя, задается вопрос о замене значения этого реквизита у всех подчиненных задач;
  • Если у задачи-родителя изменяется значение реквизита "Объект" и у подчиненных задач реквизит "Объект" не заполнен, значение автоматически наследуется от задачи-родителя;
  • При копировании задачи, значение реквизита "Объект" также копируется в новую задачу;
  • При очищении у задачи реквизита "Родитель", задается вопрос об очищении реквизита "Объект";
  • Запретить руководителю проектной задачи изменять сроки задач других руководителей – опция запрещает сохранение изменений в структуре проекта сотрудником, который является Руководителем проектных задач, но не является Руководителем проекта, если эти изменения влияют на сроки задач других сотрудников.
  • Рассчитывать процент готовности при регистрации фактически выполненных объемов – опция позволяет рассчитывать проценты готовности проектных задач по план-фактным данным номенклатуры с признаком "Основной результат" из табличной части "Субпродукты" документа Проектная задача при проведении документов Регистрация фактически выполненного объема (в новых документах будет по умолчанию будет включена опция "Записывать процент готовности по доходным объемам", с возможностью отключить вручную).
  • Настройка показателей для паспорта проекта – позволяет вывести в карточку проекта на закладку "Показатели" набор показателей, выбираемый из списка сохраненных настроек обработки Панель руководителя.
  • Настройка дерева ключевых показателей – настройка дерева ключевых показателей, элемент справочника Настройки дерева ключевых показателей, в соответствии с которой будет отображаться Дерево ключевых показателей проекта.
  • Настройка уровня планирования при расчете готовности проектов – уровень планирования трудозатрат для расчета процента готовности проектных задач при актуализации проекта документом Ручная актуализация проекта. Реквизит доступен только при включенной опции "Учитывать плановые трудозатраты при расчете процента готовности" в Параметрах подсистемы PM в группе "Основные параметры".

    • Автоматическое назначение руководителей проектной задачи

  • Автоматически назначать руководителя подразделения основной роли руководителем проектной задачи – опция позволяет при назначении ролей трудовых ресурсов на проектные задачи через документ Проектная задача и/или обработку Структура проекта автоматически назначать руководителем проектной задачи сотрудника, зарегистрированного в качестве руководителя подразделения, которому принадлежит роль, указанная в текущей проектной задаче как "Основная роль". Если опция включена и в проектной задаче указана основная роль, то блокируется возможность изменять руководителя проектной задачи вручную при помощи документа Изменение руководителя проектной задачи.
  • Автоматическая установка признака "Основная" при добавлении роли – опция позволяет при назначении ролей трудовых ресурсов на проектные задачи через документ Проектная задача и/или обработку Структура проекта автоматически устанавливать признак "Основная роль" для первой назначенной роли. Опция становится доступной только при включенной опции "Автоматически назначать руководителя подразделения основной роли руководителем проектной задачи".
