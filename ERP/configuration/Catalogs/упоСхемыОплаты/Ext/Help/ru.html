Справочник Схемы оплаты

Назначение

Справочник "Схемы оплаты" используется для хранения информации о схемах оплаты (вариантах распределения платежей) по договорам.

Форма объекта

При создании элемента справочника "Схемы оплаты" необходимо заполнить следующие реквизиты:

  • Код – формируется автоматически при записи элемента;
  • Наименование – наименование схемы оплаты;
  • Календарь – выбирается из справочника Рабочие календари;
  • Комментарий – произвольный текст.

    • Настройка схемы

    В табличной части по кнопке Добавить добавляются строки для распределения общей суммы платежа по видам платежа:

  • Вид платежа – выбирается вид платежа:
  • Аванс;
  • Оплата;
  • Расчет;
  • Удержание.
  • Доля, % – задается доля в процентах от общей суммы, приходящаяся на данный вид платежа;
  • Вид привязки – выбирается вид привязки платежа к срокам этапа /проекта:
  • К началу проектной задачи;
  • К завершению проектной задачи;
  • К началу проекта;
  • К завершению проекта;
  • К конкретной дате;
  • По профилю распределения.
  • Профиль/Дата привязки – доступно для редактирования только при выборе вида привязки К конкретной дате или По профилю распределения:
  • К конкретной дате – заполняется дата привязки платежа;
  • По профилю распределения – выбирается значение из справочника Профили распределения доходов и расходов.
  • Задержка – задается задержка платежа, в днях. Задержка может быть установлена для следующих видов привязки: 
  • К началу проектной задачи; 
  • К завершению проектной задачи; 
  • К началу проекта; 
  • К завершению проекта.
  • Статья – выбирается статья из справочника Статьи движения денежных средств.

    • Важно! При выборе вида привязки "По профилю распределения" или "К конкретной дате" задержку установить нельзя.
