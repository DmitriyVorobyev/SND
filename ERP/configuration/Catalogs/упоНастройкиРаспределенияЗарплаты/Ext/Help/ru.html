Объект доступен только в приложении "1С:ERP+PM Управление проектной организацией 2" (1С:ERP+PM).


Справочник Настройки распределения зарплаты

Назначение

Справочник "Настройки распределения зарплаты" предназначен для хранения настроек распределения расходов по заработной плате и взносам по направлениям деятельности в документе Отражение зарплаты в финансовом учете.

Важно! Перед началом использования подсистемы необходимо установить связь проектов с направлениями деятельности для сопоставления данных в контурах ERP и PM. В Параметрах подсистемы PM в разделе "Связь проектов с направлениями деятельности" рекомендуется использовать параметр "Создавать связь с направлениями деятельности только для актируемых задач". В проектах, по которым планируется выполнять распределение заработной платы и взносов, необходимо установить опцию "Обязательно указывать подразделение" на закладке "Опции проектной модели".

Форма объекта

На форме "Настройки распределения зарплаты" представлены следующие опции и реквизиты:

  • Использовать подсистему "Распределение зарплаты по проектам" – опция включает возможность использования подсистемы "Распределение зарплаты". Если опция включена, в документе Отражение зарплаты в финансовом учете на закладке "Начисления и взносы" становятся доступными команда "Распределять по трудозатратам PM" и настройки соответствия начислений PM на форме "Сотрудники организации", открываемой при вызове команды "Показать сотрудников".
  • Учитывать трудозатраты по неактируемым проектным задачам – опция позволяет при распределении заработной платы учитывать фактические трудозатраты по неактируемым проектным задачам на актируемом этапе проекта, которому подчинена проектная задача. Таким образом, если опция включена, при распределении заработной платы фактически отработанные часы на проектах будут списываться на проектные задачи (без признака актируемая), а заработная плата будет распределяться на этап проекта (с признаком актируемая), которому подчинена проектная задача или на вышестоящий этап проекта (с признаком актируемая).
  • Использовать согласованные часы – если опция включена, то в качестве базы распределения заработной платы будут использоваться фактически отработанные часы, утвержденные документом Согласование трудозатрат. Данная опция становится доступна, если в Параметрах подсистемы PM в разделе "Согласование трудозатрат" установлен флажок "Использовать подсистему "Согласование трудозатрат"".
  • Используется внешняя система учета – данная опция устанавливается, если начисление заработной платы производится во внешней системе.
  • Статья для отнесения ЗП по проектам – значение константы автоматически подставляется по умолчанию при создании нового элемента справочника Проекты в реквизит "Статья для отнесения ЗП по проектам" на закладке "Значения по умолчанию".
  • Группа для хранения неиспользуемых направлений деятельности – при переводе проекта в статус "Завершен" все направления деятельности, связанные с проектными задачами этого проекта, переносятся в группу, указанную в данной константе.
  • Страховые взносы – значение константы автоматически подставляется по умолчанию при создании нового элемента справочника Проекты на закладке "Значения по умолчанию". Для отражения страховых взносов по отдельной статье расходов устанавливается опция "по единой статье для всех фондов" и заполняется реквизит "Взносы". При необходимости в справочнике Проекты данные могут быть скорректированы.
  • Создать способы отражения актируемых задач – данная обработка предназначена для создания способов отражения зарплаты для уже созданных проектных задач с признаком "Проектная задача является актируемой". Для одной проектной задачи создается один способ отражения зарплаты.

    • Важно! Обработку рекомендуется запустить один раз, если на момент установки расширения в контуре PM уже были данные по проектам.

  • Соответствие видов начислений – таблица используется для группировки однотипных видов начислений, используемых на предприятии, по способу расчета: повременная оплата, командировки, отпуск, больничный и т.д. Вид начисления из колонки "Начисление PM" будет указан в элементах справочника Виды операций для последующего сопоставления видов трудозатрат с видами начислений.

    • Примечание. При включенной опции "Используется внешняя система учета" сопоставление сохраняется системой в регистре сведений Соответствие видов начислений ЗУП и PM, при выключенной опции – в регистре сведений Соответствие видов начислений ERP и PM.

  • Служебные типы проектов – в регистре сведений Служебные типы проектов указывается тип проекта, который используется для планирования и/или отражения трудозатрат по внепроектным задачам и потерям рабочего времени.

    • Распределение заработной платы по проектам выполняется аналогично при использовании любого из вариантов заполнения документа Отражение зарплаты в финансовом учете – по данным подсистемы расчета зарплаты контура ERP, по данным, полученным через синхронизацию с конфигурацией "1С:Зарплата и Управление Персоналом" или по данным из табличного документа формата *.xlsx.

    Для распределения заработной платы по проектам необходимо в форме "Начисления и взносы" документа Отражение зарплаты в финансовом учете нажать на кнопку "Заполнить" и выбрать команду "Распределить по трудозатратам PM". Заработная плата и взносы будут распределены по проектам пропорционально фактически отработанному за расчетный период времени, а подразделение затрат заполнится согласно фактически затраченному времени на проектах.
