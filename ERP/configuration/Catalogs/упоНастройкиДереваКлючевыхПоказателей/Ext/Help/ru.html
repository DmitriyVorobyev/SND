Справочник Настройка дерева ключевых показателей

Назначение

Справочник "Настройка дерева ключевых показателей" предназначен для хранения настроек дерева показателей проекта.

Форма объекта

При создании элемента справочника "Настройка дерева ключевых показателей" необходимо заполнить следующие обязательные реквизиты:

  • Код — уникальный код элемента (формируется автоматически).
  • Наименование — наименование показателя.
  • Описание настройки — произвольное описание настройки показателя.

    • Настройка дерева показателей производится в обработке Дерево ключевых показателей проекта. Обработка Дерево ключевых показателей проекта запускается по кнопке Редактировать после записи элемента справочника.
