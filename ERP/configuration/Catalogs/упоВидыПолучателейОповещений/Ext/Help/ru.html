Справочник Виды получателей оповещений

Назначение

Справочник "Виды получателей оповещений"﻿ предназначен для хранения информации о видах получателей оповещений. Получателями оповещений могут являться как пользователи системы, так и лица, не являющиеся пользователями, но которых также необходимо уведомлять об определенных событиях в системе.

Возможные виды получателей оповещений:

  • пользователи системы – данные для отправки оповещений берутся из справочника Пользователи;
  • внешние пользователи – данные для отправки оповещений берутся из справочника Внешние пользователи;
  • контрагенты – данные для отправки оповещений берутся из справочника Контрагенты;
  • сотрудники – данные для отправки оповещений берутся из справочника Сотрудники;
  • трудовые ресурсы – для отправки оповещений берутся из справочника Трудовые ресурсы и др.

Форма объекта

Форма элемента справочника "Виды получателей оповещений" содержит следующие реквизиты:

  • Наименование – наименование вида получателя оповещений;
  • Код – формируется автоматически;
  • Таблица получателя – конкретный справочник системы, в котором хранится контактная информация для отправки сообщения (адрес электронной почты, мобильный телефон).

В табличной части указывается:

  • Транспорт – выбирается из справочника Транспорт оповещений (электронная почта или SMS-рассылка).
  • Вариант хранения поля адреса - указывает, где хранится реквизит с контактной информацией получателя (в реквизите получателя, в контактной информации получателя, в контактной информации контактного лица получателя).
  • Поле адреса – указывается конкретный реквизит элемента справочника, из которого система берет контактную информацию получателя.
  • Описание хранения адреса – текстовое описание.
