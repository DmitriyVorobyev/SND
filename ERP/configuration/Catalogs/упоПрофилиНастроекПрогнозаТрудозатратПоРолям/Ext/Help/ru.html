Справочник Профили настроек документа "Прогноз трудозатрат по ролям"

Назначение

Справочник "Профили настроек документа "Прогноз трудозатрат по ролям"" предназначен для хранения списка профилей настроек документа Прогноз трудозатрат по ролям в разрезе пользователей системы.

Форма объекта

При заполнении формы элемента справочника "Профили настроек документа "Прогноз трудозатрат по ролям"" необходимо заполнить следующие реквизиты:

  • Код – формируется автоматически;
  • Наименование – наименование профиля настроек, обязателен для заполнения;
  • Персональная настройка – опция:
  • делает профиль настроек скрытым для всех пользователей, кроме автора, если у этих пользователей на форме списка справочника не установлен флаг "Показывать чужие персональные настройки";
  • включает запрет на редактирование профиля настроек для всех пользователей, кроме автора.

    • Важно! Профиль настроек не доступен для редактирования, если по профилю уже созданы документы Прогноз трудозатрат по ролям.

    Настройки профиля

    В разделе "Настройки профиля" расположены поля и опции для настройки формирования данных в табличной части документа:

  • Уровень планирования ролей – позволяет сделать отбор по уровню планирования ролей:
  • Предварительный;
  • Окончательный.
  • Актуализировать план предварительного уровня по окончательному – опция доступна только при выборе уровня планирования "Окончательный". Если опция включена, при проведении документа, плановые трудозатраты роли трудового ресурса по предварительному уровню планирования будут актуализированы по плановым трудозатратам роли трудового ресурса по окончательному уровню планирования;
  • Актуализировать план до периода по фактическим данным – если опция включена, при проведении документа, плановые трудозатраты роли трудового ресурса до периода планирования (периода документа) будут актуализированы по фактическим данным, указанным в табличной части документа в колонке "Факт до отч.периода";
  • Записывать факт отчетного периода – если опция включена, становится доступной возможность ручного ввода фактических трудозатрат роли трудового ресурса за отчетный период в табличную часть вкладки "Прогноз", а также запись внесенных данных при проведении документа;
  • Записывать процент готовности – если опция включена, становится доступной возможность расчета и ручного ввода процента готовности проектных задач в табличной части вкладки "Прогноз", а также запись внесенных данных при проведении документа;
  • Автоматический расчет процента готовности – если опция включена, процент готовности проектных задач будет рассчитываться автоматически на основании актуального плана и факта трудозатрат. Опция доступна только при включении опции "Записывать процент готовности";
  • Не уменьшать записанный процент готовности – если опция включена, при автоматическом расчете процента готовности полученное значение будет записано только в том случае, если оно больше ранее введенного. Опция доступна только при включении опции "Автоматический расчет процента готовности";
  • Комментарий – текстовое поле.

    • Дополнительно

    Для отображения списка всех профилей настроек, в том числе с признаком "Персональная настройка", сохраненных другими пользователями, требуется установить флаг "Показывать чужие персональные настройки" на форме списка справочника.
