Справочник Единицы измерения времени

Назначение

Справочник "Единицы измерения времени"﻿ предназначен для хранения информации об используемых на предприятии единицах времени (единицах измерения временных затрат ресурсов).

Справочник "Единицы измерения времени" позволяет:

  • Создавать и хранить информацию о единицах измерения времени, используемых на предприятии;
  • Производить нормирование трудовых ресурсов и оборудования по времени их использования.

    • Важно! В системе базовой единицей измерения времени является час. Остальные единицы задаются при помощи коэффициентов относительно базовой единицы. Например, коэффициент предопределенной единицы измерения времени "Рабочий день (стандарт)" по умолчанию равен 8. Это означает, что на предприятии стандартный рабочий день равен восьми часам.

    Форма объекта

    При заполнении формы элемента справочника "Единицы измерения времени" необходимо заполнить следующие обязательные реквизиты:

  • Код элемента — формируется автоматически;
  • Наименование — наименование единицы измерения времени (например: "Час", "Сутки", "Рабочая неделя" и т.д.);
  • Коэффициент — коэффициент пересчета единицы измерения времени относительно часа.

    • Важно! Коэффициент предопределенного элемента справочника "Час" по умолчанию равен единице. Изменять этот коэффициент не рекомендуется.
