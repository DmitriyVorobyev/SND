Справочник Виды заданий

Назначение

Справочник "Виды заданий" предназначен для хранения видов заданий, таких как "Поручение" и "Проектное решение".

Важно! Справочник "Виды заданий" является служебным и не предназначен для редактирования.

Предопределенные виды заданий:

  • Поручение — этот вид задания используется для сообщения исполнителю о необходимости выполнить какие-либо действия.
  • Согласование — этот вид задания используется для согласования с ответственными лицами данных проекта (календарно-ресурсный план, бюджеты и т.д.), а также решения других вопросов, требующих согласования.
  • Обсуждение — этот вид задания используется для обмена мнениями по какому-либо вопросу.
  • Проектное решение — описание в текстовой форме объекта проектирования или его части, необходимое для создания (материализации) объекта проектирования и удовлетворяющее заданным требованиям.

    • Форма объекта

    На форме элемента справочника "Виды заданий" расположены следующие реквизиты:

  • Код элемента — код элемента справочника;
  • Наименование — наименование вида задания.
