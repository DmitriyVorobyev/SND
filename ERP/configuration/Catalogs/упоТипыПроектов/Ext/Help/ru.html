Справочник Типы проектов

Назначение

Справочник "Типы проектов" позволяет создавать и хранить в системе информацию о типах проектов.

Форма объекта

При заполнении формы элемента справочника "Типы проектов" необходимо заполнить следующие обязательные реквизиты:

  • Код — формируется автоматически;
  • Наименование — наименование типа проекта.

    • В табличную часть элемента справочника можно подобрать список показателей проектов, элементов справочника Показатели проектов, характерных для данного типа проектов. Для заполнения табличной части используется кнопка Добавить. Выбранные показатели будут всегда выводиться для всех проектов данного типа в паспорт проекта на закладку "Показатели" (табличная часть "Показатели со значениями, регистрируемыми вручную" (показатели, привязанные к типу проекта, будут выделены жирным шрифтом)).
