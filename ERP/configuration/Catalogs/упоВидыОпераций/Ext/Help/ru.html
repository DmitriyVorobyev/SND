Справочник Виды операций

Назначение

Справочник "Виды операций" предназначен для получения информации о трудозатратах на проект, доходах и расходах, а также для интеграции с другими учетными управленческими системами.

Является классификатором видов операций таких как "ПИР", "НИР", "СМР" и др.

Форма объекта

При заполнении формы элемента справочника "Виды операций" необходимо заполнить следующие обязательные реквизиты:

  • Код – формируется автоматически при записи элемента;
  • Наименование — наименование вида операции;
  • Полное наименование — полное наименование вида операции;
  • Родитель – группа видов операций, в которую включается данный элемент;
  • Раздел учета рабочего времени – значение выбирается из перечисления:
    • Внепроектная задача;
    • Потеря рабочего времени;
    • Проектная задача.

Важно! Заполнение реквизита "Раздел учета рабочего времени" влияет на автозаполнение вида операции в документах Табель учета рабочего времени и Распределение рабочего времени за неделю.

Выбор раздела позволяет фильтровать элементы справочников Внепроектные задачи, Причины потерь рабочего времени и документы Проектная задача по видам операций в следующих документах:

    • Табель учета рабочего времени – в правой части документа возможные варианты расходования рабочего времени разделены по данным разделам;
    • Распределение рабочего времени на неделю – рабочее время распределяется по вкладкам, соответствующим  данным разделам.
  • Комментарий – произвольный текст;
  • Флаг "Управленческий" – если флаг установлен, то поручения с данным видом операции будут отображаться в иерархии списка "Поручения текущего проекта" как "Управленческие". Если флаг снят, то получения с данным видом операции будут отображаться в иерархии списка "Поручения текущего проекта" как "Технические".
  • Флаг "Ворота качества" – флаг необходимо установить для вида операции, который будет использоваться в проектной задаче типа "Веха". При этом данная веха будет являться контрольной точкой проекта и использоваться в контуре "Фазы проекта" в качестве ворот качества.
  • Цвет – можно указать цвет ворот качества, который отображается в структуре проекта в диаграмме Ганта при выполнении следующих условий:
    • у проектной задачи выбран тип "Веха";
    • в  проектной задаче указан вид операции;
    • для данного вида операции установлен флаг "Ворота качества";
    • в структуре проекта необходимо нажать кнопку Ворота качества (контрольные точки).
