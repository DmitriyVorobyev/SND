Справочник﻿ Причины потерь рабочего времени

Назначение

Справочник "Причины потерь рабочего времени" предназначен для хранения в информационной базе информации о причинах потерь рабочего времени трудовыми ресурсами. Под потерей рабочего времени понимается ситуация, когда оплаченное предприятием рабочее время расходуется трудовым ресурсом непродуктивно (например, отпуск, болезнь, простаивание).

Информация, хранимая в справочнике, используется при заполнении документов Распределение рабочего времени за неделю и Табели учета рабочего времени.

Форма объекта

При создании элемента справочника "Причины потерь рабочего времени" необходимо заполнить следующие обязательные реквизиты:

  • Код элемента — уникальный код элемента (формируется автоматически);
  • Наименование — наименование причины потерь рабочего времени;
  • Вид операции – вид операции потери рабочего времени. Значение выбирается из справочника Виды операций.
