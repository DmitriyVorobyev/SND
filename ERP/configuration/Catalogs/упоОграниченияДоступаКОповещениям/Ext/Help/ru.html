Справочник Ограничения доступа к оповещениям

Назначение

Справочник "Ограничения доступа к оповещениям" предназначен для хранения условий ограничения доступа к оповещениям.

Ограничения используются при настройке списка получателей для вида события в справочнике Виды событий.

Справочник содержит предопределенный элемент, а также позволяет создавать новые ограничения доступа к оповещениям.

Форма объекта

Форма элемента справочника "Ограничения доступа к оповещениям" содержит следующие реквизиты:

  • Наименование – наименование ограничения;
  • Код – формируется автоматически;
  • Вид получателя оповещений – вид получателя оповещений, элемент справочника Виды получателей оповещений;
  • Условие – позволяет настроить отбор объектов системы, по которым будут установлены ограничения:
    • Только указанные – ограничения будут установлены только для указанных в табличной части элементов справочников;
    • Все кроме указанных – ограничения будут установлены для всех элементов справочников, кроме указанных в табличной части.
  • Кнопка Добавить – добавляет новую строку в табличную часть;
  • Комментарий – текстовое поле.


Описание предопределенного ограничения доступа к оповещениям:

Изменение статусов проектов – используется для отбора пользователей при настройке подписки на виды событий, входящие в группу "События проекта". Если пользователь не входит в группу доступа, он не сможет подписаться на событие и не будет получать оповещения.
