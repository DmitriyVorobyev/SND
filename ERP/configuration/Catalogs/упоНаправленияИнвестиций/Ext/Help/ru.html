Справочник Направления инвестиций

Назначение

Справочник "Направления инвестиций" предназначен для хранения сведений о направлениях инвестиций проектов.

Справочник "Направления инвестиций" позволяет:

  • Создавать и хранить в системе информацию о направлениях инвестиций проектов.

    • Форма объекта

    При заполнении формы элемента справочника "Направления инвестиций" необходимо заполнить следующие обязательные реквизиты:

  • Код элемента — формируется автоматически;
  • Наименование — наименование типа проекта.
