Справочник Сообщение пользователю

Назначение

Справочник "Сообщение пользователю" предназначен для хранения сведений о сообщениях пользователю.

Форма объекта

При заполнении формы элемента справочника "Сообщение пользователю" необходимо заполнить следующие обязательные реквизиты:

  • Код элемента — формируется автоматически;
  • Наименование — наименование типа проекта.
