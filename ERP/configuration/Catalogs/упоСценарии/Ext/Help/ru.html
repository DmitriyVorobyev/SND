Справочник Сценарии

Назначение

Справочник "Сценарии" предназначен для создания и хранения сценариев версий проектов.

Сценарий — это сквозной пользовательский признак версий проектов.

Установка сценариев выполняется:

  • для версий одного проекта в обработке Управление версиями проекта;
  • одновременно для нескольких проектов в обработке Панель руководителя с помощью команды "Установить сценарий".

    • Форма объекта

    При заполнении формы элемента справочника "Сценарии" необходимо заполнить следующие обязательные реквизиты:

  • Код справочника — формируется автоматически;
  • Наименование — наименование сценария.
