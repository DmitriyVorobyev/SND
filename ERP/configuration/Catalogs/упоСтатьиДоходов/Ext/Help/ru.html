Справочник Статьи доходов по проектам

Назначение

Справочник "Статьи доходов по проектам" предназначен для хранения информации о тех статьях, в разрезе которых формируется доходная часть плана БДР.

С технической точки зрения, справочник "Статьи доходов по проектам" представляет собой аналитический разрез для любых отчетов конфигурации, в которых в том или ином качестве фигурируют финансовые показатели доходной части БДР.

Форма объекта

При создании элемента справочника "Статьи доходов по проектам" заполняются следующие реквизиты:

  • Код — уникальный код элемента (формируется автоматически);
  • Наименование — наименование статьи;
  • Полное наименование — полное наименование статьи;
  • Родитель — группа статей доходов;
  • Схема оплаты — схема оплаты, использующаяся при включении плановых доходов в план БДДС, элемент справочника Схемы оплаты;
  • Комментарий — текстовое поле.


    • Важно! При автоматическом заполнении плана БДДС на основании плана доходов, проверка схемы оплаты производится в следующей последовательности (используется первое найденное значение):

    1. Договор, указанный в строке доходов;

    2. Контрагент, указанный в строке доходов;

    3. Статья доходов, указанная в строке доходов;

    4. Реквизит "Схема оплаты по умолчанию для доходов" в проектной задаче;

    5. Реквизит "Схема оплаты по умолчанию для доходов" в карточке проекта на закладке "Дополнительно".

    Примечание. В конфигурации 1С:ERP+PM Управление проектной организацией 2 реквизит "Схема оплаты" доступен по ссылке "Настройки отражения (РМ)".
