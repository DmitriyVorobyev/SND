Справочник﻿ Профили распределения трудозатрат

Назначение

Справочник "Профили распределения трудозатрат" предназначен для хранения профилей распределения по временным периодам затрат рабочего времени трудовыми ресурсами предприятия.

Профиль распределения трудозатрат — это совокупность правил, описывающая распределение рабочего времени, затрачиваемого трудовым ресурсом на выполнение работ в рамках проектной задачи, по календарному периоду.

Профиль распределения может быть построен по одному из трех способов:

  • Равномерно по дням;
  • По таблице распределения;
  • По таблице распределения с периодами.

    • Важно! При использовании функций распределения трудозатрат тем или иным объектом конфигурации, календарный период может быть задан как собственно период (дата начала и дата завершения), так и одной только датой начала. В случае, когда период задан одной только датой начала, результатом распределения является не только таблица распределения трудозатрат, но и вычисленная дата завершения периода. В частности, такой способ используется для расчета даты завершения проектной задачи, у которой установлен тип "Модель пакета работ".

    Форма объекта

    При создании элемента справочника "Профили распределения трудозатрат" необходимо заполнить следующие обязательные реквизиты:

  • Код — уникальный код элемента (формируется автоматически);
  • Наименование — наименование профиля (есть возможность автоматического формирования);
  • Способ распределения — способ распределения трудозатрат по календарному периоду. В зависимости от значения этого реквизита изменяется состав элементов управления, отвечающих за настройку профиля.

    • Равномерно по дням

    В этом случае профиль представляет собой набор реквизитов, а именно:

  • Загрузка для линейного распределения, % — реквизит указывает, какая именно загрузка трудового ресурса предполагается для выполнения работ. Значение задается в процентах от максимально возможной загрузки. Максимально возможная загрузка определяется настройками рабочего календаря проекта (рабочий календарь указывается в документе Регистрация проекта). Загрузка трудового ресурса не может быть нулевой

    • При этом способе используется следующий алгоритм распределения трудозатрат:

    1. Распределение трудозатрат производится только между рабочими днями календарного периода. Рабочим считается такой день, для которого в рабочем календаре проекта определено ненулевое количество рабочих часов.
    2. Распределение производится последовательно по рабочим дням, начиная с первого дня календарного периода.
    3. Количество трудозатрат, распределяемых на конкретный рабочий день, вычисляется в соответствии с процентом загрузки, заданным в реквизите "Загрузка для линейного распределения", и количеством рабочих часов на этот день, определяемым настройками рабочего календаря.
    4. В случае если количество рабочих дней в заданном календарном периоде превышает количество рабочих дней, необходимых для распределения заданного количества трудозатрат с заданной загрузкой трудового ресурса, на "лишние" дни начисления трудозатрат не производится.

    Покажем алгоритм распределения на примерах. Допустим, что для проекта задан следующий рабочий календарь:

    День 01.07.19 02.07.19 03.07.19 04.07.19 05.07.19 06.07.19 07.07.19 08.07.19 09.07.19
    Кол-во часов 8.00 8.00 8.00 6.00 6.00 4.00 0.00 8.00 8.00

    Пример #1

    Для распределения имеются следующие исходные данные:

  • Календарный период: с 01.07.19 по 09.07.19
  • Общее количество трудозатрат: 40 часов
  • Загрузка трудового ресурса: 100%

    • В соответствии с правилами линейного распределения загрузка будет распределена по периоду следующим образом:

    День 01.07.19 02.07.19 03.07.19 04.07.19 05.07.19 06.07.19 07.07.19 08.07.19 09.07.19
    Кол-во часов 8.00 8.00 8.00 6.00 6.00 4.00 0.00 0.00 0.00

    Пример #2

    Для распределения имеются следующие исходные данные:

  • Календарный период: с 01.07.19 по 09.07.19
  • Общее количество трудозатрат: 18 часов
  • Загрузка трудового ресурса: 40%

    • В соответствии с правилами линейного распределения загрузка будет распределена по периоду следующим образом:

    День 01.07.19 02.07.19 03.07.19 04.07.19 05.07.19 06.07.19 07.07.19 08.07.19 09.07.19
    Кол-во часов 3.20 3.20 3.20 2.40 2.40 1.60 0.00 2.00 0.00

    Важно! В случае если заданное количество трудозатрат превышает максимальное количество трудозатрат, которое может быть распределено по периоду в соответствии с настройкой профиля распределения, настройки профиля будут проигнорированы и трудозатраты будут распределены равномерно по всем рабочим дням периода. При этом будет учтено количество рабочих часов, заданных в рабочем календаре для каждого из дней периода, и распределение трудозатрат будет производиться пропорционально этому количеству.

    Пример #3

    Для распределения имеются следующие исходные данные:

  • Календарный период: с 01.07.19 по 09.07.19
  • Общее количество трудозатрат: 70 часов
  • Загрузка трудового ресурса: 50%

    • В соответствии с правилами линейного распределения загрузка будет распределена по периоду следующим образом:

    День 01.07.19 02.07.19 03.07.19 04.07.19 05.07.19 06.07.19 07.07.19 08.07.19 09.07.19
    Кол-во часов 10.00 10.00 10.00 7.50 7.50 5.00 0.00 10.00 10.00

    По таблице распределения

    В этом случае настройка профиля распределения представляет собой табличную часть, каждая из строк табличной части описывает субпериод распределения. Табличная часть содержит следующие реквизиты:

  • Трудозатраты, % — реквизит указывает, какую именно часть от общего количества плановых трудозатрат (в процентах) необходимо распределить в данном субпериоде распределения. Общая сумма долей трудозатрат по табличной части должна составлять 100.
  • Загрузка, % — реквизит указывает, какая именно загрузка трудового ресурса (в процентах от максимально возможной) предполагается для выполнения работ в рамках данного субпериода распределения. Загрузка не может быть нулевой.
  • Комментарий — опциональный текстовый комментарий к субпериоду распределения.

    • Важно! Порядок следования строк табличной части имеет значение: при распределении трудозатрат по календарному периоду вначале производится распределение по субпериоду, заданному в первой строке табличной части, затем по субпериоду, заданному во второй строке, и так далее.

    При этом способе используется следующий алгоритм распределения трудозатрат:

    1. Заданное количество трудозатрат разбивается на несколько частей, по количеству субпериодов, описанных в табличной части.
    2. Для каждого из субпериодов вычисляется количество трудозатрат, которые необходимо распределить (в соответствии со значением реквизита "Трудозатраты, %" строки табличной части).
    3. Последовательно для каждого субпериода производится распределение трудозатрат в соответствии с правилами линейного распределения (описаны выше). При этом датой начала расчетов по субпериоду считается следующий рабочий день за датой окончания предыдущего субпериода. Порядок следования субпериодов друг за другом определяется порядком следования строк табличной части.

    Важно! В случае если при распределении трудозатрат по какому-либо из субпериодов на последний рабочий день субпериода выпадает меньшее количество трудозатрат, чем максимально возможное (с учетом процента загрузки, заданного для субпериода), неиспользованные рабочие часы "пропадают" (т.е. не используются при распределении следующего субпериода).

    Алгоритм распределения можно проиллюстрировать на примерах. Допустим, что для проекта задан следующий рабочий календарь:

    День 01.07.19 02.07.19 03.07.19 04.07.19 05.07.19 06.07.19 07.07.19 08.07.19 09.07.19
    Кол-во часов 8.00 8.00 8.00 6.00 6.00 4.00 0.00 8.00 8.00

    Пример #1

    Для распределения имеются следующие исходные данные:

  • Календарный период: с 01.07.19 по 09.07.19
  • Общее количество трудозатрат: 20 часов

    • Задана следующая таблица распределения:

    Номер строки Доля трудозатрат Загрузка Комментарий
    1 50% 100% --
    2 50% 50% --

    В соответствии с правилами линейного распределения загрузка будет распределена по периоду следующим образом:

    День 01.07.19 02.07.19 03.07.19 04.07.19 05.07.19 06.07.19 07.07.19 08.07.19 09.07.19
    Кол-во часов 8.00 2.00 4.00 3.00 3.00 0.00 0.00 0.00 0.00

    Важно! В случае если заданное количество трудозатрат превышает максимальное количество трудозатрат, которое может быть распределено по периоду в соответствии с настройкой профиля распределения, настройки профиля будут игнорированы и трудозатраты (для всех субпериодов) будут перераспределены равномерно по всем рабочим дням периода. При этом будет учтено количество рабочих часов, заданных в рабочем календаре для каждого из дней периода, и распределение трудозатрат будет производиться пропорционально этому количеству.

    Пример #2

    Для распределения имеются следующие исходные данные:

  • Календарный период: с 01.07.19 по 09.07.19
  • Общее количество трудозатрат: 28 часов

    • Задана следующая таблица распределения:

    Номер строки Доля трудозатрат Загрузка Комментарий
    1 50% 100% --
    2 50% 20% --

    В соответствии с правилами линейного распределения загрузка будет распределена по периоду следующим образом:

    День 01.07.19 02.07.19 03.07.19 04.07.19 05.07.19 06.07.19 07.07.19 08.07.19 09.07.19
    Кол-во часов 4.00 4.00 4.00 3.00 3.00 2.00 0.00 4.00 4.00

    По таблице распределения с периодами

    В этом случае настройка профиля распределения представляет собой табличную часть, каждая из строк табличной части описывает субпериод распределения. Табличная часть содержит следующие реквизиты:

  • Доля трудозатрат, % — реквизит указывает, какую именно часть от общего количества трудозатрат (в процентах) необходимо распределить в данном субпериоде распределения. Общая сумма долей трудозатрат по табличной части должна составлять 100.
  • Доля периода, % — реквизит задает, какая доля (в процентах) всего периода относится к данному субпериоду распределения.
  • Комментарий — опциональный текстовый комментарий к субпериоду распределения.

    • Важно! Порядок следования строк табличной части имеет значение: при распределении трудозатрат по календарному периоду вначале производится распределение по субпериоду, заданному в первой строке табличной части, затем по субпериоду, заданному во второй строке, и так далее.

    При этом способе используется следующий алгоритм распределения трудозатрат:

    1. Весь период разбивается на несколько частей, каждая часть соответствует заданному значению доли периода, описанных в табличной части.
    2. Для каждого из субпериодов вычисляется количество трудозатрат, которые необходимо распределить (в соответствии со значением реквизита "Доля трудозатрат, %" строки табличной части).
    3. Последовательно для каждого субпериода производится распределение трудозатрат в соответствии с правилами равномерного распределения (отличается от линейного распределения тем, что не используется такое понятие как загрузка: трудозатраты распределяются в равных пропорциях на все дни субпериода в соответствии с количеством рабочих часов в каждый день). При этом субпериод вычисляется по доле часов на данный субпериод (см. Пример #2). Т.е. в некотором дне часть часов может принадлежать одному субпериоду, а другая часть часов другому. Порядок следования субпериодов друг за другом определяется порядком следования строк табличной части.

    Важно! Независимо от того сколько трудозатрат необходимо распределить, усекаться трудозатраты не будут. Т.е. даже если общее количество трудозатрат для распределения будут превышать максимальное количество рабочих часов на данном субпериоде, то алгоритм разобьет трудозатраты так, что на каждый день будет превышение количества возможных рабочих часов.

    Примечание! Иногда требуется распределить все трудозатраты на весь период равномерно. Для таких случаев надо использовать распределение по таблице загрузки (с периодами), где в таблице вводится одна строка, в которой и доля периода и доля трудозатрат указаны 100%.

    Алгоритм распределения можно проиллюстрировать на примерах. Допустим, что для проекта задан следующий рабочий календарь:

    День 01.07.19 02.07.19 03.07.19 04.07.19 05.07.19 06.07.19 07.07.19 08.07.19 09.07.19
    Кол-во часов 8.00 8.00 8.00 6.00 6.00 4.00 0.00 8.00 8.00

    Пример #1

    Для распределения имеются следующие исходные данные:

  • Календарный период: с 01.07.19 по 09.07.19
  • Общее количество трудозатрат: 40 часов

    • Задана следующая таблица распределения:

    Номер строки Доля трудозатрат Доля периода Комментарий
    1 100% 100% --

    В соответствии с правилами распределения загрузка будет распределена по периоду следующим образом:

    День 01.07.19 02.07.19 03.07.19 04.07.19 05.07.19 06.07.19 07.07.19 08.07.19 09.07.19
    Кол-во часов 5.71 5.71 5.71 4.29 4.29 2.86 0.00 5.71 5.72

    Важно! В случае если не указана дата завершения, то производится распределение трудозатрат в соответствии с правилами линейного распределения (описаны выше).

    Пример #2

    Для распределения имеются следующие исходные данные:

  • Календарный период: с 01.07.19 по 09.07.19
  • Общее количество трудозатрат: 100 часов

    • Задана следующая таблица распределения:

    Номер строки Доля трудозатрат Доля периода Комментарий
    1 60% 20% --
    2 40% 80% --

    В соответствии с правилами распределения загрузка будет распределена по периоду следующим образом:

    День 01.07.19 02.07.19 03.07.19 04.07.19 05.07.19 06.07.19 07.07.19 08.07.19 09.07.19
    Кол-во часов 42.86 21.43 7.14 5.36 5.36 3.57 0.00 7.14 7.14

    Важно! Доля периода вычисляется следующим образом: согласно календарю всего рабочих часов у нас 50 часов. 20% от 50 часов - это 10 часов. Значит, в первый субпериод попадет 01.07.19(8 часов) и 02.07.19 (только 2 часа). Т.е. имеем: надо распределить на 1 субпериод 60% (что составляет 60 часов). Из них согласно пропорции на 01.07.19 составит 42,86 часов и только 17,14 часов на 02.07.19. Также вычисляются значения и для второго субпериода. Только надо учесть, что 02.07.19 осталось только 6 часов из 8 (2 часа ушли на 1 субпериод). Поэтому на 02.07.19 стоит 21,43 часов (это сумма значений для 1 субпериода и 2 субпериода).
