Справочник﻿ Шаблоны объектов

Назначение

Справочник "Шаблоны объектов" предназначен для ввода в систему шаблонов объектов.

Шаблон объекта — это некий "виртуальный" элемент который используется для заполнения Шаблона проектной задачи. В дальнейшем, при разворачивании графика строительства, на основании шаблона объекта автоматически создается элемент справочника Объекты.

Форма объекта

Форма элемента справочника "Шаблоны объектов" содержит следующие реквизиты:

  • Код — формируется автоматически;
  • Наименование — наименование шаблона объекта, заполняется вручную;
  • Полное наименование — полное наименование шаблона объекта, заполняется вручную;
  • Комментарий — произвольный комментарий к элементу справочника.
