Справочник Правила импорта дополнительных полей из MS Project

Назначение

Справочник "Правила импорта дополнительных полей из MS Project" предназначен для настройки соответствия дополнительных полей MS Project реквизитам документа Проектная задача.

Форма объекта

При заполнении формы элемента справочника "Правила импорта дополнительных полей из MS Project" необходимо заполнить следующие обязательные реквизиты:

  • Код – заполняется автоматически;
  • Наименование – наименование правила;

    • Табличная часть заполняется строками соответствия дополнительных полей MS Project реквизитам документа Проектная задача. Новая строка добавляется кнопкой Добавить.

    Реквизиты табличной части:

  • Поиск поля MS Project по заголовку – если опция включена, то при загрузке будет производиться поиск столбца в файле по названию, указанном в реквизите "Поле MS Project".
  • Поле MS Project (Имя поля \ заголовок) – наименование столбца в MS Project;
  • Поле проектной задачи – столбец для выбора реквизита проектной задачи, в который будут записываться данные:
  • Описание результата – текстовое поле, в котором заполняется описание результата по проектной задаче;
  • Критерий результата – текстовое поле, в котором перечисляются критерии результата по проектной задаче;
  • Комментарий – текстовое поле;
  • [Дополнительный реквизит] – при выборе данного значения становится доступным столбец "Дополнительный реквизит\свойство";
  • Дополнительный реквизит\свойство – столбец для выбора дополнительного реквизита проектной задачи, в который будут записываться данные.
