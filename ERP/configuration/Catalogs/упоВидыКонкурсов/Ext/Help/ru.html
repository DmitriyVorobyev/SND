Справочник Виды конкурсов

Назначение

Справочник "Виды конкурсов" предназначен для хранения видов конкурсов (тендеров).
Элементы справочника используются при заполнении соответствующего реквизита в документах Расчет цены контракта.

Форма объекта

При создании элемента справочника "Виды конкурсов" необходимо заполнить следующие реквизиты:

  • Код — уникальный код элемента, формируется автоматически;
  • Наименование — наименование вида конкурса;
  • Полное наименование — полное наименование вида конкурса;
  • Родитель — папка (группа) вида конкурса.
