Справочник Шаблоны проектов

Назначение

Справочник "Шаблоны проектов" предназначен для хранения в системе библиотеки шаблонов проектов.

Шаблон проекта — это совокупность информации о содержании проекта и о требуемых для выполнения проекта ресурсах.

Шаблон проекта может представлять собой не только целый проект, но и этап проекта, или даже набор проектных задач, объединенных в шаблон по каким-либо критериям.

Справочник "Шаблоны проектов" позволяет:

  • Фиксировать и хранить в системе информацию, полученную в процессе выполнения проектов.

    • Шаблоны проектов хранятся в следующих справочниках:

  • Шаблоны проектных задач;
  • Шаблоны проектов.

    • Форма объекта

    На командной панели расположены кнопки:

  • Кнопка Записать – сохранить изменения;
  • Кнопка Записать и закрыть – сохранить изменения и закрыть форму элемента справочника;
  • Кнопка Открыть панель шаблона проекта – открывает обработку Панель шаблона проекта для просмотра и актуализации сохраненного шаблона, а также моделирования проекта на его основе;
  • Кнопка Создать проект – открывает обработку Создание проекта из шаблона для переноса данных из выбранного шаблона в календарно-ресурсный план проекта. Реквизит "Шаблон проекта" в обработке будет заполнен автоматически.

    • При заполнении формы элемента справочника "Шаблоны проектов" необходимо заполнить следующие обязательные реквизиты:

  • Код элемента — формируется автоматически;
  • Наименование — наименование шаблона проекта.

    • Важно! Шаблоны проектов рекомендуется создавать при помощи обработки Сохранение проекта в шаблон.
