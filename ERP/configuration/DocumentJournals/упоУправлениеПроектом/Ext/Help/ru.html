Журнал документов Статусы проекта

Назначение

Журнал документов "Статусы проекта" позволяет создавать и хранить в системе список документов, посредством которых в системе производилось изменение статуса проекта или основных параметров проекта.

Форму журнала документов "Статусы проекта" можно вызвать из меню "Проекты и статусы" → "Статусы проекта".

Форма объекта

На форме журнала документов расположены следующие реквизиты и кнопки:

  • Проект – проект, со статусом которого планируется работать в обработке, элемент справочника Проекты;
  • Кнопка Без статуса – проект еще не прошел стадию инициации.
  • Кнопка Запланирован – создает документ Регистрация проекта, переводит проект в статус "Запланирован".
  • Кнопка Утвержден – создает документ Утверждение плана проекта, переводит проект в статус "Утвержден".
  • Кнопка Выполняется – создает документ Старт проектных работ, переводит проект в статус "Выполняется". Если проект был остановлен или завершен, а позднее возобновлен, то создается документ Возобновление проекта.
  • Кнопка Остановлен – создает документ Остановка проектных работ, переводит проект в статус "Остановлен".
  • Кнопка Завершен – создает документ Завершение проекта, переводит проект в статус "Завершен".

    • Важно! Доступность кнопок определяется текущим статусом выбранного проекта. Текущий статус проекта обозначен кнопкой голубого цвета.

    Список журнала документов "Статусы проекта" состоит из следующих документов:

  • Регистрация проекта – документ создается, если проекту назначен статус "Запланирован".
  • Утверждение плана проекта – документ создается, если проекту назначен статус "Утвержден".
  • Старт проектных работ – документ создается, если проекту назначен статус "Выполняется".
  • Остановка проектных работ – документ создается, если проекту назначен статус "Остановлен".
  • Возобновление проекта – документ создается, если проекту назначен статус "Выполняется", а до этого проект находился в статусе "Остановлен" или "Завершен".
  • Завершение проекта – документ создается, если проекту назначен статус "Завершен".
  • Назначение трудовых ресурсов на проект.
  • Изменение руководителя (куратора) проекта.

    • Журнал документов "Статусы проекта" содержит следующие графы:

  • Тип документа – вид текущего документа в журнале документов;
  • Дата – дата создания документа;
  • Номер – номер документа;
  • Проект – наименование проекта;
  • Руководитель проекта – записывается только для документов, которые меняют руководителя проекта (Регистрация проекта и Изменение руководителя (куратора) проекта).
  • Автор документа – пользователь, который создал данный документ;
  • Автор изменений – пользователь, который изменил данный документ.
