Журнал документов Документы расчета проекта

Назначение

Журнал документов "Документы расчета проекта" предназначен для представления списка документов, посредством которых производятся расчеты календарных сроков проектов.

Список журнала документов "Документы расчета проекта" можно увидеть на форме элемента справочника Проекты, на закладке "Расчеты". В этом случае, в списке журнала автоматически устанавливается отбор по данному конкретному проекту.

В журнал документов "Документы расчета проекта" входят документы следующих типов:

  • Ручная актуализация проекта;
  • Сохранение данных проекта.

    • Форма объекта

    Журнал документов "Документы расчета проекта" содержит следующие колонки:

  • Тип документа — тип сохраненного документа;
  • Дата — дата создания документа;
  • Номер — номер документа;
  • Проект — наименование проекта;
  • Расчет от даты — в зависимости от типа документа, либо дата начала проекта, использованная при расчете календарного плана, либо дата актуализации проекта;
  • Автор документа — пользователь, который создал документ;
  • Автор изменений — пользователь, который произвел последнюю по времени модификацию документа.
