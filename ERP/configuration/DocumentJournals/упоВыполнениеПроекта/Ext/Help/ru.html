Журнал документов Выполнение проекта

Назначение

Журнал документов "Выполнение проекта" позволяет создавать и хранить в системе список документов, посредством которых осуществляется ввод фактических данных по проекту.

Форма объекта

Журнал документов "Выполнение проекта" состоит из следующих документов:

  • Регистрация затрат материальных ресурсов;
  • Ручная актуализация проекта;
  • Регистрация дополнительных затрат;
  • Регистрация фактических движений денежных средств;
  • Регистрация доходов и расходов;
  • Синхронизация фактических доходов и расходов.
