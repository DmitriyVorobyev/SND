Журнал документов Планирование проекта

Назначение

Журнал документов "Планирование проекта" предназначен для представления списка документов, посредством которых в системе производилась модификация календарно-ресурсного плана проекта на этапе планирования (сроки, содержание,состав проектов и т.д.).

Журнал документов "Планирование проекта" позволяет:

  • Создавать и хранить в системе список документов, управляющих планированием проектов.

    • Форма объекта

    Список журнала документов "Планирование проекта" состоит из следующих документов:

  • Проектная задача;
  • Изменение руководителя проектной задачи;
  • Назначение трудовых ресурсов на проектную задачу;

    • Журнал документов "Планирование проекта" содержит следующие колонки:

  • Тип документа — тип сохраненного документа;
  • Дата — дата создания документа;
  • Номер — номер документа;
  • Наименование задачи — название проектной задачи (заполняется только для документов типа "Проектная задача");
  • Проект — наименование проекта;
  • Автор документа — пользователь, который создал данный документ;
  • Автор изменений — последний редактирующий данный документ пользователь.
