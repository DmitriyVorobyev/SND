Шаги настройки подключения к Telegram

Для отправки оповещений сервер 1С (или клиент, если база в файловом режиме) должен иметь доступ в интернет к ресурсу https://api.telegram.org по 443 порту.

1. Создание бота Telegram

Через клиент Telegram открыть бот @BotFather:

  1. Отправить команду /newbot.
  2. После ответов боту получить токен вида 1234567890:abcdefghijklmnopqrstuvwxwzABCDEFGHI.
  3. Полученный токен ввести поле "Токен" формы настроек и сохранить.
  4. Нажать кнопку "Проверить подключение".
  5. В случае успешной настройки в поле ниже будет выведена информация о боте.

2. Установка соответствия пользователей 1С и Telegram

  1. Пользователь через клиент Telegram должен добавить себе бота (имя вида @ИмяБотаДляОповещений создается на первом шаге).
  2. Пользователь должен отправить боту команду /start.
  3. Нажать кнопку "Получить сообщения боту" на странице "Сообщения боту".
  4. Выбрать в списке сообщений нужное (поле пользователя Telegram без соответствия выделено красным) и через контекстное меню вызвать команду "Установить соответствие пользователя".
  5. Выбрать соответствующего пользователя базы и записать.
  6. На странице "Соответствие пользователей" можно посмотреть установленные пары Пользователь базы - ID пользователя Telegram и отправить тестовое сообщение пользователю с помощью команды "Отправить сообщение пользователю".
